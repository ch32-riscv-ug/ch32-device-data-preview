<em>Note 3: Both VDD and VBAT can be connected with an internal analog switch to supply power to the backup</em>  
<em>area and the pins PC13, PC14 and PC15. This analog switch can only pass a limited current (3mA). When</em>  
<em>powered by VDD, PC14 and PC15 can be used for GPIO or LSE pins, and PC13 can be used as a</em>  
<em>general-purpose I/O port, TAMPER pin, RTC calibration clock, RTC alarm clock or second output; PC13,</em>  
<em>PC14, and PC15 can only operate at frequencies below 2MHz when used as GPIO output pins, with a</em>  
<em>maximum load capacitance of 30pF. They cannot be used as current sources (e.g., to drive LEDs). When the</em>  
<em>power is supplied by VBAT, PC14 and PC15 can only be used for LSE pin, and PC13 can be used as TAMPER</em>  
<em>pin, RTC alarm clock or second output;</em>  
<em>Note 4: These pins are in the main function state when the backup area is powered on for the first time. Even</em>  
<em>after reset, the state of these pins is controlled by the backup area registers (these registers will not be reset</em>  
<em>by the main reset system). For specific information on how to control these I/O ports, please refer to the</em>  
<em>relevant chapters on the battery backup area and BKP register in the CH32V205RM;</em>  
<em>Note 5: Chips without a BOOT0 pin have been internally pulled down to VSS.</em>  
<em>Note 6: For the CH32V205CCT6 chip, pins 1 and 2 are default-configured as OSC_IN and OSC_OUT</em>  
<em>functional pins after chip reset. Software can reconfigure these pins as PD0 and PD1 functional pins. For the</em>  
<em>CH32V205RCT6 chip, pins 5 and 6 are configured by default as OSC_IN and OSC_OUT functional pins after</em>  
<em>chip reset. Software can reconfigure these pins as PD0 and PD1 functional pins. However, for the</em>  
<em>CH32V205VCT6 chip, since PD0 and PD1 are inherently functional pins, no additional software remapping</em>  
<em>configuration is required. For further details, refer to the Multifunctional I/O section in the CH32V205RM.</em>  
<em>Note 7: For the CH32V205CCT6 and CH32V205RCT6 chips, the CAN_RX multiplexing function on</em>  
<em>PD0 is not available.</em>
