## 2.3 Pin Alternate Functions

<em>Note: The pin function in the table below refer to all functions and does not involve specific model(s). There are</em>  
<em>differences in peripheral resources between different models. Please confirm whether this function is available</em>  
<em>according to the particular model&#x27;s resource table before viewing this table.</em>  
<em>Note: When pins are configured as multiplexed inputs, optional pins for the same peripheral have priority</em>  
<em>levels (in the tables below, optional pins within the same row are listed in descending order of priority). When a</em>  
<em>lower-priority pin is selected as a multiplexed input for a peripheral, higher-priority pins for that same</em>  
<em>peripheral cannot be simultaneously configured for the same multiplexed function. Example: PA8 (AF0) and</em>  
<em>PB6 (AF0) are both optional pins for the TIM1_CH1 function, with PA8 having higher priority. If PB6 is used</em>  
<em>for TIM1_CH1, avoid configuring PA8 as AF0.</em>
