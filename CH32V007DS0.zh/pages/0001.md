# 概述

CH32V007是基于青稞RISC-V内核设计的工业级通用微控制器，支持48MHz系统主频，单线调试。  
CH32V007内置12位模数转换ADC，采样率高达3Msps；内置高压摆率运放OPA，支持3通道轮询，支  
持单电阻或双电阻电流采样方案；内置2组电压比较器CMP，支持过流保护和3通道轮询比较器定位；  
提供了7路DMA控制器、8路TouchKey、多组定时器、2组USART串口、I2C、SPI等外设资源；可用  
于有感定位、ADC采样或比较器无感定位、单电阻或双电阻采样的电机方案。  
CH32M007K8U7和CH32M007G8R6等效于CH32V007加CH283，内置48V三相双N预驱和自举二极管  
及高压LDO。CH32M007E8等效于CH32V007加CH282，内置24V三相P+N预驱和高压LDO。  

# 产品特性

● 内核Core： ● 运放OPA/PGA/电压比较器：  
- 青稞32位RISC-V2C内核，RV32EmC指令集 - 多路输入通道，可选多档增益
- 快速可编程中断控制器+硬件中断堆栈 - 2路输出通道，可选ADC引脚
- 支持2级中断嵌套 - 支持3通道轮询，支持单或双电阻方案
- 支持系统主频48MHz - 支持高速模式以提高压摆率
● 存储器： ● 2组模拟电压比较器CMP：  
- 8KB易失数据存储区SRAM - 1个通用比较器，3路输入通道，支持3路比
- 62KB程序存储区CodeFlash 较器轮询检测定位，输出到外设或者I/O
- 256B系统非易失配置信息存储区 - 1个精简比较器，在内部级联到OPA输出端
- 256B用户自定义信息存储区 ● 12位模数转换ADC：
● 电源管理和低功耗： - 模拟输入范围：VSS～VDD  
- CH32V007系统供电VDD 范围：2.0～5.5V - 8路外部信号+2路内部信号通道
- CH32M007K8U7/G8R6支持额定6～48V供电 - 支持3M采样率
- CH32M007E8支持额定6～24V供电 ● 8路TouchKey通道检测
- 低功耗模式：睡眠、待机 ● 多组定时器：
● 3相半桥驱动器： - 1个16位高级定时器，提供死区控制和紧急  
- CH32M007K8U7/G8R6内置48V双N预驱和二极管 刹车，提供用于电机控制的PWM互补输出
- CH32M007E8内置24V三相P+N预驱 - 1个16位通用定时器，提供输入捕获、输出
- 内置死区控制，防止高侧低侧功率管直通 比较、PWM、脉冲计数及增量编码器输入
- 内置欠压保护 - 1个16位精简定时器，用于辅助电机应用
● 系统时钟和复位： - 2个看门狗定时器：独立和窗口型  
- 内置出厂调校的24MHz的RC振荡器 - 系统时基定时器：32位计数器
- 内置约128KHz的RC振荡器 ● 2组USART串口：支持LIN
- 外部支持3～25MHz高速振荡器 ● I2C接口
- 内置系统时钟监控（SCM）模块 ● SPI接口
- 上/下电复位、可编程电压监测器 ● 快速GPIO端口：
● 安全特性：芯片唯一ID - 4组GPIO端口，31个I/O口  
● 7路通用DMA控制器： - 映射1个外部中断  
- 7个通道，支持环形缓冲区管理 ● 单线或双线两种调试模式
- 支持TIMx/ADC/USART/I2C/SPI ● 封装形式：QFN、QSOP
