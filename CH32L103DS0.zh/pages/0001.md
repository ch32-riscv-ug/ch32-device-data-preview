# 概述

CH32L103 是基于青稞 RISC-V 内核设计的工业级低功耗通用微控制器。CH32L103 内置 USB 和 PD  
PHY，支持PDUSB，包括USB Host主机和USB Device设备功能、USB PD及Type-C快充功能，内置低  
功耗定时器，提供了1组OPA运放、3组CMP电压比较器、4组USART串口、2个I2C接口、2个SPI  
接口、1组CAN接口、多组定时器、12位ADC、10路Touchkey等丰富外设资源。  
CH32M103G8R6等效于CH32L103加CH282，内置24V三相P+N预驱和高压LDO。  

# 产品特性

● 内核Core： ● 1组运放OPA/PGA/电压比较器：  
- 青稞32位RISC-V4C内核，RV32IMAC指令集 - 多路输入通道，可选多档增益
- 快速可编程中断控制器+硬件中断堆栈 - 多路输出通道，可选ADC引脚
- 分支预测、冲突处理机制 ● 12位模数转换ADC：
- 系统主频96MHz - 模拟输入范围：VSSA～VDDA
● 存储器： - 10路外部信号通道+3路内部信号通道  
- 20KB易失数据存储区SRAM - 片上温度传感器
- 64KB程序存储区CodeFlash ● 10路TouchKey通道检测
- 3328B系统引导程序存储区BootLoader ● 16位低功耗定时器
- 256B系统非易失配置信息存储区 ● 实时时钟RTC：32位独立定时器
- 256B用户自定义信息存储区 ● 多组定时器：
● 电源管理和低功耗： - 1个16位高级定时器，提供死区控制和紧急  
- CH32L103系统供电VDD 范围：1.8～3.6V 刹车，提供用于电机控制的PWM互补输出
- CH32M103G8R6支持额定6～24V供电 - 2个16位通用定时器，提供输入捕获/输出比
- 低功耗模式：睡眠、停止、待机 较/PWM/脉冲计数及增量编码器输入
- VBAT 电源独立为RTC和后备寄存器供电 - 1个32位通用定时器
● 3相半桥驱动器： - 2个看门狗定时器：独立和窗口型  
- CH32M103G8R6内置24V三相P+N预驱 - 系统时基定时器：64位计数器
- 内置死区控制，防止高侧低侧功率管直通 ● 4组USART串口：支持LIN和ISO7816
- 内置欠压保护 ● 2个I2C接口：支持SMBus/PMBus
● 系统时钟和复位： ● 2个SPI接口  
- 内置出厂调校的8MHz的RC振荡器 ● 1组CAN接口（2.0B主动）：
- 内置约40KHz的RC振荡器 - 部分型号支持CAN FD协议
- 内置PLL，可选CPU时钟达96MHz ● USB 2.0全速控制器及PHY：
- 外部支持3～25MHz高速振荡器 - 支持USB主机或USB设备
- 外部支持32.768KHz低速振荡器 ● USB PD和Type-C控制器及PHY：
- 上/下电复位、可编程电压监测器 - 支持DRP、Sink和Source应用
● 8路通用DMA控制器： - 支持PDUSB  
- 8个通道，支持环形缓冲区管理 ● 快速GPIO端口：
- 支持TIMx/ADC/USART/I2C/SPI - 37个I/O口，支持16个外部中断
● 3组模拟电压比较器CMP： ● 安全特性：芯片唯一ID  
- 各2路输入通道，可选公用参考电压引脚 ● 调试模式：串行2线调试接口SDI
- 输出到I/O或者内部直接触发TIM2 ● 封装形式：LQFP、QFN、QSOP、TSSOP
