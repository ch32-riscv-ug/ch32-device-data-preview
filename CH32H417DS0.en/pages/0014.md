### 1.4.4 Power Supply Detector

The power-on reset (POR)/ power-off reset (PDR) circuit is integrated in the chip, which is always in working  
state. When VDD33 is lower than the set threshold (VPOR/PDR), the device is placed in a reset state without using an  
external reset circuit.  
In addition, the system has a programmable voltage monitor (PVD), which needs to be turned on by software to  
compare the voltage magnitude of the VDD33 supply with the set threshold VPVD. Refer to Chapter 3 for VPOR/PDR  
and VPVD values.
