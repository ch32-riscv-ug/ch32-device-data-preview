## 2.3 Pin Alternate Function

<em>Note that the pin function descriptions in the following table are for all functions and do not relate to specific</em>  
<em>models. There are differences in peripheral resources between different models, please check whether this function</em>  
<em>is available according to the product model resource table before checking.</em>  
<em>Note: 1. When pins are configured as multiplexed inputs through the multiplexer, there is a priority level for the</em>  
<em>optional pins of the same peripheral (The optional pins in the same line in each of the following tables are listed</em>  
<em>in descending order of priority). When a low-priority pin is selected as a multiplexed input for a peripheral, a</em>  
<em>high-priority pin of the same peripheral must not be configured as a multiplexed function of that peripheral at the</em>  
<em>same time. Example: PE9 (AF1) and PA8 (AF1) are both optional pins for the TIM1_CH1 function, and the PE9</em>  
<em>pin has a higher priority. If PA8 pin is used as TIM1_CH1, PE9 pin should be avoided to be configured as AF1.</em>  
<em>2. The default configuration of the port pin multiplexing function is AF0.</em>
