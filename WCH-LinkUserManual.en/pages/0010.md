# 4 MounRiver Studio Download and Debug


## 4.1 Download Configuration

<!-- image: p10-draw-image-00002 bbox=[159.6, 141.12, 190.32, 156.84] -->
① Click the arrow in the toolbar to bring up the project download configuration window  
② Click the Disable Read-Protect button to disable the chip read protection  
<!-- image: p10-draw-image-00003 bbox=[191.16, 185.16, 404.04, 224.52] -->
③ Target configuration, the main elements are as follows.  

![image p.10](../assets/p10-draw-image-00004.png) <!-- p10-draw-image-00004 rendered from the PDF -->

④ Configuration Options  
<!-- image: p10-draw-image-00005 bbox=[189.12, 356.28, 406.2, 380.88] -->
<!-- image: p10-draw-image-00006 bbox=[415.32, 390.0, 432.48, 407.16] -->
⑤ Click Apply and Close to save the download configuration. Click on the icon in the toolbar to burn  
the code, and the result will be displayed in the Console.  

## 4.2 Debug

① Enter the debugging page  
<!-- image: p10-draw-image-00007 bbox=[198.84, 484.68, 217.56, 499.68] -->
Way 1: Click the Debug button in the toolbar to enter the debug page directly.  
<!-- image: p10-draw-image-00008 bbox=[177.6, 515.88, 207.6, 530.88] -->
Way 2: Click the arrow in the toolbar and select Debug Configurations to pop up the debug  
configuration page. Double-click GDB OpenOCD MRS Debugging to generate the obj file, select the obj  
file and click the Debug button at the bottom right corner to enter the debugging page.
