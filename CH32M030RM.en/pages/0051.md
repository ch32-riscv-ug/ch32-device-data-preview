This register is used to control the enable and mask of global interrupt. The enable and mask of global interrupt in  
machine mode can be controlled by the MIE and MPIE bits in mstatus, but this register cannot be operated in user  
mode. The global interrupt enable register gintenr is the mapping of MIE and MPIE in mstatus, and can be used to  
set and clear MIE and MPIE by operating gintenr in user mode.  
CSR address: 0x800
