## 19.5 User Option Bytes

The user option byte is solidified in FLASH and is reloaded into the corresponding register after a system reset,  
and can be erased and programmed by the user at will. The user select word information block has a total of 8  
bytes (4 bytes for write protection, 1 byte for read protection, 1 byte for configuration options and 2 bytes for user  
data) and each bit has its own inverse code bit for verification during loading. The structure and meaning of the  
select word information is described below.
