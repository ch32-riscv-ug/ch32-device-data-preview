● The system bus connects the core to the bus matrix and is used to coordinate accesses to the core, DMA,  
SRAM and peripherals.  
● The DMA bus is responsible for the DMA of the HB main control interface connected to the bus matrix,  
which is accessed by FLASH data, SRAM and peripherals.  
● The bus matrix is responsible for the access coordination between the system bus, data bus, DMA bus,  
SRAM.
