### 16.2.2 USB Device Register Description

In USB device mode, USBFS module provides 8 groups of bidirectional endpoints from endpoints 0-7. The  
maximum packet length of all endpoints except endpoint 3 is 64 bytes, and the maximum packet length of  
endpoint 3 is 1023 bytes.  
● Endpoint 0 is the default endpoint, which supports control transmission and shares a 64-byte data buffer  
between transmit and receive.  
● Endpoints 1-7 each include a transmit endpoint IN and a receive endpoint OUT, each with a separate data  
buffer for transmit and receive, and support bulk, interrupt and real-time/synchronous transfers.  
● Endpoint 0 has a separate DMA address, shared between transmit and receive, and endpoints 1-7 each have a  
DMA address for transmit and receive. The data buffer mode can be set to double buffer or single buffer by  
entering the RB_UEPn_BUF_MOD register. If the double buffer mode is used, the endpoint can only use  
single direction transmission.  
● Each group of endpoints has a transceiver control register R16_UEPn_CTRL and a transmission length  
register R16_UEPn_T_LEN and R32_UEPN_DMA (n=0~7), which are used to configure the  
synchronization trigger bit, the response to the OUT transaction and the IN transaction, and the length of the  
transmitted data.  
As a necessary USB device, the pull-up resistor of USB bus can be set by software at any time. When  
RB_UC_DEV_PU_EN in the USB control register R8_USB_CTRL is set to 1, the controller connects the pull-up  
resistor to the DP/DM pin of USB bus internally according to the speed setting of RB_UC_SPEED_TYPE, and  
enables the USB device function.
