### 5.5.4 Dedicated CSR Registers

A number of Control and Status Registers (CSRs) are defined in the RISC-V architecture to configure or identify  
or record operational status. In addition to the standard registers defined in the RISC-V Privileged Architecture  
document, the CH32M030 chip also has a number of vendor-defined registers that need to be accessed using the  
csr instruction.  
<em>Note: Some CSR registers need to be accessed by the system in machine mode, and accessing these CSR registers</em>  
<em>in non-machine mode will cause the chip to enter an exception. Marked as &quot;MRW&quot;: the system needs to be in</em>  
<em>machine mode to access; Marked as &quot;MRO&quot;: read-only in machine mode.</em>

For MCU of V3 series microprocessor, MODE0 is configured as 1 by default in the startup file, and the entry of  
exception or interrupt is shifted according to the interrupt number *4. Note that V3B microprocessor can be either  
a jump instruction or an absolute address of the interrupt function, and it is configured as an absolute address by  
default in the startup file.
