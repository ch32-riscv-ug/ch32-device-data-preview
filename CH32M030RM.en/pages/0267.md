Where, when DAC[5:0]=000001, the pull-up resistor is equal to 7*RDAC(about 108.5kΩ), and when

2. When PDE=1, PUE=0, AE=0, DAC[5:0] input data, BUFOE=0, this is programmable pull-down resistor mode.  
Where, when DAC[5:0]=000000, the pull-down resistor is equal to RDAC(about 15.5kΩ), and when  
DAC[5:0]=111111, the pull-down resistor is equal to 7*RDAC(about 108.5kΩ).  
<em>Note: See Table 20-1 for the resistance values of pull-up/pull-down resistors.</em>  
<strong>Pull-up/pull-down current mode</strong>  
1. When PCS = 10, this time for the weak pull-up current IPU2, about 10uA.  
2. When PCS = 11, this time for the weak pull-down current IPD3, about 2uA.  
3. When PCS=01, this is the weak pull-down current IPD1, which is about 80uA.
