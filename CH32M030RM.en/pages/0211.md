### 14.3.7 SPI Transmit CRC Register (SPI1_TCRCR)

Offset address: 0x18  

<!-- p211-table-001 (table-14-2@1) -->
<table><tr><th>Bit</th><th>Name</th><th>Access</th><th>Description</th><th>Reset value</th></tr><tr><td>[15:0]</td><td>TXCRC[15:0]</td><td>RO</td><td style="text-align:left">Transmit CRC value. Stores the result of the calculated CRC checksum of the bytes that have been sent out. Setting CRCEN resets this register.<br>The calculation is done using the polynomial used in CRCPOLY. 8-bit mode only the lower 8 bits are involved in the calculation, 16-bit mode all 16 bits are involved.
