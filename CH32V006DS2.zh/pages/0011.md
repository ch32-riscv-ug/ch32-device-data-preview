### 1.4.19 5V全桥功率驱动器

CH32M006为小功率无线充电的发射端或者电机驱动专用MCU，内部集成的全桥开关由半桥1和半  
桥2组成，每个半桥包含低侧功率管N型MOSFET和高侧功率管P型MOSFET、各自的栅极驱动模块及  
死区控制模块等。此外，CH32M006 还内置了电流采样模块 CS 及无线充电反馈信号放大模块，可用于  
小体积小功率无线充电的发射端或者电机驱动。  
CH32M006的两对半桥分别由高级定时器TIM1产生2路PWM信号控制，PWM死区时间可调。使用时  
应设置位TIM1_RM = 0011将TIM1进行引脚映射。SW1由MCU的PC5控制，SW2由MCU的PC7控制，SW1/SW2  
的输出与 PC5/PC7 提供的 PWM 控制信号同相，支持通过 PWM 占空比调节输出功率，支持 1MHz 频率的  
PWM控制。PWM1和PWM2信号默认为低电平。  
该全桥功率开关及其驱动为全静态设计，无需动态 PWM 维持自举电压，支持低频 PWM，支持直流  
有刷马达正反向驱动。  
除了上述定时器可设置的PWM死区时间，全桥模块还内置了硬件死区控制，用于避免高低两个功  
率管同时导通形成大电流而造成损坏。  
功率管存在与正常开启时电流极性相反的寄生二极管，可以用于功率管关闭期间为感性负载维持  
续流，但该二极管自身压降较大，应该避免长时间续流造成过热，禁止在空载时进行高功率驱动。  
对于感性负载的电流方向切换，建议先驱动 PWM1和 PWM2 同时低电平至少 100nS 后再切换。PWM  
调节输出功率时建议渐进式调节，禁止大幅度阶跃式调节（可能损坏芯片），禁止以高占空比进行冷启  
动或空闲重启（可能损坏芯片）。  
PWME为PWM全局使能控制信号，由MCU的PB5控制。PWME高电平使能PWM并开启CS电流采样和  
放大，PWME低电平则禁用PWM和CS等电路以降低功耗，并将SW1和SW2关闭且输出置为三态。PWME  
不影响ROP。  

### 1.4.20 全桥功率驱动电流采样CS及放大

CH32M006的全桥模块内置Current-Sense电流采样，转成电压并放大后从CSO引脚输出，由于开  
关脉冲的噪声较大，建议CSO电压信号经过RC低通滤波后再连接ADC引脚或者比较器。为去除芯片失  
调和离散性的影响，该电压会叠加直流偏置电压Vcsofs，离散性较大，MCU需要用有电流时的ADC值  
减去无电流时的ADC值，以ADC差值所对应的压差除以系数Gcs计算电流。内置电流采样离散性较大，  
且存在非线性，GND封装内阻或PCB走线电阻也都会影响Gcs，所以，电流值主要用于粗略控制和相对  
比较，例如电流信号解调或FOD异物检测，不宜用于精密计算。  
参考计算公式：Ifb = ( Vcso – Vcsz ) / Gcs  
例如，Gcs=0.65，PWM关闭、无电流时的CSO电压Vcsz为0.9V，开启后有电流时的CSO电压Vcso  
为1.29V，则全桥电流Ifb=(1.29-0.9)/0.65=0.6A；如果Vcso为2.2V，则Ifb=(2.2-0.9)/0.65=2A。  
考虑到半桥1与半桥2的内阻或PCB走线未必一致，建议用经过RC低通滤波、包含至少两个PWM  
周期的平均电流采样值作为结果。  
CSO引脚如果短接到VDD，满足关闭电压Vaioff，则可以关闭CS模块，以降低静态电流。  

### 1.4.21 调试接口（SDI Serial Debug Interface）

内核自带一个串行单线调试接口（1-wire SDI Serial Debug Interface）和一个串行2线调试接  
口（2-wire SDI Serial Debug Interface）。系统支持单双线两种调试模式；其中，单线调试为默认  
调试模式，对应SWIO引脚（Single Wire Input Output），而双线调试对应SWDIO和SWCLK引脚，应  
用于下载时可以提高速度。系统上电或复位后默认调试接口引脚功能开启，主程序运行后可以根据需  
要关闭SDI。在使用单线仿真调试接口时必须开启HSI时钟。
