# 概述

CH32M030是基于青稞RISC-V3B内核设计的工业级Type-C/电机微控制器。CH32M030内置4个OPA运放  
和3个电压比较器CMP，支持组合成2组交流小信号放大解码器QII和2组差分输入电流采样ISP；内置USB  
PHY和双路Type-C/PD PHY，支持USB主机和USB设备、PDUSB、Type-C快充、BC1.2及CDP等多种高压充电  
协议；内置4对N型功率管栅极预驱，提供高压I/O；内置可编程灌电流模块用于动态调节DC-DC；提供DMA  
控制器、12位模数转换ADC、定时器、UART串口、I2C、SPI等外设资源，提供过压保护和过温保护。  

# 产品特性

● 内核Core ● SPI接口  
- 青稞32位RISC-V3B内核 ● 2组Type-C和USB PD控制器及PHY
- 支持RV32IMCB指令集和自扩展指令 - 支持DRP、Sink和Source应用
- 三级流水线 - 4个耐28V高压的CC引脚
- 特有高速的中断响应机制 ● 全速USB 2.0控制器及PHY
- 最高72MHz系统主频 - 支持PDUSB、Host主机和Device设备模式
● 存储器 - 支持BC1.2及多种HV DCP/CDP充电协议  
- 12KB易失数据存储区SRAM - 内置6位DAC，可编程电压输出及上下拉
- 64KB带ECC校验的程序存储区Code Flash ● 多组定时器
- 512B用户自定义信息存储区 - 1个16位高级定时器，提供死区控制和紧急刹
● 电源管理和低功耗 车，提供用于电机控制的PWM互补输出  
- 内置高压LDO，VHV 支持额定5～28V系统供电 - 1个16位通用定时器
- 预驱动I/O供电VDD8 额定电压：5～10V - 1个16位的精简通用定时器
- 普通I/0和ADC供电VDD33 额定电压：3.3V - 1个窗口看门狗定时器
- 低功耗模式：睡眠、停止、待机 - 系统时基定时器：32位计数器
● 4个双N型MOSFET半桥驱动器 ● 4个运放OPA和3个模拟电压比较器CMP  
- 4对高侧/低侧MV引脚，支持VDD8 电压 - 可组合为2组交流小信号放大解码器QII1及
- 内置低压降自举二极管，外部只需要电容 QII2和2组差分输入电流采样ISP1及ISP2
- 可组合为三相电机栅极驱动 - OPA1和OPA2支持自偏置的PGA
- 可组合为两路独立的全桥驱动 - OPA3和OPA4支持单端及差分输入，PGA多档增
● 系统时钟 益选择，提供内部自偏置电压  
- 内置出厂调校的8MHz的RC振荡器 - CMP1支持数字滤波
- 支持外部4～25MHz晶体 - CMP2和CMP3支持N端偏置可选，数字滤波
● 7路通用DMA控制器 - CMP3有多路输入通道，输出到I/O或者内部  
- 7个通道，支持环形缓冲区管理 ● 2组10位可编程灌电流模块
- 支持TIMx/ADC/UART/I2C/SPI ● 2组源电流模块
● 12位模数转换ADC ● GPIO端口  
- 模拟输入范围：GND～VDD33- 36个I/O口，映射16个外部中断
- 20路外部信号通道 - 8个MV大电流预驱动引脚，用于功率管驱动
- 支持外部延迟触发，支持ADC滑动平均功能 - 多个40V高压开漏引脚，提供升压电荷泵
● OTP过温保护和OVP过压保护及欠压复位 ● 安全特性：64位芯片唯一ID  
● 多引脚映射的UART串口 ● 调试模式：支持单线和双线两种调试模式  
● I2C接口 ● 封装形式：LQFP、QFN、QSOP
