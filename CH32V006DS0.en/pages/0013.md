### 1.4.18 Serial Debug Interface (SDI)

The core comes with 1-wire SDI Serial Debug Interface and 2-wire SDI Serial Debug Interface. The system  
supports 2 debugging modes: 1-wire SDI is the default debugging mode, which corresponds to SWIO pin (Single  
Wire Input Output), while 2-wire SDI corresponds to SWDIO and SWCLK pin, which can be used to increase the  
speed when applying to download. The debug interface pin function is turned on by default after the system is  
powered on or reset, and the SDI can be turned off according to the need after the main program is running. The  
HSI clock must be turned on when using the 1-wire emulation debug interface.
