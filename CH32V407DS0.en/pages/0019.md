### 1.4.29 Random Number Generator (RNG)

The chip has a built-in hardware random number generator, based on continuous analog noise, which  
provides a 32-bit random number through internal analog circuitry.  

### 1.4.30 Operational Amplifier (OPA/PGA)

The chip integrates one operational amplifier (OPA or PGA) and can also function as a voltage comparator;  
both its input and output can be configured to select from multiple channels, It features built-in PGA gain  
adjustment resistors, supporting multiple amplification levels such as 4, 8, 16, and 32. It supports amplifying  
external analog small signals for input to an ADC to enable small-signal ADC conversion, and can also  
function as a signal comparator, with the comparison results output via GPIO or directly connected to the  
input channel of TIMx.  

### 1.4.31 General-purpose Input and Output (GPIO)

The system provides 5 groups of GPIO ports (PA0~PA15, PB0~PB15, PC0~PC15, PD0~PD15, PE0~PE12)  
with a total of 80 GPIO pins. Each pin can be configured by software as output (push-pull or open-drain), input  
(with or without pull-up or pull-down) or multiplexed peripheral function port.  
Most GPIO pins are shared with digital or analog multiplexed peripherals. Except for ports with analog input  
functions, all GPIO pins have high current passing capabilities. A locking mechanism is provided to freeze the  
IO configuration to avoid accidental writing to the I/O register.  
All I/O pins in the system are powered by VDD, which is rated at 3.3 V. When VDD is de-energized, pins PC13  
~ PC15 automatically switch to being powered by VBAT.  

### 1.4.32 Serial Debug Interface (SDI)

The core includes a built-in 1-wire SDI Serial Debug Interface and a 2-wire SDI Serial Debug Interface. The  
system supports both 1-wire and 2-wire debug modes. 1-wire debugging is the default mode, utilizing the  
SWIO pin (Single Wire Input Output). 2-wire debugging employs the SWDIO and SWCLK pins, enhancing  
download speeds during application. Upon power-up or reset, the debug interface pins default to active  
functionality. After the main program runs, SDI can be disabled as needed.
