## 1.4 Functional Description


### 1.4.1 QingKe RISC-V3V Processor

RISC-V3V supports the ICBM-X subset of the RISC-V instruction set. The processor is managed internally  
in a modular fashion and contains units such as fast programmable interrupt controller (PFIC) and extended  
instruction support. Externally multiple buses are connected to external unit modules to enable interaction  
between external function modules and the core.  
The processor can be flexibly applied in different scenarios, such as small-area low-power embedded  
scenarios, high-performance application operating system scenarios, etc., due to its minimal instruction set,  
multiple working modes, and modular customization extensions.  
● Sequential single-issue architecture  
● 2–3-stage pipeline  
● Provide a non-maskable interrupt (NMI)  
● 2-level interrupt nesting  
● Fast Programmable Interrupt Controller (PFIC)  
● Support bit operation instructions  
● Support custom extended instructions  
● Hardware interrupt stack  
● Vector operation/parallel processing  

### 1.4.2 On-chip Memory and Boot Mode

Built-in zero-wait 200K byte SRAM area is used to store data, which will be lost after power failure.  
Built-in 992K bytes program flash memory storage area (Code FLASH), i.e. user area, for user&#x27;s application  
program and constant data storage. This includes a 480K byte non-zero-wait program area and a 512K byte  
zero-wait program execution area.  
64KB of the zero-wait data SRAM can be configured for zero-wait programs, resulting in a 416KB  
non-zero-wait program area, a 576KB zero-wait program execution area, and a 136 KB zero-wait data  
SRAM area.  
Built-in 28 bytes System FLASH (System FLASH), i.e. BOOT area, used for system boot program storage,  
built-in bootstrap loading program.  
Built-in 128 bytes system non-volatile configuration information storage area, used for vendor&#x27;s configuration  
word storage, factory-cured, user cannot be modified.  
Built-in 128 bytes user-defined information storage area for user option byte storage.  
At startup, one of three bootstrap modes can be selected via the bootstrap pins (BOOT0 and BOOT1):  
● Bootstrap from program flash memory  
● Boot from system memory  
● Boot from internal SRAM  
The bootstrap loading program is stored in the system memory and the contents of the program flash memory  
storage area can be reprogrammed via the USART1 and USB interfaces.
