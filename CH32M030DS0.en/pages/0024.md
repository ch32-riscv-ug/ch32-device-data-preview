<em>HV= High voltage pin, which supports input and output of VHV voltage range;</em>  
<em>HVOD= High voltage pin, supporting open-drain output in VHV voltage range;</em>  
<em>PD= Built-in pull-down resistor that cannot be turned off, which can be used to drive the gate of N-MOSFET;</em>  
<em>A= Analog signal input or output, supporting VDD33 voltage range.</em>  
<em>Note 2: The underlined value of the remapping function indicates the configuration value of the corresponding bit</em>  
<em>in the AFIO register. For example, SPI_MOSI_2 indicates that the corresponding bit of AFIO register is</em>  
<em>configured as 10b.</em>  
<em>Note 3: All GPIO pins support controllable pull-up except PB7~PB15 and PC5. PB0 and PB1 have built-in</em>  
<em>pull-down resistors that are turned on by default, adjustable and turned off, and can provide pull-down current;</em>  
<em>CC1/CC2/CC3/CC4 if there is a suffix R, it means that the controllable Rd pull-down resistor defined by the</em>  
<em>built-in Type-C specification is turned on by default; PA0/CC1R and PA1/CC2R pins are internally provided with</em>  
<em>controllable Rd pull-down resistors; PB8, PB10, PB12 and PB14 have built-in pull-down resistors that cannot be</em>  
<em>turned off; None of the other GPIO pins have built-in pull-down resistors.</em>  
<em>Note 4: For the reset pin, its position selection is controlled by the user word configuration bit RST_PIN_SEL.</em>  
<em>When bit RST_PIN_SEL = 1, PA15 is the reset pin; When bit RST_PIN_SEL = 0, PC0 is the reset pin.</em>  
<em>Note 5: When VHV&lt; 5V and PA0~PA3 are used as ADC input channels or GPIO push-pull outputs, the voltage</em>  
<em>range is about 0V ~ (VDD33-1.7V).</em>  
<em>Note 6: For CH32M030K8U7 chip, PA4 and PA6 pins are short-bonded inside the chip, and it is forbidden to</em>  
<em>configure both IO as output function.</em>  
<em>Note 7: For CH32M030G8R7 chip, the pins PB5 and PA13 are short-circuited inside the chip, and it is forbidden</em>  
<em>to configure both IO as output functions.</em>  
<em>Note 8: For CH32M030K8U7 chip, VS1, VS2 and VS3 pins are shorted inside the chip.</em>  
<em>Note 9: For CH32M030K8U7 chip, VB1, VB2 and VB3 pins are shorted inside the chip.</em>  
<em>Note 10: The PWM output of TIM2_CH2 is changed to PC5 pin output when bit[11:10] TIM2_RM of register</em>  
<em>AFIO_PCFR1 = 10 and bit[12] CH2_PWMOUT_EN of TIM2_CTLR1 = 1. PC5 is an open source output when it</em>  
<em>is used for TIM2_CH2 output, and if TIM2_CH2 is at high level, PC5 is at high level; If TIM2_CH2 is low, PC5 is</em>  
<em>high impedance state.</em>  
<em>Note 11: When PB4 is used as a VHV partial pressure monitoring function, the input voltage must not exceed</em>  
<em>VDD33-0.9V.</em>
