<em>Note 3: These pins are in the main function state when the backup area is powered on for the first time. Even</em>  
<em>after reset, the state of these pins is controlled by the backup area registers (these registers will not be reset</em>  
<em>by the main reset system). For specific information on how to control these I/O ports, please refer to the</em>  
<em>relevant chapters on the battery backup area and BKP register in the CH32FV2x_V3xRM datasheet.</em>  
<em>Note 4: For CH32V317WCU6 chip, pin 5 and pin 6 are configured as OSC_IN and OSC_OUT function pins</em>  
<em>by default after the chip is reset. Software can reset these two pins to PD0 and PD1 functions. However, for</em>  
<em>CH32V317VCT6 chip, because PD0 and PD1 are inherent function pins, there is no need for remapping</em>  
<em>settings by software. For more details, please refer to the reuse function I/O chapter and debugging setting</em>  
<em>chapter in the CH32FV2x_V3xRM.</em>  
<em>Note 5: For chips where neither the BOOT0 nor BOOT1/PB2 pins are externally routed, the internal BOOT0</em>  
<em>pin is internally shorted to GND, while the BOOT1/PB2 pin is left floating. In low-power scenarios, it is</em>  
<em>recommended to configure PB2 as a pull-down input to prevent additional current flow.</em>  
<em>For chips where the BOOT1/PB2 pin is brought out but the BOOT0 pin is not, the internal BOOT0 pin is</em>  
<em>internally shorted to GND.</em>  
<em>For chips where the BOOT0 pin is brought out but the BOOT1/PB2 pin is not, the internal BOOT1/PB2 pin is</em>  
<em>internally shorted to GND. In low-power mode, it is recommended to configure PB2 as a pull-down input to</em>  
<em>prevent additional current flow.</em>  
<em>Note 6, note 7: For CH32V317WCU6 chip, the pins PB10 and PD15 are short sealed inside the chip, and it</em>  
<em>is forbidden to configure both IO as output function, so pay attention to the pin state with power consumption</em>  
<em>requirements; PB11 and PD14 pins are short-sealed inside the chip, so it is forbidden to configure both IO as</em>  
<em>output function. Please pay attention to the pin status if there is power consumption requirement.</em>  
<em>Note 8: SDIO_D0 and SDIO_D1 are mapped to PC8 and PC9 by default. When bit[14]ETHMACEN=1 and</em>  
<em>bit[10]SDIOEN=1 in register RCC_HBPCENR, the default mapping of SDIO_D0 and SDIO_D1 is</em>  
<em>automatically changed to PB14 and PB15.</em>  
<em>Note 9: DVP_D5 is mapped to PB6 by default. When bit[13]DVPEN=1 and bit[11]USBHSEN=1 in register</em>  
<em>RCC_HBPCENR and bit[2]RB_UC_RST_SIE=0 in R8_USB_CTRL, the default mapping of DVP_D5 is</em>  
<em>automatically changed to PB3.</em>  
<em>Note 10: The value underlined by the remapping function indicates the configuration value of the</em>  
<em>corresponding bit in the AFIO register. For example, UART4_RX_3 indicates that the corresponding bit of</em>  
<em>AFIO register is configured as 11b.</em>  
<em>Note 11: TIM2_CH1 and TIM2_ETR share a pin, but they cannot be used at the same time.</em>  
<em>Note 12: The CH32V317 chip supports Ethernet pin RX/TX transmission/reception identification and paired</em>  
<em>switching, supports pin MDIRP/MDIRN positive/negative identification and switching, and supports pin</em>  
<em>MDITP/MDITN positive/negative identification and switching.</em>
