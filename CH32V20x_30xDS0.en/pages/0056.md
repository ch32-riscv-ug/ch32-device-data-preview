Note 6: SPI3_MOSI is mapped to PB5 by default. Only for products with the fifth last digit of the lot number being 2 and the sixth last digit of the lot number being 0,  
when using Ethernet, the I2S3 default pin function is unavailable, and the chip select signal of the SPI3 default pin is unavailable. At this time, the SPI3_MOSI default  
mapping is automatically changed to PA15.
