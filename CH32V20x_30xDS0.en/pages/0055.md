Note 1: SDIO_D0 and SDIO_D1 are mapped to PC8 and PC9 by default. Only for products where the fifth last digit of the lot number is greater than 1, or the sixth last  
digit of the lot number is not 0 (except for the CH32V305GBU6 chip), when bit[14]ETHMACEN=1 and bit[10]SDIOEN=1 in the register RCC_HBPCENR, the default  
mapping of SDIO_D0 and SDIO_D1 is automatically changed to PB14 and PB15.  
Note 2: DVP_D5 is mapped to PB6 by default. Only for products where the fifth last digit of the lot number is greater than 1, or the sixth last digit of the lot number is  
not 0, when bit[13]DVPEN=1 and bit[11]USBHSEN=1 of the register RCC_HBPCENR and bit[2]RB_UC_RST_SIE=0 of R8_USB_CTRL, the default mapping of  
DVP_D5 is automatically changed to PB3.  
Note 3: FSMC_NADV is mapped to PB7 by default. Only for products where the fifth last digit of the lot number is greater than 1, or the sixth last digit of the lot  
number is not 0, when bit[8]FSMCEN=1 and bit[11]USBHSEN=1 in the register RCC_HBPCENR and bit[2]RB_UC_RST_SIE=0 in R8_USB_CTRL, the default  
mapping of FSMC_NADV is automatically changed to PD2.  
Note 4: I2S3_SD is mapped to PB5 by default. Only for products where the fifth last digit of the lot number is greater than 2, or the sixth last digit of the lot number is  
not 0, if 10M Ethernet and I2S3 functions are used at the same time, the default mapping of I2S3_SD is automatically changed to PA9.  
Note 5: I2S3_MCK is mapped to PC7 by default. Only for products where the fifth last digit of the lot number is greater than 2, or the sixth last digit of the lot number is  
not 0, if 10M Ethernet and I2S3 functions are used at the same time, the default mapping of I2S3_MCK is automatically changed to PA8.
