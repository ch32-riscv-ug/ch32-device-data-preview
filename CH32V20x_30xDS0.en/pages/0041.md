<em>Note 3: These pins are in the main function state when the backup area is powered on for the first time. Even</em>

<em>Note 4: Pin 5 and pin 6 of those in LQFP64M package are configured as OSC_IN and OSC_OUT function</em>  
<em>pins by default after chip reset. Software can reconfigure these 2 pins as PD0 and PD1. But for those in</em>  
<em>LQFP100 package, since PD0 and PD1 are inherent functional pins, there is no need to remap settings by</em>  
<em>software. For more detailed information, please refer to the chapters on Alternate Function I/O and Debug</em>  
<em>Setting in the CH32FV2x_V3xRM datasheet.</em>  
<em>Note 5: For chips where neither the BOOT0 nor BOOT1/PB2 pins are externally routed, the internal BOOT0</em>  
<em>pin is internally shorted to GND, while the BOOT1/PB2 pin is left floating. In low-power scenarios, it is</em>  
<em>recommended to configure PB2 as a pull-down input to prevent additional current flow.</em>  
<em>For chips where the BOOT1/PB2 pin is brought out but the BOOT0 pin is not, the internal BOOT0 pin is</em>  
<em>internally shorted to GND.</em>  
<em>For chips where the BOOT0 pin is brought out but the BOOT1/PB2 pin is not, the internal BOOT1/PB2 pin is</em>  
<em>internally shorted to GND. In low-power mode, it is recommended to configure PB2 as a pull-down input to</em>  
<em>prevent additional current flow.</em>  
<em>Note 6: For CH32V305FBP6 and CH32V305GBU6 chips, the PA8 and PC9 pins are shorted inside the chip,</em>  
<em>it is prohibited to configure both IOs as output functions, pay attention to the pin state if there are power</em>  
<em>consumption requirements.</em>  
<em>Note 7: SDIO_D0 and SDIO_D1 are mapped to PC8 and PC9 by default. Only for products with the fifth</em>  
<em>from the bottom of the batch number greater than 1 or the sixth from the bottom of the lot number not equal</em>  
<em>to 0 (except for the chip CH32V305GBU6), when the bit[14]ETHMACEN=1 and bit[10]SDIOEN=1 in the</em>  
<em>register RCC_HBPCENR, the default mapping of SDIO_D0 and SDIO_D1 is automatically changed to PB14</em>  
<em>and PB15.</em>  
<em>Note 8: DVP_D5 is mapped to PB6 by default. Only for products with the fifth from the bottom of the lot</em>  
<em>number greater than 1 or the sixth from the bottom of the batch number not equal to 0, when the</em>  
<em>bit[13]DVPEN=1 and bit[11]USBHSEN=1 in the register RCC_HBPCENR and the</em>  
<em>bit[2]RB_UC_RST_SIE=0 in R8_USB_CTRL, the default mapping of DVP_D5 is automatically changed to</em>  
<em>PB3.</em>  
<em>Note 9: FSMC_NADV is mapped to PB7 by default. Only for products with the fifth from the bottom of the lot</em>  
<em>number greater than 1 or the sixth from the bottom of the lot number not equal to 0, when the</em>  
<em>bit[8]FSMCEN=1 and bit[11]USBHSEN=1 in the register RCC_HBPCENR and bit[2]RB_UC_RST_SIE=0</em>  
<em>in R8_USB_CTRL, the default mapping of FSMC_NADV will be automatically changed to PD2.</em>  
<em>Note 10: I2S3_SD is mapped to PB5 by default. Only for products with the fifth from the bottom of the lot</em>  
<em>number greater than 2 or the sixth last digit of the lot number not equal to 0, if 10M Ethernet and I2S3</em>  
<em>functions are used at the same time, the default mapping of I2S3_SD will be automatically changed to PA9.</em>  
<em>Note 11: I2S3_MCK is mapped to PC7 by default. Only for products with the fifth from the bottom of the lot</em>  
<em>number greater than 2 or the sixth last digit of the lot number not equal to 0, if 10M Ethernet and I2S3</em>  
<em>functions are used at the same time, the default mapping of I2S3_MCK will be automatically changed to PA8.</em>  
<em>Note 12: SPI3_MOSI is mapped to PB5 by default. Only for products with the fifth from the bottom of the lot</em>  
<em>number equal to 2 or the sixth last digit of the lot number equal to 0, when using Ethernet, the default pin</em>  
<em>function of I2S3 is not available, and the chip selection signal of the default pin of SPI3 is not available. At</em>  
<em>this time, the default mapping of SPI3_MOSI is automatically changed to PA15.</em>
