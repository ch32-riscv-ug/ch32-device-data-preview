#### 19.2.5.6 LINK ITP Timeout Mode Register (R8_LINK_ITP_PRE)

Offset address: 0x17  

<!-- p330-table-001 (table-19-14@1) -->
<table><tr><th>Bit</th><th>Name</th><th>Access</th><th>Description</th><th>Reset value</th></tr><tr><td>[7:0]</td><td>ITP_PRE</td><td>RO</td><td style="text-align:left">ITP timeout mode:<br>1: Ignore the impact of ITP transmission/reception on the link idle state for both downlink and uplink ports;<br>0: The link is considered non-idle when the downlink port transmits non-delayed ITP or the uplink port receives non-delayed ITP.</td><td>0x80</td></tr></table>


#### 19.2.5.7 LINK U2 Inactivity Timeout Counter Threshold Register (R8_LINK_U2_INACT_TIMER)

Offset address: 0x1D  

<!-- p330-table-002 (table-19-14@1) -->
<table><tr><th>Bit</th><th>Name</th><th>Access</th><th>Description</th><th>Reset value</th></tr><tr><td>[7:0]</td><td style="text-align:left">U2_INACTIVE_TIMER</td><td>RW</td><td style="text-align:left">Value of U2&#x27;s inactivity timeout counter threshold:<br>U2 Timeout value (this value represents the maximum allowed time in U0/U1 inactive state, and enters U2 state after timeout), value range: 0x00~0xff, 256us/LSB.<br>Note: When the U1/U2 Timeout value is 0xff, it means that the timeout time of the link inactive state is infinite, and the conversion request to U1/U2 will not be actively initiated when the timer reaches 0xff.</td><td>0</td></tr></table>


#### 27.2.5.8 U1 Wake-up LFPS Valid Duration Register (R8_LINK_U1_WKUP_FILTER)

Offset address: 0x28  

<!-- p330-table-003 (table-19-14@1) pages 330-331 -->
<table><tr><th>Bit</th><th>Name</th><th>Access</th><th>Description</th><th>Reset value</th></tr><tr><td>[7:0]</td><td style="text-align:left">U1_WKUP_FILTER</td><td>RW</td><td style="text-align:left">The valid duration of the LFPS received during U1 exit. The port sends LFPS for handshaking.<br>When the received LFPS reaches this duration,<br>the received U1 EXIT is considered valid. Pull high the sent LFPS_last to indicate successful handshaking. Default is 600ns.<br>U1_WKUP_FILTER[7]: Controls the time unit of U1_WKUP_FILTER[6:0];<br>1: U1_WKUP_FILTER[6:0] unit is in us,<br>duration is (n)us;<br>0: U1_WKUP_FILTER[6:0] unit is 8ns,<br>duration is (8n)ns, where n ranges from 0 to 124;<br>Note: When the duration exceeds 1ns, the configuration method with U1_WKUP_FILTER[7] set to 1 must be used;<br>otherwise, U1 cannot be awakened.</td><td>0x4A</td></tr></table>
