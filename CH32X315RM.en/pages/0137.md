The dual ADC mode for ADC3 and ADC4 is used in the same way as for ADC1 and ADC2.  
<em>Note: In the dual ADC mode, when selecting an external trigger event, the user must enable the external trigger of</em>  
<em>the master-slave ADC and set the master ADC to the corresponding trigger and the slave ADC to software trigger</em>  
<em>to prevent unnecessary triggering from causing the slave ADC to convert.</em>  
The following possible modes can be achieved through configuration:  
● Independent mode  
● Synchronous injection mode  
● Synchronization rule mode  
● Fast alternating mode  
● Slow alternating mode  
● Alternate trigger mode  
● Synchronous rule mode + synchronous injection mode  
● Synchronous rule mode + alternate trigger mode  
● Synchronous injection mode + fast alternating mode  
● Synchronous injection mode + slow alternating mode  
<em>Note: 1. In dual ADC mode, in order for the main data register to read the conversion data from the slave ADC,</em>  
<em>the DMA bit needs to be enabled.</em>  
<em>2. Each ADC has independent DMA function.</em>
