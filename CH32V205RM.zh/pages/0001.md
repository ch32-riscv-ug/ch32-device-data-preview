# 说明

CH32V205是基于青稞RISC-V内核设计的工业级通用微控制器。CH32V205内置USB2.0高速PHY  
收发器（480Mbps）和 PD PHY，支持 PDUSB，包括 USB Host 主机和 USB Device 设备功能、USB PD  
及Type-C快充功能，提供了可编程协议I/O控制器PIOC、静态存储器控制器FSMC、QSPI接口、CAN  
接口、8组USART串口、2组I2C、2组SPI、多组定时器、2组OPA运放、2组CMP电压比较器、4Msps  
高速12位ADC、16路Touchkey等丰富外设资源。  
本手册针对用户的应用开发，提供了CH32V205、CH32V203芯片的详细使用信息。
