### 33.3.5 Timeout Control Register (R8_EMMC_TIMEOUT)

Offset address: 0x1C  

<!-- p743-table-002 (table-33-1@1) -->
<table><tr><th>Bit</th><th>Name</th><th>Access</th><th>Description</th><th>Reset Value</th></tr><tr><td>[7:4]</td><td>Reserved</td><td>RO</td><td>Reserved</td><td>0</td></tr><tr><td>[3:0]</td><td style="text-align:left">RB_EMMC_TOCNT_<br>MASK</td><td>RW</td><td style="text-align:left">Response/Data Timeout Configuration.<br>Non-zero: Sets the timeout duration, valid values 1-15;<br>Calculation: Module clock cycle * 4194304 *<br>RB_EMMC_TOCNT_MASK.<br>Example: For an SDCLK cycle of 10ns and a value of 12 entered, the timeout duration is 10ns *<br>(4194304) * (12) = 503ms.<br>0: Not available.</td><td>0xC</td></tr></table>

<em>Note 1: The aforementioned data timeouts encompass the following four scenarios:</em>  
<em>1) D[0] busy timeout following the R1b response;</em>  
<em>2) D[0] busy timeout after the CRC status during data block write;</em>  
<em>3) CRC status wait timeout during data block write;</em>  
<em>4) Start bit wait timeout during data block read.</em>
