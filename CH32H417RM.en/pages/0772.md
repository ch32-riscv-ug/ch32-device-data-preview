# Chapter 36 Serial Audio Interface (SAI)

Serial Audio Interface (SAI) supports various common audio protocols, such as I2S, PCM/DSP, AC&#x27;97, LSB or  
MSB alignment and TDM, which is suitable for mono and stereo applications. In order to realize the flexibility  
and configurability of SAI interface, it adopts two completely independent audio submodules, each of which  
contains up to four IO pins (SD, SCK, FS and MCLK).  
SAI can be configured as any combination of master/slave and sending/receiving, and its operation mode can be  
set as full duplex/simplex according to the synchronous/asynchronous configuration of audio submodule.  

## 36.1 Main Features

● Provide 2 independent control modules, with each audio submodule configurable in any combination of  
master/slave or transmit/receive roles, each featuring an 8-word FIFO  
● Audio submodules can operate in synchronous or asynchronous modes, with master/slave configurations  
independent of each other  
● Flexible slot length configuration, with slots configurable as valid or invalid  
● Frame synchronization configuration (valid level, valid length, and offset)  
● Each audio frame contains up to 16 configurable slots  
● Up to 16 slots, each supporting 8-bit, 10-bit, 16-bit, 20-bit, 24-bit, or 32-bit data  
● Support LSB or MSB data transmission  
● Support multiple audio protocols including I2S standard, LSB or MSB alignment, PCM/DSP, TDM, and  
AC&#x27;97  
● Features mono/stereo audio functionality with mute settings  
● Serial clock strobe edge selection (SCK)  
● Each audio submodule has 2 independent DMA interfaces supporting slave mode at frequencies up to 4MHz  
● Error flag bits and interrupt sources:  
- FIFO overflow and underflow;
- Frame sync advance detection in slave mode;
- Frame sync lag detection in slave mode;
- AC&#x27;97 codec not ready;
- Clock configuration error.
