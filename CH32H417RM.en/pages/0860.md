### 40.4.1 NOR/PSRAM Address Mapping

HADDR[27:26] bits are used to select one of the four storage areas shown in Table 40-1.  

<!-- p860-table-002 (table-40-2@1) -->
<table><caption>Table 40-2 NOR/PSRAM memory area selection</caption><tr><th>HADDR[27:26](1)</th><th>Selected storage area</th></tr><tr><td>00</td><td>Storage area 1NOR/PSRAM1</td></tr><tr><td>01</td><td>Storage area 1NOR/PSRAM2</td></tr><tr><td>10</td><td>Storage area 1NOR/PSRAM3</td></tr><tr><td>11</td><td>Storage area 1NOR/PSRAM4</td></tr></table>

<em>Note 1: HADDR is HB&#x27;s internal address line, but also participates in addressing external memory.</em>  
The HADDR[25:0] bits contain the external memory address. Since HADDR is a byte address and memory is  
addressed in words, the address actually sent to memory varies depending on the memory data width, as shown in  
the table below.  

<!-- p860-table-003 (table-40-3@1) -->
<table><caption>Table 40-3 NOR/PSRAM memory area address</caption><tr><th>Memory width(1)</th><th>The data address sent to the memory</th><th>Maximum memory capacity (bits)</th></tr><tr><td>8位</td><td>HADDR[25:0]</td><td>64MB×8=512Mb</td></tr><tr><td>16位</td><td>HADDR[25:1]&gt;&gt;1</td><td>64MB/2×16=512Mb</td></tr><tr><td>32位</td><td>HADDR[25:2]&gt;&gt;2</td><td>64MB/4×32=512Mb</td></tr></table>

<em>Note 1: When the external memory width is 16 bits, the FMC uses the internal HADDR[25:1] address as the</em>  
<em>external memory address FMC_A[24:0]. When the memory width is 32 bits, the FMC will use the internal</em>  
<em>HADDR[25:2] address for external addressing. Regardless of the external memory width, FMC_A[0] must be</em>  
<em>connected to the external memory address A[0].</em>
