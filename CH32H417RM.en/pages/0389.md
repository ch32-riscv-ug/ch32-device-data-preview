<strong>Perform frame transmission initiated by the master device</strong>  
On the bus, the master device continuously executes frame transfers until the final message is transmitted  
(R32_I3C_EVR register FCF bit is 1) or an error occurs during transmission (R32_I3C_EVR register ERRF bit is  
1), triggering the corresponding interrupt (if enabled). This process relies on the R32_I3C_CTLR and  
R32_I3C_TDW/TDR registers (written explicitly by software or automatically pushed by assigned DMA channels)  
and the R32_I3C_RDW/RDR registers (read explicitly by software or by assigned DMA channels). After  
completing the transmission, the I3C master device returns to idle state.  
When the S-FIFO is disabled (the SMODE bit in the R32_I3C_CFGR register is 0), the hardware will update the  
I3C status register (R32_I3C_STATR) for each message that has been completed without transmission errors,  
indicating that the transmission of an exchange message has been completed on the I3C bus, and the software can  
choose to read or ignore this register.  
When the S-FIFO is disabled in the R32_I3C_STATR register (SMODE bit in the R32_I3C_CFGR register is 0),  
except for the completion of the last message transmission (FCF bit in the R32_I3C_EVR register is 1) or a  
transmission error occurs (ERRF bit in R32_I3C_EVR register is 1) triggering a corresponding interrupt (if  
enabled), the software is also notified when the slave device prematurely terminates a read transfer during a direct  
CCC read or private read transfer. This notification occurs via the RXTGTENDF bit in the R32_I3C_EVR register  
being set to 1 and triggering a corresponding interrupt (if enabled). Software can subsequently read the  
R32_I3C_STATR register to obtain additional information about the executed transfer.  
If the S-FIFO is enabled (bit 1 in the SMODE field of the R32_I3C_CFGR register), the status register  
R32_I3C_STATR must be read once after each word message transfer completes, regardless of whether the device  
prematurely terminates the read transfer. This can be done via software (notified by the SFNEF bit in the  
R32_I3C_EVR register being set to 1 and the corresponding interrupt, if enabled) or via DMA (if the SDMAEN  
bit in the R32_I3C_CFGR register is set to 1). Frame transfer completion is only reported after reading the status  
of the last message (S-FIFO is empty) (R32_I3C_EVR register FCF bit set to 1).  
<strong>Update master device transmission configuration</strong>  
After the software returns to the idle state, it can update the configuration of the I3C peripheral before the next  
transmission:  
- Configure the R32_I3C_TIMINGR2 register to modify the SCL clock pause;
- Configure the R32_I3C_INTENR register to modify the interrupt/polling mode strategy;
- Configure the TXTHRES, RXTHRES, TMODE, SMODE, TXDMAEN, CDMAEN, RXDMAEN, SDMAEN,
EXITPTRN, RSTPTRN, and NOARBH bits in the R32_I3C_CFGR register;  
Modify/prepare the control word, status word and read/write data of the next frame transmission to be executed by  
software and/or DMA.  
Generally, after broadcast/direct DISEC/ENEC CCC is issued and completed:  
– Modify the hot-join acknowledgment strategy via the HJACK bit in the R32_I3C_CFGR register;  
– Modify the IBI/CR acknowledgment strategy for any slave device x via the R32_I3C_DEVRx register.
