–According to the configuration at DMA module level, DMA will automatically push/write data bytes/words  
from its memory source buffer into R32_I3C_TDR or R32_I3C_TDWR register (depending on the TXTHRES bit  
in R32_I3C_CGFR register) until the frame is completed (after the last message of the frame, a stop bit will be  
issued on I3C bus), except when a transmission error occurs.  
I3C messages start with a start bit or a repeat start bit and end with a stop bit or a repeat start bit. At the message  
level, the last data byte/word to be sent is indicated by the R32_I3C_EVR register TXLASTF=1. When the I3C  
frame contains multiple messages (separated by repeated start bits), the software can use this event to update the  
corresponding pointer to the buffer for storing the byte/word of the next message.  
When the report frame completes (R32_I3C_EVR register FCF = 1 and the corresponding interrupt is enabled),  
the TX-FIFO is empty. If the TX-FIFO is empty and a data byte must be transmitted on the I3C bus, a TX-FIFO  
underflow is reported (R32_I3C_EVR register ERRF = 1 and R32_I3C_STATER register DOVR = 1). If the  
corresponding interrupt is enabled (R32_I3C_INTENR register ERRIE = 1), an interrupt is generated. When the  
I3C peripheral is not active, the configuration managing the TX-FIFO can be modified.  
When operating as a master device, the hardware automatically clears the TX-FIFO upon a transmission error  
(ERRF = 1).  
<strong>No C-FIFO/TX-FIFO preload</strong>  
C-FIFO size is 2 words and TX-FIFO size is 8 bytes.  
When the preload function of the C-FIFO/TX-FIFO is not enabled, that is, the R32_I3C_CFGR register  
TMODE=0, once the C-FIFO receives the first control word, the I3C peripheral will immediately send out the  
start bit on the I3C bus. Subsequently, the peripheral will decode the R32_I3C_CTLR register and write the next  
data byte or word as needed. Once it is detected that the hardware requires to send the next control word on the  
I3C bus (for example, it is necessary to send a repeated start bit on the I3C bus or the C-FIFO needs to obtain  
available space), the peripheral will immediately request to write the control word into the C-FIFO until the last  
message (that is, R32_I3C_CTLR register MEND=1). Similarly, once it is detected that the hardware requires  
another data byte or word to be sent on the I3C bus (for example, a repeated start bit needs to be sent on the I3C  
bus, the TX-FIFO is not full, or the data byte or word must be sent during the I3C message), the data byte/word  
must be written into the TX-FIFO immediately.
