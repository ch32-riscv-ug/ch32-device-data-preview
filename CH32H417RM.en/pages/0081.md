## 4.4 Inter-process Communication (IPC)

Inter-core communication functionality provides four communication channels, each with 8 status bits. Status bits  
are independently enabled, supporting 2 interrupt modes, and featuring 32-bit × 4 communication data registers.  
● 2 types of channel interrupt modes: receive interrupt and transmit interrupt.  
● Each channel features 8 status bits, with independent enable capability and automatic status bit updates.
