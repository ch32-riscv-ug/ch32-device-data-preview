If the corresponding audio module is configured as the master module and the NODIV bit in the  
R32_SAI_xCFGR1 register is set to 0, the master clock can be generated for an external decoder via the I/O port.  
When the audio module is defined as slave mode, the clock generator is disabled. The values of the NODIV and  
MCKDIV bits are ignored. Additionally, the MCLK I/O pin is released and can be used as a general-purpose I/O.  
The bit clock is derived from the master clock. The bit clock divider sets the division factor between the bit clock  
(SCK) and the master clock (SCK) according to the following formula:  
SCK = MCLK*(FRL[7:0]+1)/256  
Among them:  
256 is the fixed ratio between MCLK and the audio sampling frequency;  
FRL[7:0] represents the number of bit clock cycles within an audio frame minus one, configured in the  
R32_SAI_xFRCR register.  
In Master Mode, (FRL[7:0]+1) must equal a power of 2 to yield an even number of MCLK pulses per bit clock  
cycle. A 50% duty cycle is guaranteed on the bit clock (SCK).  
The SAI_CK_x clock may also equal the bit clock frequency. In this case, the NODIV bit in the  
R32_SAI_xCFGR1 register should be set to 1, and the values within the MCKDIV divider and the bit clock  
divider will be ignored. At this time, the number of bits in each frame is completely configurable, and it is not  
necessary to be equal to several powers of 2.  

### 36.3.2 Operation Mode

The SAI audio submodule can be configured via the MODE[1:0] bits of the R32_SAI_xCFGR1 register to operate  
in any combination of master/slave, transmit/receive modes.  
Each audio module within the SAI is enabled via the SAIEN bit in the R32_SAI_xCFGR1 register. In slave mode,  
once this bit is activated, the transmitter or receiver becomes sensitive to activity on the clock line, data line, and  
sync line.  
In master TX mode, the enabled audio module immediately generates bit clocks for the external slave module  
even if no data is present in the FIFO, but the generation of the FS signal is controlled by the presence of data in  
the FIFO. Upon receiving the first data to be transmitted, the FIFO outputs this data to the external slave module.  
If no data is present in the FIFO for transmission, subsequent values of zero are transmitted within the audio frame,  
and an underflow flag is generated.  
In slave mode, audio frames commence when the audio module is enabled and the SOF bit is detected.  
In slave TX mode, an underflow event cannot occur on the first frame after enabling the audio module, as the  
forced operation sequence is as follows:  
1) Write to R32_SAI_xDATAR via software or DMA;  
2) Wait until the FIFO threshold (FLTH) flag differs from 000b (indicating FIFO is empty);  
3) Enable the audio module for slave transmit mode.  
<strong>Master mode</strong>  
In master mode, the SAI provides clock signals to connected external devices:  
1) Bit clock and frame sync are output on pins SCK and FS, respectively;  
2) If required, the SAI can also generate the master clock on the MCLK pin.  
FS is generated when the FIFO is not empty and at the start of a frame. CK and MCLK generation, however, are  
not dependent on the FIFO status and are produced whenever the audio submodule is enabled.
