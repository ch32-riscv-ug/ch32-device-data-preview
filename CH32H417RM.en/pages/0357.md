# Chapter 20 Serial-parallel Interconversion Controller and Transceiver (SerDes)

<strong><em>The module description in this chapter only applies to CH32H417 microcontroller products.</em></strong>  
A set of SerDes modules supporting signal isolation and long-distance transmission are built into the system,  
which includes 2 independent SerDes controllers, supports 1.5Gbps high-speed differential signals  
(SERDES_RXP, SERDES_RXN, SERDES_TXP, SERDES_TXN pins), and can carry out long-distance data  
transmission through an optical fiber module or a differential peer-to-peer transmission medium in a network  
cable.  
The SerDes module integrates a full-duplex PHY and 2 independent control units. Each control unit can be  
functionally paired with either the PHY&#x27;s receive (Rx) channel or transmit (Tx) channel. Note: A single control  
unit must not interface with both the receive and transmit channels simultaneously. By configuring 2 controllers to  
2 channels, the SerDes full-duplex communication functionality can be achieved. For the specific implementation  
approach and configuration process, please refer to the official EVT reference example provided.  
The base addresses of the 2 controllers are configured as follows:  
SerDes1 controller 1 base address: 0x40027C00  
SerDes2 controller 2 base address: 0x40027C40  

## 20.1 Main Features

● Programmable data transmission rates up to 1.5Gbps  
● Support high-voltage signal isolation via network transformers and low-voltage capacitive isolation  
● Built-in 8-bit/10-bit encoding/decoding with CRC checksum and serial number matching  
● Integrated FIFO with dual-buffer mode for transmit/receive  
● Support DMA functionality with byte-aligned address access  
● Provide multiple transmission interrupt flags and status indicators for timely application layer feedback  
● Differential transceiver capable of directly driving fiber optic modules  

## 20.2 Function Description


### 20.2.1 Transmit Mode (Query Mode)

1. Set SERDESx_CTRL register  
ALIGN_EN/PWR_UP/TX_PWR_UP/LINK_RESET/ALL_CLR is 1;  
2. Wait PLL locked (PLL_LOCK=1);  
3. Set SERDESx_CTRL register  
ALIGN_EN/PWR_UP/TX_PWR_UP/INT_BUSY/DMA_EN/TX_EN is 1;  
4. Set LINK_INIT to 1, start sending initialization packet, delay 100ms (software delay), and clear  
LINK_INIT;  
5. Set transmit DMA address (Single buffer configuration DMA0 is enough);  
6. Set SERDESx_DATA0 (Single buffer mode);
