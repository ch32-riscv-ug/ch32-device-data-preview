### 44.2.15 HB Dead-time

To limit HB bandwidth usage, a dead-time can be programmed between 2 consecutive HB accesses.  
The dead-time function is enabled by setting bit EN in the R32_GPHA_AMTCR register to 1.  
The dead-time value is stored in bits DT[7:0] of the R32_GPHA_AMTCR register. This value represents the  
minimum number of cycles allowed between 2 consecutive transactions on the HB bus.  
Updates to the dead-time value during GPHA operation take effect during the next HB transmission.
