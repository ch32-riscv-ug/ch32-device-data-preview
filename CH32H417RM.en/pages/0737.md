### 33.2.4 Write Multiple Data Blocks Consecutively

1) Configure the R16_EMMC_CONTROL register to set the sampling edges for commands and data, the data  
bus width for transmission and reception, and enable DMA functionality. Configure the  
RB_EMMC_TOCNT_MASK bit in the R8_EMMC_TIMEOUT register to set the command timeout and data  
timeout durations. After successful command transmission, configure the R32_EMMC_BLOCK_CFG  
register to set the single data block length during transfer and the total number of data blocks to be read,  
thereby initiating data transfer. Configure the R32_EMMC_TRAN_MODE register to set the DMA transfer  
direction to “Controller to SD”.  
2) Send commands to the SDIO slave interface device. These commands require the host interface to transmit  
data to the slave device via the data cable, such as CMD24 and CMD25 in the SD protocol.  
3) The controller interface writes data to the data line: After the slave interface device responds to the host  
command, it generates a response packet and releases the data line state (non-low level). At this point, the host  
can drive the data line to output a data block. Writing to the DMA register R32_EMMC_DMA_BEG1 or  
performing a write operation to the R32_EMMC_WRITE_CONT register both trigger the host interface to  
drive the data line. The difference lies in the behavior when manipulating register R32_EMMC_DMA_BEG1:  
the hardware loads the current value of the R32_EMMC_DMA_BEG1 register internally and fetches data  
from this address to send to the controller. whereas writing to the R32_EMMC_WRITE_CONT register  
instructs the hardware to continue fetching SRAM data from the position currently occupied by the DMA  
internally. Therefore, to change the DMA address (making it non-contiguous with previous data), the  
R32_EMMC_DMA_BEG1 register must be rewritten to resume data line output. If the new address is  
contiguous with previously written data, the hardware automatically fetches data from the address and moves  
it. You can directly write to the R32_EMMC_WRITE_CONT register to instruct the controller to continue  
data line output. Each time data of the size specified by RB_EMMC_BKSIZE_MASK is output, it indicates  
the completion of one data block transfer. Simultaneously, the internal total number of transferred data blocks  
is decremented by one. Once all data blocks have been transferred, the internal DMA will cease further data
