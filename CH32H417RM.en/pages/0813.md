### 37.3.6 QSPI FLASH Configuration

The device configuration register (R32_QSPIx_DCR) is used to define the characteristic parameters of the  
external SPI FLASH. The FSIZE[4:0] field determines the capacity of the external memory according to the  
following formula:  
Number of bytes in FLASH = 2[FSIZE+1]  
FSIZE+1 represents the number of address bits required for FLASH addressing. In indirect mode, the maximum  
FLASH capacity reaches 4GB (using 32-bit addressing), but the addressable space in memory-mapped mode is  
limited to 256MB. If DFM=1, FSIZE denotes the combined capacity of 2 FLASH chips.  
When QSPI executes two consecutive commands, it holds the chip select signal (nCS) high between commands  
for a default duration of one SCK cycle. If the FLASH requires a longer interval between commands, the Chip  
Select High Time (CSHT) field can be used to specify the minimum number of SCK cycles (maximum 8) that  
nCS must remain high. The clock mode (CKMODE) bit indicates the logic level of the SCK signal between  
commands (when nCS=1).  

### 37.3.7 QSPI Configuration

QSPI configuration occurs in 2 stages: QSPI IP configuration and QSPI FLASH configuration. Once configured  
and enabled, the QSPI can operate in one of three modes: Indirect Mode, Status Polling Mode, and  
Memory-Mapped Mode.  
QSPI IP Configuration: Configured via R32_QSPIx_CR. The user must configure the clock prescaler division  
factor for incoming data and the sampling shift settings. The FIFO level for generating DMA triggers or interrupts  
is programmed in the FTHRES bit. If a timeout counter is required, set the TCEN bit to 1 and program the timeout  
value in the R32_QSPIx_LPTR register. Dual flash mode can be activated by setting DFM to 1.  
QSPI FLASH Configuration: Configure parameters related to the external target FLASH via the  
R32_QSPIx_DCR register. Users must program the FLASH size in the FSIZE bit, program the minimum hold  
time for the chip select high level in the CSHT bit, and set the functional mode (Mode 0 or Mode 3) in the MODE  
bit.  

### 37.3.8 Usage of QSPI

Select the operation mode through R32_QSPIx_CCR register FMODE[1:0].  
<strong>Indirect Mode</strong>  
When FMODE=00b, the indirect write mode is selected, enabling data transmission to the FLASH. When  
FMODE=01b, the indirect read mode is selected, allowing data retrieval from the FLASH.  
When QSPI operates in indirect mode, frames are constructed as follows:  
1) Specify the target address in the R32_QSPIx_AR register;  
2) Specify the operating mode in the R32_QSPIx_CR register;  
3) Specify the number of bytes to read or write in the R32_QSPIx_DLR register;  
4) Specify the frame format, mode, and command code in the R32_QSPIx_CCR register;  
5) Read data from/write data to the FIFO via the R32_QSPIx_DR register;
