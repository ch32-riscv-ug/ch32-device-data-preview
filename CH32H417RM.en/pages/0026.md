#### 3.3.5.6 USB Clock

The USBHS clock source originates from the USBHSPLL clock. The USBHS_PLL clock source is selected by  
configuring the USBHSPLLSRC bit in the RCC_PLLCFGR2 register. If the input clock is selected as the divided  
SYS_PLL_CLK, the division factor can be chosen via the USBHSPLL_IN_DIV[4:0] bits. The clock frequency is  
selected by configuring the USBHSPLL_REFSEL[1:0] bits. The clock frequency must match the USBHS_PLL  
input clock. The USBHS_PLL clock is enabled by configuring the USBHS_PLLON bit in the RCC_CTLR  
register.  
The USBFS/OTG_FS 48MHz clock source originates from either the PLL clock through a configurable divider or  
the USBFS_PLL clock, selectable by configuring the USBFSSRC bit in the RCC_CFGR2 register. The  
USBOTG_FS clock is enabled by configuring the OTGFSEN bit in the RCC_HBPCENR register.  
The USBSS clock source originates from a USBSS_PLL clock, which outputs a 125MHz clock to USBSS. The  
USBSS_PLL clock is enabled by configuring the USBSS_PLLON bit in the RCC_CTLR register.  

#### 3.3.5.7 ETH Clock

Refer to Section 31.4.3 for the ETH clock configuration.  

#### 3.3.5.8 I2S and RNG Clock

The clock source for I2S and RNG originates from PLL_CLK or the system clock (SYSCLK). The clock sources  
for I2S2, I2S3, and RNG can be selected via the I2S2SRC, I2S3SRC, and RNGSRC bits in the configuration  
register RCC_CFGR2, respectively.  

### 3.3.6 Clock Security System

The clock security system is a running protection mechanism of the controller, which can switch to the HSI clock  
in the case of HSE clock transmission failure, and generate interrupt notification, allowing application software to  
complete the rescue operation.  
Activate the clock security system by setting CSSON position 1 of the RCC_CTLR register. At this point, the  
clock monitor will be enabled after the HSE oscillator startup (HSERDY=1) delay and turned off after the HSE  
clock is turned off. Once the HSE clock fails during the operation of the system, the HSE oscillator will be turned  
off, the clock failure event will be sent to the brake input of the advanced timer (TIM1 and TIM8), and the clock  
security interrupt will be generated, CSSF position 1, and the application will enter the NMI unshielded interrupt.  
By setting the CSSC bit, the CSSF bit flag can be cleared and the NMI interrupt suspension bit can be revoked.  
When CSSON is enabled, an HSE failure event does not affect HSE or PLL enable states, and software may  
handle it within the NMI interrupt. However, if the CSS_HSE_DIS bit in the RCC_CTLR register is set to 1  
before activating the clock security system (CSSON=1), an HSE failure event occurring while CSSON is enabled  
will cause the hardware to disable HSE and all PLLs utilizing HSE.
