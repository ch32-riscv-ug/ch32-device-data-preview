### 44.2.5 GPHA Foreground Layer and Background Layer CLUT Interface

CLUT is a table for storing color mapping, which maps the index value of each pixel to a specific color value.  
CLUT interface can manage the access to CLUT memory and the automatic loading of CLUT. CLUT interface  
supports the following access methods:  
- PFC reads the CLUT during pixel format conversion;
- The CPU accesses the CLUT via the HB from the device port to read or write data;
- When performing automatic CLUT loading, CLUT writing is executed through the HB master device port.
CLUT memory loading can be realized by automatic loading and manual loading:  
<strong>Autoloading</strong>  
1) Program the CLUT address into the R32_GPHA_FGCMAR register (foreground layer CLUT) or the  
R32_GPHA_BGCMAR register (background layer CLUT).  
2) Program the CLUT size into the CS[7:0] bits of the R32_GPHA_FGPFCCR register (foreground layer CLUT)  
or the R32_GPHA_BGPFCCR register (background layer CLUT).  
3) Set the START bit in the R32_GPHA_FGPFCCR register (foreground layer CLUT) or R32_GPHA_BGPFCCR  
register (background layer CLUT) to 1 to initiate the transfer. During auto-loading, the CPU must not access the  
CLUT. If a conflict occurs and the CAEIE bit in the R32_GPHA_CTLR register is set to 1, a CLUT access error  
interrupt is generated.  
<strong>Manual loading</strong>  
The application must manually program the local CLUT memory via the GPHA HB from the device port; this  
CLUT maps to the CLUT in the dedicated SRAM.  
1) Program the CLUT pixel address into the FG_CLUT_INDEX bit of the R32_GPHA_FGCRWS register  
(foreground layer CLUT) or the BG_CLUT_INDEX bit of the R32_GPHA_FGCRWS register (background layer  
CLUT).  
2) Program the CLUT pixel value into the R32_GPHA_FGCDAT register (foreground layer CLUT) or the  
R32_GPHA_BGCDAT register (background layer CLUT). The CPU automatically loads this pixel value into the  
corresponding CLUT memory.  
The CLUT format supports 24-bit or 32-bit. The CCM bit in the R32_GPHA_FGPFCCR register (for the  
foreground layer CLUT) or the R32_GPHA_BGPFCCR register (for the background layer CLUT) configures the  
CLUT color mode. Refer to Table 44-4 for specific configuration details.
