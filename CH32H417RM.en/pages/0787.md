### 36.3.10 Mute Mode

When the audio sub-module is used as a transmitter or receiver, the mute mode can be used.  
<strong>Audio sub-module in transmission mode</strong>  
In transmit mode, mute mode can be selected at any time. Mute mode is effective for all audio frames. During  
frame transmission, mute mode can be enabled by setting the MUTE bit in the R32_SAI_xCFGR2 register to 1.  
This mute mode bit is latched only at the end of a frame. If the MUTE bit is set to 1 at the end of a frame, mute  
mode activates at the start of the next audio frame and persists throughout its entire duration until the next frame  
ends. The bit is then latched to determine whether the subsequent frame remains a mute frame.  
If the number of slots set via the NBSLOT[3:0] bits in the R32_SAI_xSLOTR register is less than or equal to 2,  
you can specify whether the value sent in mute mode is 0 or the last value for each slot. This is selected via the  
MUTEVAL bit in the R32_SAI_xCFGR2 register.  
If the number of slots set in the NBSLOT[3:0] bits of the R32_SAI_xSLOTR register exceeds 2, the MUTEVAL  
bit in the R32_SAI_xCFGR2 register becomes meaningless since a value of 0 is sent on every bit of each slot.  
In mute mode, the FIFO pointer continues to increment. This means that data requested for transmission in the  
FIFO during mute mode will be discarded.  
<strong>Audio sub-module in receiving mode</strong>  
In receive mode, for a given number of consecutive audio frames (R32_SAI_xCFGR2 register MUTECNT[5:0]  
bits), if zero is received in all declared active slots of the audio frame, a mute pattern from an external transmitter  
is detected. Upon detecting the corresponding number of mute frames, the MUTEDET flag in the R32_SAI_xSR  
register is set to 1 and triggers an interrupt if the MUTEDETIE bit in the R32_SAI_xCFGR2 register is set to 1.  
The mute frame counter is reset when the audio submodule is disabled or when at least one data frame is received  
within a valid slot. An interrupt is generated only once when the counter reaches the value specified in the  
MUTECNT[5:0] bits. Subsequent interrupt events are reinitialized when the counter is reset.  
<em>Note: Mute mode is not available for SPDIF audio module.</em>  

### 36.3.11 Compressed Expansion Mode

In the field of mobile communications, pre-processing of data for transmission often involves the application of  
data compression and decompression algorithms.  
The application can select whether to process data before transmission on the SD serial output line (compression)  
and whether to decompress data after reception on the SD serial input line (expansion) based on the COMP[1:0]  
bits of the R32_SAI_xCFGR2 register (used only when TDM mode is selected), as shown in Figure 36-11. The  
two supported compression/decompression modes are μ-Law and A-Law, both of which are standards  
recommended by CCITT G.711.
