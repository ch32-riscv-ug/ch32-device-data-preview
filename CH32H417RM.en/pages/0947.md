### 42.3.10 Extreme Value Detector

The Extreme Value Detector captures the minimum and maximum values (peak-to-peak values) of the final output  
data word.  
If the output data word exceeds the value stored in the maximum value register of the extremum detector  
(EXMAX[23:0] bits in the R32_DFSDM_FLTxEXMAX register), this register is updated with the current output  
data word value, and the channel storing its data is indicated in the EXMAXCH bit (of the  
R32_DFSDM_FLTxEXMAX register).  
If the output data word is less than the value stored in the extremum detector minimum register (EXMIN[23:0]  
bits in the R32_DFSDM_FLTxEXMIN register), this register is updated with the current output data word value,  
and the channel storing its data is indicated by the EXMINCH bit (in the R32_DFSDM_FLTxEXMIN register).  
The minimum and maximum value register values can be refreshed by software (by reading the  
R32_DFSDM_FLTxEXMAX or R32_DFSDM_FLTxEXMIN registers). After refresh, the minimum value data  
register (R32_DFSDM_FLTxEXMIN) is filled with 0x7FFFFF (maximum positive value), and the maximum  
value register (R32_DFSDM_FLTxEXMAX) is filled with 0x800000 (minimum negative value).  
The extremum detector performs comparison operations only after completing right shift and offset data  
correction. For each extremum detector, the input channels involved in extremum calculation are selected by the  
EXCH[1:0] bits (in the R32_DFSDM_FLTxCR2 register).
