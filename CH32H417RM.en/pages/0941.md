### 42.3.4 Parallel Data Input

Each input channel provides a register for 16-bit parallel data input (except serial data input). Each 16-bit parallel  
input can only come from an internal data source:  
● Internal ADC results (ADC1 and ADC2 only)  
● Direct CPU/DMA write operation  
Use the DATMPX[1:0] field of R32_DFSDM_CHyCFGR1 register to select whether to use serial or parallel data  
input for a given channel. DATMPX[1:0] also defines parallel data source: internal ADC or write operation  
directly by CPU/DMA.  
Each channel contains a 32-bit data input register (R32_DFSDM_CHyDATINR), in which 16 bits of data can be  
written. The data is in a 16-bit signed format. These data can also be used as the input of a digital filter that  
accepts 16-bit parallel data.  
If serial data input is selected (DATMPX[1:0]=0), the R32_DFSDM_CHyDATINR register is write-protected.  
<strong>Input from internal ADC (ADC1 and ADC2 only)</strong>  
For parallel ADC data inputs (DATMPX[1:0]=1), the ADC[y+1] result is assigned to channel y input (ADC1  
populates the R32_DFSDM_CH0DATINR register, ADC2 populates the R32_DFSDM_CH1DATINR register).  
The conversion complete event from ADC[y+1] triggers an update to channel y&#x27;s data (the parallel data from  
ADC[y+1] is used as the next sample for the digital filter). When the conversion complete event occurs, the data  
from ADC[y+1] is written to the R32_DFSDM_CHyDATINR register (the INDAT0[15:0] field).  
The data packing mode setting (DATPACK[1:0] in the R32_DFSDM_CHyCFGR1 register) has no effect on the  
ADC data input.  
<em>Note: ADC Extension Specification: When the internal ADC is configured in interleaved mode (e.g., ADC1</em>  
<em>interleaved with ADC2 - refer to ADC specification), each result from ADC1 or ADC2 is transmitted to the same</em>  
<em>16-bit bus (i.e., ADC1&#x27;s bus), which is connected to DFSDM Channel 0 (fixed connection). Therefore, DFSDM</em>  
<em>channel 0 will carry double the input data rate (even samples from ADC1, odd samples from ADC2). Channel 1,</em>  
<em>associated with ADC2, will remain idle.</em>
