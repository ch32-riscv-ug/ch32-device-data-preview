### 42.3.14 Continuous and Fast Continuous Mode

If RCONT in the R32_DFSDM_FLTxCR1 register is set to 1, normal conversion will be performed in continuous  
mode. RCONT=1 means that after writing 1 to RSWSTART, the channel selected by the RCH bit is repeatedly  
converted.  
Normal conversion performed in continuous mode can be stopped by writing 0 to RCONT. After the RCONT is  
cleared, the ongoing conversion will be stopped immediately.  
In continuous mode, the data rate can be increased by setting bit 1 of the FAST position in the  
R32_DFSDM_FLTxCR1 register. At this time, if a continuous conversion is performed on a channel, the filter  
does not need to be refilled with new refresh data because the internal filter data is valid. This data was previously  
obtained by sampling continuous data. The speed increase is related to the selected filter order. After initiating  
continuous conversion with RSWSTART=1, the initial conversion in Fast mode (FAST=1) is performed fully  
(identical to FAST=0), followed by subsequent conversions completed at shorter intervals.  
Conversion time in continuous mode:  
When FAST=0 (or fast transition when FAST=1):  
For Sincx filter:  
t=CNVCNT/fDFSDMCLK=[FOSR*（2IOSR+FORD+1）+2]/fCKIN  
For FastSinc filter:  
t=CNVCNT/fDFSDMCLK=[FOSR*（2IOSR+5）+2]/fCKIN  
When FAST=1 (except for the first conversion):  
For Sincx and FastSinc filter:  
t=CNVCNT/fDFSDMCLK=[FOSR*2IOSR]/fCKIN  
When FOSR=FOSR[9:0]+1=1 (filter bypass, only integrator is effective):  
t=2IOSR/fCKIN(...but CNVCNT=0)
