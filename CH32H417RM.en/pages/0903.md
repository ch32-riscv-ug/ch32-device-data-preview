### 40.6.6 Error Correction Code (ECC) Calculation (NAND Flash)

The FMC NAND card controller incorporates two error correction code (ECC) calculation hardware modules, one  
for each storage area. These modules reduce the host CPU workload during software-based ECC processing.  
Both ECC modules are identical and associated with storage areas 2 and 3, respectively. Consequently, hardware  
ECC calculations do not apply to memory connected to storage area 4.  
During read or write operations to NAND Flash, the ECC algorithm employed in the FMC corrects single-bit  
errors and detects double-bit errors for every 256, 512, 1024, 2048, 4096, or 8192 bytes. This operation is based  
on the Hamming code algorithm and includes the calculation of row and column parity.  
Whenever the NAND Flash storage area is active, the ECC module monitors the NAND Flash data bus and  
read/write signals (NCE and NWE).  
ECC operates as follows:  
● When accessing NAND Flash memory regions 2 or 3, it latches data appearing on the D[15:0] bus and uses it  
for ECC computation.  
● When accessing any other address in the NAND Flash, the ECC logic enters idle state and performs no  
operation. Therefore, write operations defining NAND Flash commands or addresses are invalid during ECC  
computation.  
After the host CPU completes the read/write operation for the required number of bytes to the NAND Flash, it  
must read the R32_FMC_ECCR register to retrieve the computed value. Following this read operation, these  
registers should be cleared by resetting the ECCEN bit to zero. To compute a new data block, the ECCEN bit in  
the FMC_PCR register must be set to 1.  
To perform ECC calculation:  
1) Enable the ECCEN bit in the R32_FMC_PCR register.  
2) Write data to the NAND Flash page. During NAND page write, the ECC module calculates the ECC value.  
3) Read the ECC value provided in the R32_FMC_ECCR register and store it in a variable.  
4) Clear and then enable the ECCEN bit in the R32_FMC_PCR register. Read back the written data from the  
NAND page. During the NAND page read operation, the ECC module will compute the ECC value.  
5) Read the new ECC value provided in the R32_FMC_ECCR register.  
6) If the two read ECC values match, no correction is needed. Otherwise, an ECC error exists, and the software  
correction routine will return information indicating whether the error can be corrected.
