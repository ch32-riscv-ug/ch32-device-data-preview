### 26.2.2 Device Register Description

In USB device mode, the USB OTG module provides eight sets of bidirectional endpoint configuration registers  
numbered 0 through 7. These can map configurations for endpoints numbered 8 through 15. Except for endpoint 3,  
all endpoints support a maximum packet length of 64 bytes. Endpoint 3 supports a maximum packet length of  
1023 bytes (synchronous transfers).  
● Endpoint 0 is the default endpoint that supports controlling transmission, transmitting and receiving sharing a  
64-byte data buffer.  
● Endpoints 1-15 support configurable independent 64-byte transmit and receive buffers or dual 64-byte data  
buffers, enabling lot transmission, interrupt transmission, and real-time/synchronous transmission.  
Each endpoint pair possesses a control register R8_UEPn_CTRL and a transmission length register
