### 14.3.12 Dead-time Asymmetry

Based on complementary output configuration and dead time control, configure the DT_VLU2 bit (with a value  
greater than 0 and less than the number of Tdtg bits set in the DTG[7:0] field of the TIMx_BDTR register) to  
select whether the dead time configured by DT_VLU2 occurs on the rising or falling edge of OCXREF by setting  
the DTP_MODE or DTN_MODE bit. This method achieves asymmetric dead time.  

### 14.3.13 Debug Mode

When the system enters debug mode, the timer continues to run or stops according to the settings of the DBG  
module.
