### 44.2.4 GPHA Foreground Layer and Background Layer Pixel Format Converter (PFC)

The GPHA Foreground and Background Layer Pixel Format Converter (PFC) performs pixel format conversion to  
generate 32-bit values per pixel. Additionally, the PFC possesses the capability to modify the alpha channel.  
This converter performs color format conversion in the first stage. The CM[3:0] bits of the  
R32_GPHA_FGPFCCR register and the CM[3:0] bits of the R32_GPHA_BGPFCCR register configure the raw  
color formats for foreground layer pixels and background layer pixels, respectively. The supported input color  
modes are listed in Table 44-1.

The Alpha channel is an extra channel used to represent the transparency of each pixel in the image. It is often  
used with red, green and blue (RGB) channels to form RGBA model.  
The following is a description of the encoding methods of color formats appearing in Table 44-1:  
Alpha value field: transparent, with 0xFF value corresponding to opaque pixels and 0x00 corresponding to  
transparent pixels;  
R field: Represents red;  
G field: Represents green;  
B field: Represents blue;  
L field: Represents luminance; this field serves as the CLUT index for retrieving 3 or 4 RGB/ARGB components.
