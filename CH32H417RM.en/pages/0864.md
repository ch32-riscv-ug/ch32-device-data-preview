## 40.5 NOR Flash/PSRAM Controller

The FMC generates appropriate signal timing to drive the following memory types:  
● Asynchronous SRAM and ROM: 8-bit, 16-bit, 32-bit;  
● PSRAM (Cellular RAM): Asynchronous mode, burst mode with synchronous access, multiplexed or  
non-multiplexed;  
● NOR Flash: Asynchronous mode, burst mode with synchronous access, multiplexed or non-multiplexed.  
The FMC outputs unique chip select signals NE[4:1] for each memory region. All other signals (address, data, and  
control) are shared. The FMC supports multiple devices through programmable timing, including:  
● Programmable continuous clock (FMC_CLK) output  
● Programmable wait cycles (up to 15 clock cycles)  
● Programmable bus turnaround cycles (up to 15 clock cycles)  
● Independent read and write timing and protocols to support various memory types and timing requirements  
● Programmable output enable and write enable delays (up to 15 clock cycles)  
To generate the FMC_CLK continuous clock, memory area 1 must also be configured to support synchronous  
mode (refer to Section 40.5.6: NOR/PSRAM Control Registers). Since all synchronous memory uses the same  
clock, the HB data size must match the memory data width (MWID) when generating continuous output clocks  
and performing synchronous accesses. Otherwise, the FMC_CLK frequency will vary based on the occurrence of  
HB data transactions (refer to Section 40.5.5: Synchronous Transactions for information on the FMC_CLK  
division ratio formula).  
Each memory region has a fixed size of 64MB. Each memory region is configured via dedicated registers (refer to  
Section 40.5.6: NOR/PSRAM Control Registers). Programmable memory parameters include access times (as  
shown in the table below) and support for wait management (used for burst mode access to NOR Flash and  
PSRAM).  
When reading data using the NOR Flash/PSRAM controller, only DMA 256-bit reads are permitted.
