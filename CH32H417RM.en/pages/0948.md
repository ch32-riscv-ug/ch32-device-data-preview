The right shift of the final data is performed in this module, because the final data width is 24 bits, and the data  
from the processing path can be up to 32 bits. For each selected input channel, this right shift can be configured in  
the range of 0-31 bits (refer to bits DTRBS[4:0] in R32_DFSDM_CHyCFGR2 register). Shift right rounds the  
result to the nearest integer value. The sign of the shifted result is preserved, so as to obtain the result data in a  
valid 24-bit signed format.  
Next, the results are offset corrected. Subtract the offset correction value (OFFSET[23:0] stored in register  
R32_DFSDM_CHyCFGR2) from the output data of a given channel. The data in the OFFSET[23:0] field is set by  
the software through the corresponding calibration program.  
Since all operations in digital processing are performed on 32-bit signed registers, the following conditions must  
be met to ensure that the results will not overflow:  
1) FOSRFORD.2IOSR≤231, suitable for Sincx filter (x=1..5);  
2) FOSR2.2IOSR≤231, suitable for FastSinc filter.  
<em>Note: When the filter and integrator are bypassed (IOSR[3:0]=0, FOSR[9:0]=0), the input data rate (fDATAIN_RATE)</em>  
<em>must be limited to be able to read all the output data: fDATAIN_RATE≤fHCLK; Among them, fHCLK is the bus frequency</em>  
<em>of DFSDM peripheral connection.</em>  

### 42.3.12 Signed Data Format

Each channel of the DFSDM input serial channel can be connected to an external ΣΔ modulator. An external ΣΔ  
modulator is configured with two differential inputs (positive and negative), which can be used for either  
differential measurements or single-ended signal measurements.  
It is always assumed that the ΣΔ modulator&#x27;s output uses a signed format (i.e., the 0/1 data stream from the ΣΔ  
modulator represents the values -1 and +1).  
Signed Data Format in Registers: Data stored in the final output data register, analog watchdog register, extreme  
value detector register, and offset correction register are all in signed format. The most significant bit (MSB) of  
the output data word indicates the sign of the value (using two&#x27;s complement format).
