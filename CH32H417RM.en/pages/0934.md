# Chapter 42 Digital Filter for ΣΔ Modulator (DFSDM)

DFSDM is a high-performance module dedicated to connecting external ΣΔ modulator to MCU. It contains two  
external digital serial interfaces and 2 digital filters, and has flexible ΣΔ digital processing options, which can  
provide the final resolution of ADC up to 24 bits. DFSDM can also select parallel data stream input from internal  
ADC peripherals or device memory.  

## 42.1 Main Features

● Provide 2 multiplexed digital serial input channels  
● 2 internal digital parallel channels supporting optional inputs  
● Support adjustable digital signal processing  
● Support up to 24-bit output data resolution  
● Support signed data formats  
● Support automatic data offset correction (offset value stored by user in register)  
● Include 2 conversion modes: single conversion mode and continuous conversion mode  
● Conversion initiation supported via software trigger, internal timer, external event, or synchronization with  
the first DFSDM filter  
● Supports analog watchdog  
● Built-in short-circuit detector to identify saturated analog input values (lower and upper limits)  
● Support open-circuit generation upon analog watchdog events and short-circuit monitoring events  
● Built-in extreme value detector  
● Support interrupts and DMA
