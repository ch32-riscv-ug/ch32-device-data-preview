### 4.5.1 HSEM Function Description


#### 4.5.1.1 Locking Mode

This module provides 2 locking modes:  
■ 2-step (write) lock  
■ 1-step (read) lock  
A value of 0 in the HSEM channel LOCK register indicates that the channel is idle, and the CID and PID values  
of this channel are also 0. When the channel LOCK register value is 1, it means that the channel is locked, the  
CID value is updated to the core ID of the locked channel, and the PID register value is the bus write value.  
When writing a locked channel, the CID is updated to the core ID of the locked channel, and the PID value is  
updated to write data. When reading the locked channel, the CID is updated to the core ID of the locked channel,  
and the PID value remains 0. Any PID value can be written when writing lock.  
<strong>2-step (write) lock process</strong>  
The 2-step lock process locks the channel by writing the lock information to the HSEM_RX register, and then  
checks whether the lock is successful by reading the same data as the write data.  
● Write the PID to the HSEM_RX register with LOCK = 1. If the channel is idle, locking succeeds, and the  
PID, CID, and LOCK values are updated.  
● Perform a read data check: the read PID matches the written PID, the CID matches the core ID, and a LOCK  
value of 1 indicates a successful operation.  
● Otherwise, repeat the above steps.  
The HSEM channel can only be locked when idle.  
Attempting to lock an already locked channel will have no effect.  
<strong>1-step (read) lock process</strong>  
The 1-step lock process checks for successful locking by reading the HSEM_RLRX register and comparing the  
returned value.  
● Read the HSEM_RLRX register to obtain the return value.  
● If the read data is 0, the lock was successful; if non-zero, the lock failed, indicating the channel is already  
locked by another process. For successfully locked channels, the HSEM_RLRX register updates to LOCK =  
1, CID = the core ID performing the operation, and PID = 0.  
● Otherwise, repeat the above operation.
