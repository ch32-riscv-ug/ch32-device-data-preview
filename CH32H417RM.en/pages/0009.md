### 1.2.1 Memory Allocation

Built-in SRAM with a total capacity of 896K bytes, partially allocated for the data area and partially for the  
zero-wait code area. Data is lost upon power loss. This SRAM is divided into 3 blocks: a 128KB ITCM core 1  
tightly coupled zero-wait code area, a 256KB DTCM core 1 tightly coupled zero-wait data area, and the  
remaining 512KB shared code and data area. Additionally, core 1 features a 32KB high-speed instruction cache.  
The 512KB shared area can be configured as the zero-wait code and data regions for RISC-V3F. It is  
recommended to allocate this space flexibly in 128KB increments as needed.  
As an option, both the 128KB ITCM and 256KB DTCM can be configured as the RISC-V5F code segment,  
totaling 384KB. When the DTCM is used as the code segment, it introduces an additional clock wait during  
jumps.  
RISC-V3F can access ITCM or DTCM with 2 HCLK clock cycles.  
RISC-V5F and RISC-V3F can access the 512KB shared region with zero HCLK clock cycles.  
Built-in 256-byte system non-volatile configuration information storage area for vendor configuration word  
storage, fixed at factory and non-modifiable by users.  
Built-in 256-byte user-defined information storage area for user selection word storage.  
The sizes of the user area and BOOT area are read via the DBMODE bit in the R32_FLASH_CFGR0 register:  
When DBMODE=1, the chip incorporates a 960K-byte non-zero-wait program flash memory area (Code FLASH),  
i.e., the user area, for storing user applications and constant data, with an equivalent frequency of approximately  
25MHz. It also incorporates a maximum of 56K bytes of system memory area (System FLASH), i.e., the BOOT  
area, for storing the system bootloader and the built-in bootstrap loader.  
When DBMODE=0, the chip incorporates a 480K-byte non-zero-wait program flash memory area (Code FLASH),  
serving as the user area for storing user applications and constant data, with an equivalent frequency of  
approximately 12.5MHz. It also includes a maximum 28K-byte system memory area (System FLASH),  
functioning as the BOOT area for storing the system bootloader, with an integrated bootstrap loader.  
For information on using the chip&#x27;s BOOT function and related precautions, please refer to the CH32H417  
<em>Evaluation Board Reference.</em>
