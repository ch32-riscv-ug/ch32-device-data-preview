#### 36.3.4.2 Frame Length

<strong>Master mode</strong>  
Setting the FRL[7:0] field of the R32_SAI_xFRCR register to 1 configures the audio frame length to a maximum  
of 256 bit clock cycles.  
If the frame length exceeds the number of slots declared for that frame, the remaining bits to be transmitted will  
be zero-padded or the SD line will be released to a high configuration, depending on the state of the TRIS bit in  
the R32_SAI_xCFGR2 register. In receive mode, the remaining bits are ignored.  
If the NODIV bit is cleared, (FRL+1) must equal a power of 2 (from 8 to 256) to ensure each bit clock cycle of the  
audio frame contains an integer number of MCLK pulses. If the NODIV bit is set to 1, the (FRL+1) field can take  
any value from 8 to 256.  
<strong>Slave mode</strong>  
The audio frame length is primarily used to specify the number of bit clock cycles for each audio frame  
transmitted from the external master module to the slave module. It is mainly employed to detect frame  
synchronization signals that occur ahead of schedule or behind schedule during audio frame transmission from the  
master module. Errors occur in such cases.  
In slave mode, the configuration of the FRL[7:0] bits in the R32_SAI_xFRCR register is unrestricted.  

#### 36.3.4.3 Frame Synchronization Polarity

Set the effective polarity of the FS pin through the FSPOL bit in R32_SAI_xFRCR register, and start the frame  
through this polarity. SOF signal is sensitive to edge.  
In the slave mode, the audio module is in a waiting state until a valid frame signal is received to perform the  
sending or receiving operation, and the SOF signal is synchronized with the frame signal. The frame  
synchronization polarity is valid only when the SOF signal is not detected during communication and the SOF  
signal is consistent with the expected SOF signal.  
In the main mode, every time an audio frame is completed, a frame synchronization signal is sent until the SAIEN  
bit in the R32_SAI_xCTLR1 register is cleared. If there is no data in the FIFO at the end of the previous audio  
frame, the underflow will be handled as described in section 36.3.12.1, but the audio communication flow will not  
be interrupted.  

#### 36.3.4.4 Frame Synchronization Effective Level Length

The FSALL[6:0] bits of the R32_SAI_xFRCR register configure the length of the active level for the frame sync  
signal. This length can be set to between 1 and 128 bit clock cycles.  
In I2S, LSB, or MSB alignment modes, the active length is set to half the frame length; in PCM/DSP or TDM  
modes, the active length is set to 1 bit.
