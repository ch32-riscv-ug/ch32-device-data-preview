# Chapter 34 Programmable Protocol I/O Microcontroller (PIOC)

A programmable protocol I/O microcontroller is embedded in the chip. The microcontroller is based on the RISC  
core with a single clock cycle, runs at the main frequency of the system, has a program ROM with 2K instructions,  
49 SFR registers and PWM timers/counters, and supports the protocol control of two I/O pins.  

## 34.1 Main Features

● RISC core, optimized single cycle bit manipulation instruction set, fully static design.  
● Multiplex 4K bytes of system SRAM as 2K capacity program ROM, supports program pause and dynamic  
loading.  
● Provide 33 bytes of 1 register each in bidirectional and unidirectional mode, providing 6 levels of  
independent stacking.  
● Support 2 general-purpose bi-directional I/O protocol controls and input level change detection.  
● Support 1- and 2-wire interfaces with multiple protocol specifications by dynamically loading different  
protocol programs.  
● Support 1-wire ARGB chip 1024-stage series connection  

## 34.2 Instruction, Program Space and Stack


### 34.2.1 Instruction Set

eMCU adopts RISC8B core with reduced instruction set, with data width of 8 bits and instruction width of 16 bits.  
There are 66 instructions, all of which are single clock cycles, except that the jump instruction is double clock  
cycle and the program space reading and writing instruction is double cycle. For more information, please refer to  
RISC8B core instruction set and assembly tool document CHRISC8B.PDF.  

### 34.2.2 Program ROM

EMCU&#x27;s program ROM comes from 4-kbyte system SRAM multiplexing. When SB_MST_CLK_GATE is 0, it is  
dedicated to the system SRAM on the host side, and when SB_MST_CLK_GATE is 1, it is dedicated to eMCU&#x27;s  
program ROM.  
The program space of eMCU is 2048 words, and the address of the program space ranges from 0x0000 to 0x07FF.  
The instruction at address 0 in the program ROM has a special purpose and will not be executed.  
eMCU chip supports reading program space. The steps are as follows: first, write the lower 8 bits of the target  
address into SFR_INDIR_ADDR, and the upper 3 bits of the target address into the A register, and then execute  
the RDCODE instruction, so that the 16-bit data in the program space can be read out at one time, which is  
divided into high and low bytes, with the low byte returned to the A register and the high byte returned to the  
SFR_INDIR_ADDR. This operation can be used for double-byte table lookup.  
eMCU chip does not support writing to program space.  

### 34.2.3 Stack

The eMCU features a stack memory with a depth of 6 levels and an 11-bit data width. It is used to store the  
program return address during subroutine calls and can also be employed with the PUSHAS instruction to save  
variables, status data, and other information from the running program onto the stack.
