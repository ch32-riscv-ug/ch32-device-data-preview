● Write unlock:  
Write the PID to the HSEM_RX register corresponding to the locked HSEM channel with LOCK=0. If this  
channel is locked by the current core, writing a PID equal to the channel&#x27;s PID unlocks the channel, clearing PID,  
CID, and LOCK. When the channel interrupt is enabled, an interrupt request may be generated.  
● Match unlock:  
Write a key value to the HSEM_CLR register to configure matching rules. Channels matching the rules can be  
unlocked in lot. When the channel interrupt is enabled, an interrupt request can be generated.  

#### 4.5.1.2 HSEM Interrupt

When the HSEM channel is unlocked, an interrupt can be generated. The interrupt of HSEM has the following  
characteristics:  
● Each HSEM channel can be enabled independently.  
● Each HSEM channel has an independent interrupt flag.  
● The interrupt flag of each HSEM channel can be cleared separately.  
● Each core has independent interrupt enable, interrupt flag and clear bit.  
When the channel interrupt is enabled (HSEM_IER), an interrupt request can be generated when the channel is  
unlocked by other cores, and the corresponding channel interrupt flag register (HSEM_ISR) is set to 1.  
Write a 1 to the corresponding bit of the channel interrupt flag (HSEM_ISR) to clear the interrupt flag.  
The channel interrupt mask register (HSEM_ISM) can be used to obtain the source channel that generates the  
interrupt, and the channel with the channel interrupt enabled and the interrupt flag set to 1 can generate the  
interrupt request, and the corresponding HSEM_ISM bit value is 1.
