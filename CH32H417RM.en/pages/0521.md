# Chapter 26 USB Full-speed Host/Device Controller (USBFS/OTG_FS)


## 26.1 USB Controller Introduction

USB 2.0 Full-Speed Host Controller and Device Controller (USBFS) conforms to the USB 2.0 Full-Speed  
standard. It provides 16 configurable USB device endpoints and a set of host endpoints. Supports  
control/bulk/synchronous/interrupt transfers, dual-buffer mechanism, USB bus suspend/resume operations, and  
offers standby/wake-up functionality.  
OTG_FS is a dual-role USB controller supporting both host and device functionality, compliant with the  
On-The-Go Supplement to the USB 2.0 specification. Additionally, this controller can be configured as a  
host-only or device-only controller, compliant with the USB 2.0 Full-Speed specification.  
The characteristics are as follows:  
● Support the USB On-The-Go Supplement, Revision 1.3 specification, defined as an optional feature in the  
OTG_FS controller&#x27;s physical layer  
● Software-configurable as USB full-speed host, USB full-speed/low-speed device, or USB dual-role device  
● Provide power-saving functionality  
● Support control transfer, lot transfer, interrupt transmission and synchronous/real-time transmission.  
● Provide bus reset, suspend, wake-up and recovery functions.  
● Support packets up to 64 bytes, built-in FIFO, interrupt and DMA.  

## 26.2 Register Description

The USB registers are divided into 3 parts, and some registers are multiplexed in the host and device modes.  
● USB global registers  
● USB device control registers  
● USB host control registers
