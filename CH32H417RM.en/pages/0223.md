# Chapter 12 High-speed Analog/Digital Conversion (HSADC)

The chip incorporates a single 10-bit high-speed analog/digital converter (HSADC) that provides seven external  
channel sampling capabilities. With a sampling rate of up to 20Msps, it enables continuous conversion and  
supports DMA operations.  

## 12.1 Functional Description

● Support sampling from 7 external channels  
● Support receive FIFO  
● Support burst mode  
● Support DMA functionality  
● Support ping-pong mode  
● Support continuous conversion mode  
● Provide multiple transfer interrupt flags and status  
● Provides 1 interrupt vector  

## 12.2 Functional Description


### 12.2.1 HSADC Module Power-up

The EN bit in the R32_HSADC_CFGR register set to 1 indicates the ADC module is powered on. When the ADC  
module transitions from power-down mode (EN=0) to power-up state (EN=1), a delay period tSTAB is required  
for module stabilization. Subsequently, writing a value of 1 to the START bit serves as the software trigger signal  
to initiate an ADC conversion. Clearing the EN bit to 0 terminates the current conversion and places the ADC  
module into power-down mode, where it consumes negligible power.  

### 12.2.2 HSADC Clock

The HSADC clock source can be derived from the system clock (SYSCLK), PLL clock, USBHS_PLL clock, or  
ETH_PLL clock. It can be selected via the HSADCSRC[1:0] bits in the RCC_CFGR2 register. Additionally, the  
HSADC clock can be divided using the CLKDIV[5:0] bits in the R32_HSADC_CFGR register.  
The total conversion time for the sampling cycle is calculated as follows:  
TCONV= Sampling time + 4THSADCCLK;  
The sampling time is fixed at 1THSADCCLK.  

### 12.2.3 HSADC Channel Configuration

The HSADC module provides 7 external channel sampling sources.  

### 12.2.4 HSADC DMA Function

The HSADC channel conversion supports DMA functionality. The channel conversion value is stored in a single  
data register, R32_HSADC_DATAR. Failing to retrieve data from the R32_HSADC_DATAR register in a timely  
manner enables the ADC&#x27;s DMA capability (if ping-pong transfer is not enabled, only DMA0 can be configured).
