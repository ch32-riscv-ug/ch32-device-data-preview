<strong>Single burst transmission</strong>  
When the selected storage area is configured in synchronous burst mode, for example, if an HB single burst  
transaction is requested from a 16-bit memory, FMC will execute a burst transaction with a length of 1 (if the HB  
transmission is 16 bits) or a burst transaction with a length of 2 (if the HB transmission is 32 bits), and then  
disable the chip selection signal at the last data strobe.  
Compared with asynchronous read operation, this is not the most efficient transmission method in terms of cycle.  
However, random asynchronous reading requires reprogramming the memory access mode first, so the total time  
will be longer.  
<strong>Cross the border page of Cellular RAM1.5</strong>  
Cellular RAM1.5 does not allow burst access to cross page boundaries. When the CPSIZE bit in the  
R32_FMC_BCR1 register is configured according to the memory page size to reach the memory page size, the  
FMC controller will automatically separate the burst access.  
<strong>Waiting management</strong>  
For synchronous NOR Flash, NWAIT will be evaluated after the configured delay period (equivalent to  
(DATLAT+2) CLK clock cycles).  
If NWAIT is valid (low level when WAITPOL=0 and high level when WAITPOL=1), the waiting state will be  
inserted until NWAIT is invalid (high level when WAITPOL=0 and low level when WAITPOL=1).  
When NWAIT is invalid, the data will be considered valid immediately (bit WAITCFG=1) or at the next clock  
edge (bit WAITCFG=0).  
During the waiting period when the NWAIT signal is inserted, the controller will continue to send clock pulses to  
the memory to keep the chip select and output enable signals valid. But the data is not considered valid.  
In burst mode, NOR Flash NWAIT signal has two timing configurations:  
● Flash sends out NWAIT signal (the default value after reset) one data period before the waiting period.  
● Flash sends out NWAIT signal during the waiting period.  
FMC supports these 2 configurations of NOR Flash waiting period, and each chip selection is configured through  
the WAITCFG bit (x=0..3) pin of R32_FMC_BCRx register.
