● Receive interrupt and transmit interrupt are independently enabled, with configurable interrupt cores.  
● 4 sets of inter-core information registers.  

### 4.4.1 IPC Function Description

This module provides 2 types of interrupts:  
■ Receiving end interrupt  
■ Transmitting end interrupt  
IPC channel interrupts are jointly controlled by the interrupt enable bits (RX_IERx/TX_IERx), status enable bits  
(IPC_ENAx[7:0]), and status bits (IPC_STSx[7:0]).  
<strong>Receive interrupt</strong>  
When the status bit value is 1, the corresponding status enable bit value is 1, and the corresponding bit value in the  
IPC_ISR register is 1. If the channel receive interrupt enable is active (RX_IERx = 1), an interrupt request can be  
generated to the RX_CID core configured for the channel, and the corresponding bit value in the IPC_ISM  
register is 1.  
<strong>Transmit interrupt</strong>  
When the status bit value is 0, the corresponding status enable bit value is 1, and the corresponding bit value in the  
IPC_ISR register is 1. If the channel transmit interrupt is enabled (TX_IERx = 1), an interrupt request can be  
generated to the TX_CID core configured for the channel, and the corresponding bit value in the IPC_ISM  
register is 1.  
When the AUTOENx bit is configured for automatic updating, writing/setting the IPC_STS register at the transmit  
end simultaneously updates the IPC_ENA register to the same value. If the channel receive interrupt is enabled, a  
receive interrupt can be immediately generated at the receive end. Clearing the IPC_STS flag after completing the  
reception interrupt response does not affect the IPC_ENA register. If the channel transmission interrupt is active, a  
transmission interrupt can be immediately generated for the transmitter. The transmitter disables the IPC_ENA  
enable within the interrupt and clears the transmitter interrupt flag.  
When the AUTOENx bit is configured for non-auto-update, the sequence of first writing the status enable bit  
followed by writing the IPC_STS may introduce additional transmitter interrupts.
