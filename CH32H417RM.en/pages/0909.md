### 40.7.3 SDRAM Controller Function Description

All SDRAM controller outputs (signal, address and data) can be configured to change on the falling edge of the  
memory clock (FMC_SDCLK).  
<strong>SDRAM initialization</strong>  
The initialization sequence is managed by software. If 2 memory regions are used, the target memory region bits  
CTB1 and CTB2 in the R32_FMC_SDCMR register must be set to 1, and the initialization sequences for memory  
region 1 and memory region 2 must be generated at the same time:  
1) Program the memory device characteristics into the R32_FMC_SDCRx registers. The SDRAM clock  
frequency, RBURST, and RPIPE characteristics must be programmed into the R32_FMC_SDCR1 register.  
2) Program the memory device timing into the R32_FMC_SDTRx registers. TRP and TRC timing must be  
programmed into the R32_FMC_SDTR1 register.  
3) Set MODE[2:0] in the R32_FMC_SDCMR register to “001” and configure the target memory region bits  
(CTB1 and/or CTB2) in the R32_FMC_SDCMR register to begin clocking the memory (SDCKE driven high).  
4) Wait for the specified delay cycle. Typical delay is 100μs.  
5) Set MODE[2:0] in the R32_FMC_SDCMR register to “010” and configure the target memory area bits (CTB1  
and/or CTB2) in the R32_FMC_SDCMR register to send the “Full Precharge” command.  
6) Set MODE[2:0] in the R32_FMC_SDCMR register to “011” and configure the target storage area (CTB1  
and/or CTB2) and the number of Non-Repeatable Automatic Refresh (NRFS) commands in the  
R32_FMC_SDCMR register.  
7) Configure the MRD field according to the SDRAM device. Set MODE[2:0] in the R32_FMC_SDCMR register  
to “100” and configure the target storage area bits (CTB1 and/or CTB2) in the R32_FMC_SDCMR register to  
send the “Load Mode Register” command and program the SDRAM device. Specifically:  
- a) The CAS delay must be selected based on the value in R32_FMC_SDCR1/2;
- b) The burst length (BL) must be set to 1 by configuring the MRD[2:0] bits in the R32_FMC_SDCMR register to
000.  
If the mode registers for the two SDRAM storage regions differ, this step must be repeated twice—once for each  
storage region—with the corresponding target storage region bit set to 1.  
8) Program the refresh rate in the R32_FMC_SDRTR register. The refresh rate corresponds to the delay between  
refresh cycles. Its value must be compatible with the SDRAM device.
