In SPDIF mode, underflow is the only error flag used in R32_SAI_xSR register. Since SAI can only work in the  
send mode, to recover from the underflow error detected by the underflow interrupt or underflow status bit, the  
following steps should be performed in sequence:  
1) If DMA is already in use, disable the DMA stream via the DMA peripheral.  
2) Disable SAI operation and verify physical disablement by polling the SAIEN bit in the R32_SAI_xCFGR1  
register.  
3) Clear the flag by writing a 1 to the OVRUDR bit in the R32_SAI_xSR register.  
4) Flush the FIFO by setting the FFLUSH bit to 1 in the R32_SAI_xCFGR2 register. The software must point to  
the subsequent data address corresponding to the start of the new data block (data in header B). If DMA is in use,  
update the DMA source start address pointer accordingly.  
5) Re-enable the DMA stream if the DMA controller resumes data transfer based on the new source start address  
pointer.  
6) Re-enable the SAI by setting the SAIEN bit in the R32_SAI_xCFGR1 register to 1.

### 36.3.9 Stereo/Mono

In transmit mode, if the number of slots equals 2 (with the NBSLOT[3:0] bits of the R32_SAI_xSLOTR register  
set to 0001b), mono mode can be addressed without any data preprocessing in memory. In this case, since the data  
from Slot 0 is copied to data Slot 1 during transmission, the FIFO access time is reduced by half.  
To enable mono mode, the following steps are required:  
1) Set the MONO bit in the R32_SAI_xCFGR1 register to 1;  
2) Set the NBSLOT bit in the R32_SAI_xSLOTR register to 1 and configure the SLOTEN bit to 3.
