### 18.2.2 DAC Channel Configuration


#### 18.2.2.1 Enable DAC:

Set the ENx bit in the DAC_CTLR register to 1, to enable the analog power to DAC channel x. After a period of  
start-up time, DAC channel x can be enabled. The DAC contains 2 analog output channels which can output  
independently or simultaneously.  
<em>Note: In order to avoid parasitic interference and additional power consumption, the corresponding pins of the</em>  
<em>DAC channel need to be set to analog input (AIN) mode in advance.</em>
