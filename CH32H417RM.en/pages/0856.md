# Chapter 40 Flexible Memory Controller (FMC)

<em>This chapter&#x27;s module description applies only to the CH32H417 microcontroller product.</em>  
The Flexible Memory Controller (FMC) is a controller for managing external memory, comprising: NAND  
memory controller, NOR/PSRAM memory controller, and synchronous DRAM (SDRAM/Mobile LPSDR  
SDRAM) controller.  

## 40.1 Main Features

The FMC manages expanded connectivity to different types of memory, including: SDRAM, NAND Flash, and  
synchronous/asynchronous static memory. Its primary purposes are: meeting the access time requirements of  
external memory devices; and translating HB data communication transactions into appropriate external device  
protocols.  
All external memories share address, data, and control signals, but each possesses an independent chip select  
signal. The FMC can access only one external device at a time.  
The main features of FMC controllers are as follows:  
● Connect static memory mapped devices:  
- Static Random Access Memory (SRAM)
- PSRAM (4 memory regions)
- NOR Flash/OneNAND Flash
- NAND Flash memory with hardware ECC capable of verifying up to 8KB of data
● Connect to synchronous DRAM (SDRAM/Mobile LPSDR SDRAM) memory  
● External asynchronous wait control  
● 16×32-bit depth write FIFO  
● Each memory region configurable independently  
● Independent chip select control for each memory region  
● Support 8-bit, 16-bit, or 32-bit wide memory data buses  
● Programmable continuous clock output for asynchronous and synchronous access  
● SDRAM controller features a cacheable 6×32-bit depth read FIFO (6×14-bit address tag)  
● Write enable and byte channel select outputs compatible with PSRAM, SRAM, and SDRAM devices  
● Support burst mode for accelerated access to synchronous devices (e.g., NOR Flash, PSRAM, and SDRAM)
