–Through polling mode (R32_I3C_INTENR register TXFNFIE=0): Wait for the hardware to request the next  
data byte/word (R32_I3C_INTENR register TXFNFF=1) before explicitly writing to R32_I3C_TDR or

- Via enabled interrupt notification (if TXFNFIE=1)
● Preloaded by the allocated DMA channel (TXDMAEN=1) to enable the corresponding I3C peripheral DMA  
request (i3c_tx_dma):  
–According to the configuration of DMA module level, DMA will automatically push/write data bytes/words  
from its memory source buffer into R32_I3C_TDR or R32_I3C_TDWR register (depending on TXTHRES) until  
the transmission is completed (R32_I3C_EVR register FCF=1), except in case of transmission error.  
Then, when the remaining data in TGTTDCNT[15:0] of R32_I3C_TGTTDR register is to be loaded into the  
TX-FIFO to continue private read transmission (PRELOAD is set to 1 and TGTTDCNT[15:0]&gt;TX-FIFO size), if  
the master device has not completed private read transmission, it will be preloaded in the same way (directly  
through software or through the allocated DMA channel).  
– If TXTHRES=0: When one byte is transmitted on the I3C bus, the next byte is preloaded into the TX-FIFO.  
– If TXTHRES=1: When four bytes are transmitted on the I3C bus, the next byte is preloaded into the TX-FIFO.  
When the slave device or the master device terminates the data byte transmission first, the private read  
transmission is completed (FCF=1 in the R32_I3C_EVR register). After the transmission is completed, the  
software can:  
● Read XDCNT[15:0] in the R32_I3C_STATR register: Number of valid data bytes transmitted  
● Read TGTTDCNT[15:0] in the R32_I3C_TGTTDR register: Number of bytes remaining to be loaded and  
transmitted on the I3C bus  
● Clear TX-FIFO: Whether to set TXFLUSH in the R32_I3C_CFGR register to 1 via a write operation and  
proceed with another private read transfer depends on the user application.  
If the TX-FIFO is empty and a data byte must be transmitted on the I3C bus, a TX-FIFO underflow is reported  
(R32_I3C_EVR register ERRF=1 and R32_I3C_STATER register DOVR=1). If the corresponding interrupt is  
enabled (R32_I3C_EVR register ERRIE=1), an interrupt is generated.  
Configuration managed by the TX-FIFO can be modified when the I3C peripheral is not active.  
<strong>If the number of bytes is less than the TX-FIFO size, you can choose not to use R32_I3C_TGTTDR.</strong>  
In addition to using the R32_I3C_TGTTDR register, as shown in Figure 22-20, when DMA is disabled  
(TDMAEN=0), if the number of data bytes to be read from the I3C bus is less than the TX-FIFO size, the  
software can prepare and fill the TX-FIFO directly with the number of bytes read by writing to R32_I3C_TDR or  
R32_I3C_TDWR consecutively (depending on TXTHRES).
