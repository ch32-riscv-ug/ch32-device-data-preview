<strong>Start the frame transmission initiated by the master device</strong>  
When the master device is in the enabled state (the EN bit in R32_I3C_CFGR register is 1), the software can start  
frame transmission by any of the following configuration methods:  
1. Software trigger: set the TSFSET bit of R32_I3C_CFGR register to 1 by performing a write operation;  
This operation will cause the hardware to set the CFNFF flag in the R32_I3C_EVR register to request writing  
the first control word to the R32_I3C_CTLR register.  
2. No trigger: directly write the first control word to R32_I3C_CTLR register through software.  
Regardless of the initialization method used, the I3C peripheral subsequently transitions to operational status.  
When the control word is not the final message in an I3C frame (i.e., the MEND bit in the R32_I3C_CTLR  
register is not set) and no transmission errors have occurred (i.e., the ERRF bit in the R32_I3C_EVR register is  
not set), the hardware will continue to request the next control word and proceed with frame transmission:  
1) If the C-FIFO is in non-DMA mode (CDMAEN bit in the R32_I3C_CFGR register is 0), the software will  
write the next control word after the CFNFF flag in the R32_I3C_EVR register is set or the corresponding  
interrupt is triggered (CFNFIE bit in the R32_I3C_INTENR register is 1);  
2) If the C-FIFO is in DMA mode (CDMAEN bit in the R32_I3C_CFGR register is set to 1), the corresponding  
I3C DMA request will be automatically processed by the assigned DMA channel, and the next control word will  
be written.  
<strong>Initiate and receive transmissions initiated from devices</strong>  
When the master device is in the enabled state (the EN bit in the R32_I3C_CFGR register is 1), the master device  
can initiate the transmission, and the slave device can also initiate the transmission by issuing a start request  
(driving SDA to a low level), but only if the master device has allowed the hot join request, IBI request or master  
role request through the R32_I3C_DEVR0 register.
