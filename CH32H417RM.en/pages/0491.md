# Chapter 24 USB PD Controller (USBPD)


## 24.1 USB PD Controller Introduction

The chip has built-in USB Power Delivery controller and PD transceiver PHY, supports USB Type-C master-slave  
detection, automatic BMC codec and CRC, hardware edge control.  
Supports USB PD 2.0, PD 3.0, and PD 3.2 Power Delivery control, supports SPR and EPR, supports 100W or  
240W fast charging, supports PD sink and PD source applications, and DRP applications. Supports PDUSB,  
supports UFP and DFP, and DRD applications.  
Supports PD packets including SOP, SOP&#x27;, and SOP&quot;, supports USB PD reset signal frame hardware reset,  
supports a maximum packet length of 510 bytes, and supports DMA.
