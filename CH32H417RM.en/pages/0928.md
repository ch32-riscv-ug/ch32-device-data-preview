● Initial counter value: When using CTR mode for encryption/decryption, an initial counter value is required.  
Set the 128-bit counter value in the CTR mode counter register group R32_ECDC_IV. Each successful  
completion of a data encryption/decryption cycle (128-bit data) increments the internal counter value by 1.  
This counter value is not needed in ECB mode.  

### 41.4.2 Encryption and Decryption Configuration

The encryption and decryption data flow of the module includes two ways: memory to memory and one-time  
encryption and decryption of 128-bit data. Please refer to the configuration in Table 41-1 for details.
