## 42.4 Interrupt

In order to enhance the performance of central processing unit (CPU), a set of interrupts related to CPU events  
have been implemented:  
● Injection conversion end interrupt:  
- Enabled via the JEOCIE bit in the R32_DFSDM_FLTxCR2 register
- Indicated via the JEOCF bit in the R32_DFSDM_FLTxISR register
- Cleared by reading the R32_DFSDM_FLTxJDATAR register (injection data)
- Indicates which channel completed conversion and reports it in the JDATACH bit of the
R32_DFSDM_FLTxJDATAR register  
● Regular conversion end interrupt:  
- Enabled via the REOCIE bit in the R32_DFSDM_FLTxCR2 register
- Indicated via the REOCF bit in the R32_DFSDM_FLTxISR register
- Cleared by reading the R32_DFSDM_FLTxRDATAR register (regular data)
- Indicates which channel completed conversion and reports it in the RDATACH bit of the
R32_DFSDM_FLTxRDATAR register  
● Injection conversion data overflow interrupt:  
- This interrupt occurs when injected conversion data is not read from the R32_DFSDM_FLTxJDATAR
register (via CPU or DMA) and is overwritten by newly injected conversion data.  
- Enabled via the JOVRIE bit in the R32_DFSDM_FLTxCR2 register
- Indicated via the JOVRF bit in the R32_DFSDM_FLTxISR register
- Cleared by writing a 1 to the CLRJOVRF bit in the R32_DFSDM_FLTxICR register
● Regular conversion data overflow interrupt:  
- This interrupt occurs when conventional conversion data is not read from the
R32_DFSDM_FLTxRDATAR register (via CPU or DMA) and is overwritten by a new conventional  
conversion.  
- Enabled via the ROVRIE bit in the R32_DFSDM_FLTxCR2 register
- Indicated via the ROVRF bit in the R32_DFSDM_FLTxISR register
- Cleared by writing a 1 to the CLRROVRF bit in the R32_DFSDM_FLTxICR register
● Analog watchdog interrupt:  
- This interrupt occurs when converted data (output data or data from the analog watchdog
filter—depending on the setting of the AWFSEL bit in the R32_DFSDM_FLTxCR1 register) exceeds  
the upper threshold in the R32_DFSDM_FLTxAWHTR/R32_DFSDM_FLTxAWLTR register or falls  
below the corresponding lower threshold.  
- Enabled via the AWDIE bit in the R32_DFSDM_FLTxCR2 register (for the selected channel
AWDCH[1:0])  
- Indicated by the AWDF bit in the R32_DFSDM_FLTxISR register
