The memory types of V5F are divided into 2 categories:  
<strong>● Normal</strong>  
CPU&#x27;s access to this kind of memory will be reordered to improve performance.  
<strong>● Device and Strongly-ordered</strong>  
CPU access to this type of memory will be strictly executed in program order.

In the out-of-order core, the actual memory access sequence is not always the same as that in the program. In  
order to improve the access efficiency, the core will adopt reordering, buffer and multi-bus interface to speed up  
the access speed without violating the data correlation.  
For 2 unrelated memory access instructions A1 and A2 in the program, assuming that the A1 instruction sequence  
is earlier than A2 instruction and there is no instruction/data synchronization instruction between them, the actual  
request sequence of A1/A2 depends on the memory type (Normal, Device) accessed by A1/A2 and its instruction  
type (Load, Store). Possible situations as shown in Table 4-3.
