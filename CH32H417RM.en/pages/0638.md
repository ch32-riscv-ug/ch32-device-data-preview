# Chapter 31 Ethernet Transceiver (ETH)

<em>This chapter&#x27;s module description applies only to the CH32H417 microcontroller product.</em>  
The &quot;Ethernet transceiver&quot; mentioned in this chapter is a proper term, which means the Ethernet (Ethernet) data  
link layer transceiver inside the microcontroller, the communication rate is up to gigabit per second (1Gbps), it is a  
communication peripheral. The &quot;MAC&quot; mentioned in this chapter refers to the role name of the Ethernet  
transceiver at the data link layer and is a component of the Ethernet transceiver.  
Ethernet transceiver (Ethernet Transceiver MAC) is an important high-speed communication component of  
microcontroller, which allows microcontroller to access Ethernet at Gigabit connection speed to achieve extremely  
fast data communication.  

## 31.1 Main Features

The Ethernet transceiver in a microcontroller is a critical high-speed communication peripheral. It integrates a  
Gigabit MAC (Media Access Controller), a 256-bit-wide DMA controller, a Management Counter (MMC), a  
Precision Time Protocol (PTP) controller, and a 10/100 Mbps Ethernet Physical Layer (10M/100M PHY). When  
paired with an external Gigabit Ethernet PHY, it enables Gigabit Ethernet (1Gbps) data transmission. Operating at  
the data link layer, the Ethernet transceiver requires software implementation of the TCP/IP protocol stack and  
interfaces. The Ethernet transceiver supports a standard RGMII interface for connecting to the PHY. If users  
require gigabit access speeds, they must use the RGMII interface.Ethernet MAC controls PHY through SMI  
interface, and the timing of the interface is automatically realized by MAC, without the need for users to generate  
it through software. The RGMII interface supports the phase inversion of the transmission clock and the relative  
data delay, with a maximum delay of 4 nanoseconds.  
Ethernet MAC supports Ethernet of standard IEEE802.3 protocol, magic frame and specific wake-up frame. The  
DMA controller matched with Ethernet transceiver manages data receiving and dispatching and carries memory in  
the form of descriptors. The number of descriptors is determined by the user according to the communication  
density. The DMA controller can write the received data into the memory space specified by descriptors or  
retrieve the data to be sent at a speed of 32 bits. In addition, the MAC of Ethernet transceiver also supports  
IEEE1588 precise time protocol.  

### 31.1.1 MAC Features

● Support RGMII interface  
● RGMII supports transmit clock delay and inversion  
● Support full-duplex and half-duplex, support 10M/100M/1000Mbps data transfer rate  
● Support automatic insertion of frame header sequence and SFD  
● Support automatic insertion and check CRC  
● Support automatic calculation and verification of the checksum of IP/ICMP/TCP/UDP protocol packets  
● Support sending frame length control  
● Support sending gap adjustment  
● Support VLAN frame
