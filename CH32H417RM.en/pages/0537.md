#### 26.2.3.2 USB Host Endpoint Mode Control Register (R8_UH_EP_MOD)

The host transmit endpoint data buffer mode is controlled by the combination of RB_UH_EP_TX_EN and  
RB_UH_EP_TBUF_MOD, refer to the following table.  

<!-- p537-table-003 (table-26-6@1) -->
