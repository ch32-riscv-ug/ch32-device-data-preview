# Chapter 1 Memory and Bus Architecture


## 1.1 Bus Architecture

The CH32H417 series chips feature an internally integrated dual-core architecture based on the QingKe V3F and  
V5F designs. Within this architecture, components such as the cores, arbitration unit, DMA module, and SRAM  
storage interact via multiple bus groups. The design incorporates a universal DMA controller to reduce CPU load  
and enhance access efficiency. Concurrently, it includes data protection mechanisms and clock auto-switching  
protection to enhance system stability. The system block diagram is shown in Figure below.
