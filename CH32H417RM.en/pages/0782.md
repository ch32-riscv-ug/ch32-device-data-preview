<strong>Generate an interrupt in receive mode</strong>  
According to the FIFO configuration in receiving mode, an interrupt is generated:  
When the FIFO threshold bits in the R32_SAI_xCFGR2 register are configured for an empty FIFO (FTH[2:0] set  
to 000b), an interrupt is generated if at least one data bit is present in the R32_SAI_xDATAR register (FLTH[2:0]  
bits in the R32_SAI_xSR register are greater than or equal to 001b). (the FREQ bit in the R32_SAI_xSR register  
is set to 1 by hardware). When the FIFO becomes empty (FLTH[2:0] in the R32_SAI_xSR register equals 000b),  
i.e., when no data is stored in the FIFO, this interrupt (the FREQ bit in the R32_SAI_xSR register) is cleared by  
hardware.  
When the FIFO threshold bit in the R32_SAI_xCFGR2 register is configured for one-quarter FIFO fill (FTH[2:0]  
set to 001b), an interrupt is generated if at least one-quarter of the FIFO data cells are available (R32_SAI_xSR  
register FLTH[2:0] bits greater than or equal to 010b). (the FREQ bit in the R32_SAI_xSR register is set to 1 by  
hardware). When less than one-quarter of the FIFO data cells are available (FLTH[2:0] bits in R32_SAI_xSR are  
less than 010b), this interrupt (the FREQ bit in the R32_SAI_xSR register) is cleared by hardware.  
When the FIFO threshold bits in the R32_SAI_xCFGR2 register are configured for half-full FIFO (FTH[2:0] set  
to 010b), an interrupt is generated if at least half of the FIFO data cells are available (FLTH[2:0] bits in the  
R32_SAI_xSR register are greater than or equal to 011b). (The FREQ bit in the R32_SAI_xSR register is set to 1  
by hardware). When less than half of the FIFO data cells are available (FLTH[2:0] bits in the R32_SAI_xSR  
register are less than 011b), this interrupt (the FREQ bit in the R32_SAI_xSR register) is cleared by hardware.  
When the FIFO threshold bit in the R32_SAI_xCFGR2 register is configured to three-quarters full (FTH[2:0] set  
to 011b), an interrupt is generated if at least three-quarters of the FIFO data cells are available (FLTH[2:0] bits in  
SAI_xSR are greater than or equal to 100b). (the FREQ bit in the R32_SAI_xSR register is set to 1 by hardware).
