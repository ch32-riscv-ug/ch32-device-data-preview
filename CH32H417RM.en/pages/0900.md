### 40.6.3 NAND Flash Timing Diagram

NAND Flash storage area is managed by the following set of registers:  
● Control Register: FMC_PCR  
● Interrupt Status Register: FMC_SR  
● ECC Register: FMC_ECCR  
● Timing Register for General Memory Space: R32_FMC_PMEM  
● Timing Register for Feature Memory Space: R32_FMC_PATT
