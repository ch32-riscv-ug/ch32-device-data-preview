# Chapter 46 Flash Memory and User Option Bytes (FLASH)


## 46.1 Flash Memory Organization

The flash memory organization inside the chip is as follows:

<em>in 8K bytes (32 pages) units; except that the &quot;manufacturer configuration word&quot; area is factory locked, the user is</em>  
<em>inaccessible. Other areas can be operated by users under certain conditions.</em>
