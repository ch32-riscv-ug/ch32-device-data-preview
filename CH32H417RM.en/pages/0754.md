## 34.3 Data Space and Registers and Addressing

The data space of the eMCU includes 49 dedicated special function registers (SFRs) addressed via 8-bit addresses  
within the range 0x00 to 0x3F. All registers have a data width of 1 byte, equivalent to 8 bits.  
Some SFRs are accessible for read/write or read-only operations from the host side, which supports 8-bit, 16-bit,  
or 32-bit width read/write operations. The host side has write priority. When both the eMCU and host attempt to  
write to the same register simultaneously, the eMCU&#x27;s write operation is automatically discarded.  
The eMCU&#x27;s addressing modes include: immediate address, immediate fast address, standard direct address,  
extended direct address, indirect address, and bit address. The latter four are used for register addressing.  
The indirect addressing range is 0x000-0x0FF, covering all registers of the eMCU. The eMCU provides two sets  
of indirect address registers, each consisting of an address register and a data read/write port. First, write the target  
register&#x27;s address into the address register, then read or write the target register via the data read/write port.  
The address range for extended direct addressing is 0x000-0x1FF, where the instruction directly provides a 9-bit  
register address. This is only applicable to the following two direct register read/write instructions: MOV  
register,A or F, and MOVA register.  
The addressing range for standard direct addressing is 0x000-0x0FF. The instruction directly provides an 8-bit  
register address, applicable to all direct address instructions except those covered by extended direct addressing,  
such as CLR register, ADD register, BS register, bit, etc. When addressing a larger range is required, indirect  
addressing should be employed.  
Immediate number fast addressing enables rapid writing of operands from instruction codes to target registers  
without requiring an A register intermediary. MOVA1F is used for fast setting of register #1 (SFR_PORT_DIR),  
while MOVA2F is used for fast setting of register #2 (SFR_PORT_IO). MOVA1P and MOVA2P employ indirect  
addressing for rapid setting of all registers, equivalent to first performing immediate addressing followed by  
indirect addressing within a single cycle.  
Bit addressing utilizes a 3-bit address provided directly by the instruction. Register addressing can employ either  
standard direct addressing or indirect addressing, covering address ranges 0x000 to 0x0FF respectively, thereby  
enabling access to any bit within any register.  

## 34.4 Special Function Register SFR

Some SFR or some bits are not really realized, and they are reserved bits. Reading is 0, and writing must keep the  
original value or write 0.
