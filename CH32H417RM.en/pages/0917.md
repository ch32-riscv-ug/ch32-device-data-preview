2) Generate the PALL command. (provided an activation line exists in power-down mode)  
3) Generate an auto-refresh command  
4) Drive SDCKE low again to return to power-down mode.  
To exit power-down mode, the MODE bit must be set to “000” (normal mode) and the target storage area bits
