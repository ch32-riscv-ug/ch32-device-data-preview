### 33.3.3 Response Parameter Register (R32_EMMC_RESPONSE)

Offset address: 0x08, 0x0C, 0x10, 0x14, 0x14

<em>Note: When the response length is 136 bits, the valid data is 128 bits; when the response length is 48 bits, the</em>  
<em>valid data length is 32 bits. The R32_EMMC_RESPONSE3 register stores the valid data parameters of the</em>  
<em>response.</em>  
<em>The R32_EMMC_RESPONSE3 register is multiplexed. This multiplexing occurs as follows: When using the</em>  
<em>CMD25 command to write multiple blocks of data to the card consecutively, writing to this register upon</em>  
<em>completion of a block transfer causes the controller to automatically offset the address by the block length and</em>  
<em>continue writing data. If the DMA address needs to be changed, writing the DMA address register will initiate the</em>  
<em>write operation, eliminating the need to use register writes for initiation.</em>
