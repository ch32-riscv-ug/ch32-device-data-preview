### 34.4.17 Data Register (SFR_DATA_x) (x=0-31)

SFR_DATA_x are all bidirectional read/write data registers. Write operations from the host take precedence, and  
their functions are software-defined.  
Among these, SFR_DATA_EXCH also supports single-cycle bit transfer instructions.  

## 34.5 Application

The eMCU operates at the same clock frequency as the host side, facilitating dynamic data exchange. It features a  
rich set of bit manipulation instructions, enabling single-cycle I/O configuration, single-cycle I/O status polling, or  
bit data copying. It supports hardware encoding/decoding of PWM or Manchester-modulated bit data, making it  
suitable for implementing I/O for various low-to-medium speed communication protocols and for I/O control  
requiring precise timing.
