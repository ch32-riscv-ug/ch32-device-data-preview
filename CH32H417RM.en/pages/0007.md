● The system bus connects the core to the bus matrix, coordinating access between the core, DMA, SRAM,  
and peripherals.  
● The DMA bus connects the HB controller interface for DMA operations to the bus matrix. This bus accesses  
FLASH data, SRAM, and peripherals.  
● The bus matrix coordinates access between the system bus, data bus, DMA bus, and SRAM.
