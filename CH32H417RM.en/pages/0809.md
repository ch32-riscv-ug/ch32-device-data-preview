### 37.3.2 QSPI Signal Interface Protocol Mode

Single-wire SPI mode  
Traditional SPI mode permits serial transmission/reception of individual 1-bit data. In this mode, data is sent to  
the FLASH via SIO0. Data received from the FLASH is delivered via SIO1.  
To utilize this single-bit mode, configure different command phases by setting the  
IMODE/ADMODE/ABMODE/DMODE field in R32_QSPIx_CCR to 01b.  
Within each phase configured for single-wire mode:  
● SIO0 is in output mode  
● SIO1 is in input mode (high impedance)  
● SIO2 is in output mode and forced to 0 (to disable the “write protection” function)  
● SIO3 is in output mode and forced to 1 (to disable the “hold” function)  
If DMODE=01b, this also applies to the empty instruction phase as described above.  
<strong>Dual-Wire SPI Mode</strong>  
In dual-wire mode, 2 bits are transmitted/received simultaneously via the SIO0/SIO1 signals. By configuring the  
IMODE/ADMODE/ABMODE/DMODE field of the R32_QSPIx_CCR register to 10b, different command phases  
can be set accordingly.  
In each phase configured for dual-wire mode:  
● SIO0/SIO1 are in high-impedance state (input) during data phase read operations and in output mode  
otherwise.  
● SIO2 is in output mode and forced to 0.  
● SIO3 is in output mode and forced to 1.  
During the empty instruction phase, if DMODE=01b, SIO0/SIO1 remain in high-impedance state at all times.  
<strong>Quad-wire SPI Mode</strong>  
In quad-wire mode, four bits of data are transmitted/received simultaneously via the SIO0/SIO1/SIO2/SIO3  
signals. Configuring the IMODE/ADMODE/ABMODE/DMODE fields in the R32_QSPIx_CCR register to 11b  
enables corresponding settings for different command phases.  
In each phase configured for quad-wire mode:  
● SIO0/SIO1/SIO2/SIO3 are in high-impedance state (input) during the data phase of read operations and  
function as outputs in other cases.  
● SIO2 and SIO3 are used exclusively for QSPI mode. If no phase is configured for quad-wire SPI mode, the  
corresponding SIO2 and SIO3 pins can be used for other functions even when QSPI is active.  
During the empty command phase, if DMODE=11, SIO0/SIO1/SIO2/SIO3 are all in high-impedance state.
