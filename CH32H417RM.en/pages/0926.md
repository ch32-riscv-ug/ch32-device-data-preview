# Chapter 41 Encryption Module (ECDC)

The system has built-in block cipher algorithm module, which supports AES and SM4 block cipher algorithms  
and electronic codebook (ECB) and counter (CTR) modes. The module completes one encryption and decryption  
process with 128-bit data size as the basic unit, and provides a DMA encryption and decryption mode for data in  
memory and a single encryption and decryption mode for SFR registers.  

## 41.1 Main Features

● ECB and CTR modes for SM4 algorithm with 128-bit keys  
● ECB and CTR modes for AES algorithm with 128/192/256-bit keys  
● Support direct encryption of individual 128-bit data via software writing to SFRs  
● Support DMA-based (memory-to-memory) encryption/decryption of software-specified data blocks  

## 41.2 AES/SM4 Algorithm

The Advanced Encryption Standard (AES) algorithm is a block cipher that employs a symmetric block cipher  
system, ranking among the most widely used symmetric-key encryption algorithms. The SM4 block cipher  
algorithm is typically a dedicated block cipher designed for wireless local area networks (WLANs) and trusted  
computing environments, though it can also be utilized for data encryption protection in other contexts.  
During data encryption and decryption, keys must be loaded. For the AES algorithm, depending on the key length  
set to 128/192/256 bits, the user key must be expanded into an expansion key of 11×128/13×128/15×128 bits,  
respectively. In contrast, the SM4 algorithm expands a 128-bit user key into a 32×32-bit expanded key. These  
expanded keys are stored in internal registers for convenient access during encryption and decryption operations.
