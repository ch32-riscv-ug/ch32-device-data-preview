<em>During write operations to the SD card, it stores the starting address in SRAM for data to be written. Addressing</em>  
<em>occurs within the SRAM region.</em>  
When performing consecutive multi-block read/write operations to SD, after a single block transfer completes  
(RB_EMMC_IF_BKGAP), the user may write the DMA_BEG1 register to change the DMA address as needed.
