## 19.8 DMA

The USART module supports DMA, and can use DMA to implement fast continuous reception and transmission.  
When DMA is enabled and the TXE bit is set, DMA writes data to the transmit buffer from the set memory space.  
When DMA is used for reception, DMA transfers the data in the receive buffer to a specific memory space each  
time the RXNE bit is set.  

## 19.9 Interrupt

The USART module supports multiple interrupt sources, including transmit data register empty (TXE), CTS,  
transmission complete (TC), received data ready (RXNE), data overrun error (ORE), idle line (IDLE), parity  
check error (PE), break flag (LBD), noise (NE), multi-buffer communication overrun (ORT) and framing error  
(FE).

## 19.10 Interrupt

Enable the low-power wake-up function via the LPWKUP_EN bit in the USARTx_CTLR3 register, and read the  
low-power wake-up start indicator flag from the LPWKUP_ACT_FLAG bit in the USARTx_STATR register; The  
clock source for low-power wake-up is selected via the LPWKUP_CK_SRC bit in the USARTx_CTLR3 register,  
offering choices between LSE or LSI. The LPWKUP_DLY_CFG bit configures the clock source period for the  
low-power wake-up receive delay.
