## 4.3 Physical Memory Protection (PMP)

In order to improve the security of the system, a set of physical address access restrictions is defined in the  
architecture of RISC-V, which can set its read, write and execute attributes for the physical memory in the area,  
and the minimum length of the area is 4 bytes. PMP unit always takes effect in user mode, and it can take effect  
optionally in machine mode. If it violates the current memory limit, it will generate system abnormal interrupt  
(EXC).  
The PMP unit of Core 1 (RISC-V5F) contains four sets of 8-bit configuration registers (CSR address 0x3A0) and  
four sets of address registers (CSR addresses 0x3B0–0x3B3). These require access via the &#x27;csr&#x27; instruction and  
must be performed in machine mode.  
The PMP unit of Core 0 (RISC-V3F) contains four sets of 8-bit configuration registers (CSR address 0x3A0) and  
four sets of address registers (CSR addresses 0x3B0–0x3B3). Access requires the &#x27;csr&#x27; instruction and must be  
performed in machine mode.  
<em>Note: The PMP functionality of Core 0 is only available on chips where the fifth digit of the lot number is not zero.</em>
