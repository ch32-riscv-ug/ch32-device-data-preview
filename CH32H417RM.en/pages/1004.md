#### 44.2.11.1 Register to Memory

Register-to-memory mode is used to fill user-defined areas with predefined colors.  
The color format is set in the R32_GPHA_OPFCCR register.  
The GPHA does not acquire data from any source. It only writes the color defined in the R32_GPHA_OCOLR  
register to the region defined by R32_GPHA_OMAR addressing and the R32_GPHA_NLR and  
R32_GPHA_OOR registers.  

#### 44.2.11.2 Memory to Memory and Perform PFC

In this mode, GPHA performs pixel format transform on the source data and stores the result in the target storage  
unit.  
For the size of the region to be transferred, the source region size is defined by the R32_GPHA_NLR and  
R32_GPHA_FGOR registers, while the destination region size is defined by the R32_GPHA_NLR and  
R32_GPHA_OOR registers.  
Data is retrieved from the location defined by the R32_GPHA_FGMAR register and processed by the foreground  
layer PFC. The original pixel format is configured via the GPHA_FGPFCCR register.  
If the original pixel format is in direct color mode, all color channels are expanded to 8 bits.  
If the pixel format is in indirect color mode, the corresponding CLUT must be loaded into the CLUT memory.  
CLUT loading can be performed automatically in the following sequence:  
1) Set the CLUT address in the R32_GPHA_FGCMAR register.  
2) Set the CLUT size in the CS[7:0] bits of the R32_GPHA_FGPFCCR register.  
3) Set the CLUT format (24-bit or 32-bit) in the CCM bit of the R32_GPHA_FGPFCCR register.  
4) Enable CLUT loading by setting the START bit in the R32_GPHA_FGPFCCR register to 1.  
Upon completion of CLUT loading, the CTCIF flag in the R32_GPHA_ISR register will be set; if the CTCIE bit  
in the R32_GPHA_CTLR register is set to 1, an interrupt will also be generated. The automatic CLUT loading  
process cannot occur concurrently with traditional GPHA transfers.  
The CLUT can also be filled by the CPU or by any other host device via the HB port. The CLUT cannot be  
accessed during GPHA transfers or when using CLUT (indirect color format).  

#### 44.2.11.3 Memory to Memory and Perform PFC and Mixing

In this mode, two source images will be captured in the foreground layer FIFO and the background layer FIFO  
(defined in R32_GPHA_FGMAR register and R32_GPHA_BGMAR register respectively).  
2 pixel format converters must be configured as described in memory-to-memory mode. Since these 2 pixel  
format converters are independent and have their own CLUT memory, their configurations can be different.  
After each pixel is converted into 32 bits by the corresponding PFC, it will be mixed according to the formula in  
44.3.6. The output PFC will encode the obtained 32-bit pixel value according to the specified output format, and  
the encoded data will be written into the target storage unit addressed by GPHA_OMAR.
