#### 36.3.12.2 Frame Synchronization Advance Detection (AFSDET)

AFSDET flag is only used when SAI audio module is used as slave mode, and it will be disabled in master mode.  
In R32_SAI_xFRCR register, the frame length, frame polarity and frame offset configuration are all known, and  
this flag is used to indicate whether the frame synchronization (FS) signal is detected earlier than expected. When  
the frame detection advance occurs, the AFSDET flag in R32_SAI_xSR register will be set.  
For the current audio frame which is insensitive to FS advance, the secondary detection will not affect it. In other  
words, the &quot;parasitic&quot; event of the FS signal will be marked, but it will not interfere with the processing of the  
current audio frame.  
If the AFSDETIE bit in the R32_SAI_xINTENR register is set to 1, an interrupt will be generated. Clearing the  
AFSDET flag requires writing a 1 to this bit.  
To resynchronize with the main module after a Frame Sense Detect Early error occurs, the following steps must be  
followed:  
1) Disable the SAI module by resetting the SAIEN bit in the R32_SAI_xCFGR1 register. To ensure SAI is  
disabled, read back the SAIEN bit and verify its value is set to 0.  
2) Flush the FIFO by setting the FFLUSH bit in the R32_SAI_xCFGR2 register to 1.  
3) Re-enable the SAI peripheral by setting the SAIEN bit in the R32_SAI_xCFGR1 register to 1.  
4) The SAI module will wait for the FS enable signal to restart synchronization with the main module.  
<em>Note: The SAIEN flag is not enabled in AC&#x27;97 mode because the SAI audio module, acting as a link controller,</em>  
<em>generates the FS signal even when declared as a slave module. Since the AC&#x27;97 protocol does not utilize the FS</em>  
<em>signal, this feature serves no practical purpose in SPDIF mode.</em>  

#### 36.3.12.3 Frame Synchronization Lag Detection (LFSDET)

The LFSDET flag is only used when the SAI audio module operates as a slave module; it is disabled in master  
mode. In the R32_SAI_xFRCR register, the frame length, frame polarity, and frame offset configurations are  
known. If the external master module fails to send the FS signal within the scheduled time or generates the FS  
signal too late, the LFSDET flag will be set to 1. An interrupt will also be generated if the LFSDETIE bit in the  
R32_SAI_xINTENR register is set to 1. Writing a value of 1 to the LFSDET bit in the R32_SAI_xSR register  
clears the LFSDET flag.  
The Frame Synchronization Lag Detection flag is set to 1 when the corresponding error is detected, indicating that  
the SAI requires resynchronization with the master module. Refer to Section 36.3.12.2: Frame Synchronization  
Advance Detection (AFSDET) for the specific sequence described.  
In noisy environments, the audio module&#x27;s state machine may incorrectly detect interference on the SCK clock  
and shift SAI data to an erroneous frame position. The SAI detects this event and reports it as a frame  
synchronization delay detection error.  
Frame corruption does not occur if the external master module manages audio data frame transmission in  
continuous mode, which is the case for most applications. If this situation occurs, the LFSDET flag will be set to  
1.  
<em>Note: The LFSDET flag is not enabled in AC&#x27;97 mode because the SAI audio module, acting as a link controller,</em>  
<em>generates the FS signal even when declared as a slave module. Since the AC&#x27;97 protocol does not utilize the FS</em>  
<em>signal, this functionality is not relevant in SPDIF mode.</em>
