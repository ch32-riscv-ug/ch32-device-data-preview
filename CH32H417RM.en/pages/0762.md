### 34.4.15 Coded Bit Period Register (SFR_BIT_CYCLE)


### 34.4.16 Coded Bit Configuration Register (SFR_BIT_CONFIG)

The eMCU supports 2 bit-modulation methods: PWM duty cycle modulation and Manchester modulation.  
Setting SB_BIT_CYCLE greater than 3 enables encoding/decoding. When SB_BIT_TX_EN=0, the system  
receives data. Input status is received from IO0 based on the preset width, and decoded data is stored in  
SB_BIT_RX_I0. When SB_BIT_TX_EN=1, the system transmits data. Raw data to be transmitted is placed in  
SB_BIT_TX_O0. After encoding, it is automatically delivered to SB_PORT_OUT0 for pin output.  
SB_BIT_CYC_CNT and SB_BIT_CYC_TAIL indicate the cycle status of the encoded bit. When  
SB_BIT_CYC_TAIL=1, it signifies the current phase is within the last 25% of the bit cycle, indicating that  
SB_BIT_RX_I0 has completed reception and decoding, and the transmission encoding is finished and has reached  
SB_PORT_OUT0.  
Setting SB_BIT_CYCLE=0 forces SB_BIT_CYC_TAIL to 1, facilitating Manchester encoding/decoding  
initiation.  
Setting SFR_BIT_CYCLE clears the rising and falling edge detection records for IO0, enabling the WAITB  
instruction to restart waiting.
