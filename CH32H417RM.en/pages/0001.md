# Overview

The CH32H417 is an interconnected general-purpose microcontroller based on a dual-core design featuring  
QingKe RISC-V5F and RISC-V3F architectures. It integrates a USB 3.2 Gen1 controller and transceiver, a  
100Mbps Ethernet MAC and PHY, a SerDes high-speed isolated transceiver, and a Type-C/PD controller and PHY.  
It Provides SD/eMMC controllers, 500MBytes Universal High-Speed Interface (UHSIF), DVP digital image  
interface, Single Wire Protocol master interface (SWPMI), Programmable Interface Controller (PIOC), Flexible  
Memory Controller (FMC), DFSDM, LTDC, GPHA, DMA controller, multiple timer groups, 8 serial ports, I3C, 4  
I2C groups, 2 QSPI groups, 4 SPI groups, 2 I2S groups, 3 CAN groups, and other peripheral resources. It  
incorporates a 5MHz sampling rate dual 12-bit ADC unit, a 20MHz sampling rate 10-bit high-speed HSADC unit,  
16 Touchkey channels, dual DAC units, 3 OPAs, and CMP for analog resources. Supports 10M/100M Ethernet  
communication, USB 2.0 and USB 3.0, USB Host and USB Device functionality, Type-C and PD USB fast  
charging, SerDes high-speed isolation and long-distance transmission, and dual-core task division to enhance  
network protocol processing efficiency and communication response speed.  
This manual provides detailed usage information for the CH32H417, H416, and H415 chips to support user  
application development.  
For device specifications of the CH32H417 series chips, please refer to the CH32H417DS0 manual.
