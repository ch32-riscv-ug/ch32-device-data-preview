When I3C operates as a slave device, the hardware returns two data bytes upon receiving a GETSTATUS CCC  
command, following either Format 1 (without an interpretation byte or with an interpretation byte TGTSTAT =  
0x00) or Format 2 (with an interpretation byte PRECR = 0x91).  
On the I3C bus, the 2-byte STATUS[15:0] returned in Format 1 is as follows:  
STATUS[15:14] = 00 (unused);  
STATUS[13] = 1 (if a missing start bit is detected since the previous GETSTATUS CCC reception) or 0  
(otherwise);  
STATUS[12] = 1 (if an overflow/underflow error is detected since the previous GETSTATUS CCC reception) or 0  
(otherwise);  
STATUS[11] = 1 (if SCL stabilization time exceeds 125μs during SDR read transmission since the previous  
GETSTATUS CCC reception) or 0 (otherwise);  
STATUS[10:8] = 000 to 110 (if a protocol error is detected since the previous GETSTATUS CCC reception  
(provided STATUS[5] = 1), encoded value x = 0 to 6, corresponding to slave device error TEx) or 000  
(otherwise);  
STATUS[7:6] = 00 (ready to execute the switching process);  
STATUS[5] = 1 (if a protocol error was detected since the previous GETSTATUS CCC reception) or 0  
(otherwise);  
STATUS[4] = 0 (reserved);  
STATUS[3:1] = 000 (unused);  
STATUS[0] = 1 (if a pending interrupt exists—provided IBI is configured in the R32_I3C_CTLR register, IBIEN  
= 1 and DAVAL = 1 in the R32_I3C_DEVR0 register, and IBI has not been acknowledged by the master device or  
disabled via DISEC) or 0 (otherwise).  
On the I3C bus, the 2-byte STATUS[15:0] returned in format 2 is as follows:  
STATUS[15:8] = 00000000 (unused);  
STATUS[7:2] = 00000 (unused);  
STATUS[1] = 1 (if software is still processing a received DEFTGTS or DEFGRPACCC and has not yet cleared  
the associated event (DEFF = 1 or GRPF = 1 in the R32_I3C_EVR register)); the master device must wait for  
software to complete these operations before issuing a GETACCR CCC (otherwise it will not be acknowledged);  
STATUS[0] = 1 (if the DEFTSGTS or DEFGRPA CCC may have been lost). If a missing start bit is detected  
(WKPF = 1 in the R32_I3C_EVR register), this bit will be set to 1; if DEFF = 1 or GRPF = 1 in the  
R32_I3C_EVR register, this bit will be cleared.  
Upon completion of Format 1 GETSTATUS CCC, it is reported via STAF = 1 in the R32_I3C_EVR register and  
the corresponding interrupt (if enabled, i.e., STAIE = 1 in the R32_I3C_INTENR register).  
Upon completion of a GETSTATUS CCC in Format 2, it is reported via GETF = 1 in the R32_I3C_EVR register  
and the corresponding interrupt (if enabled, i.e., GETIE = 1 in the R32_I3C_INTENR register).
