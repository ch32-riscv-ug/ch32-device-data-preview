# Chapter 27 USB3.0 SuperSpeed Host/Device Controller (USBSS)

<strong><em>The module description in this chapter is only applicable to CH32H417 and CH32H416 microcontroller</em></strong>  
<strong><em>products.</em></strong>  
The USB 3.0 SuperSpeed controller functions as both a host controller and a device controller. It incorporates a  
built-in SuperSpeed USB PHY physical layer transceiver, enabling USB 3.0 interface functionality and supporting  
5Gbps USB SuperSpeed signals.  
The USBSS module provides application code with a link-layer register access interface for managing device  
connection/disconnection, bus status, and power modes. It offers separate host (HOST) and device (DEVICE)  
function access interfaces to implement various data transfers and upper-layer protocols defined by the USB 3.0  
specification.  
USBSS module peripheral base address: 0x40034000  

## 27.1 Main Features

● Support USB 3.0 protocol specifications and USB 3.2 Gen1  
● Support USB Host functionality and USB Device functionality  
● Power management modes support U1/U2/U3 low-power states  
● Support driving USB 3.0 hubs  
● Support control transfers, bulk transfers, interrupt transfers, real-time/synchronous transfers  
● All non-zero endpoints support maximum 1024-byte packets with burst mode capability  
● Support direct memory access (DMA) to endpoint buffer data  
● Proprietary controller and transceiver with high-speed integrated design, tested at 450 Mbytes/s  

## 27.2 Register Description

The USBSS registers are divided into 4 parts:  
● USBSS global registers  
● USBSS device control registers  
● USBSS host control registers  
● USBSS LINK control registers
