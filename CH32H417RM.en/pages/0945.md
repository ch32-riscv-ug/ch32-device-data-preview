### 42.3.8 Analog Watchdog

The analog watchdog is used to trigger an external signal (open circuit or interrupt) when it reaches or exceeds a  
given upper threshold or reaches or falls below a given lower threshold. Interrupt/event/open circuit generation  
can then be invoked.  
Each analog watchdog monitors the serial data receiver output (after the watchdog filter is simulated on each  
channel) or the data output register (current injection or general conversion result) according to the AWFSEL bit  
setting (in the R32_DFSDM_FLTxCR1 register). Whether the input channels need to be monitored by analog  
watchdog X can be selected by AWDCH[1:0] in R32_DFSDM_FLTxCR2 register.  
Analog watchdog conversions on input channels are independent of standard conversions. In standard conversion  
mode, the analog watchdog employs its own filter and signal processing on each input channel, unaffected by  
injection or regular master conversions. In continuous conversion mode, analog watchdog conversions are  
performed on selected input channels to maintain channel monitoring even when injection or regular master  
conversions are paused (RCIP=0, JCIP=0).  
The upper threshold and lower threshold registers are compared against a given data value (set via the  
AWHT[23:0] bits of the R32_DFSDM_FLTxAWHTR register and the AWLT[23:0] bits of the  
R32_DFSDM_FLTxAWLTR register).  
You can choose two situations to compare the threshold register with the data value:  
● Option 1: In this case, the input data is taken from the final output data register (AWFSEL=0). This choice  
has the following characteristics:  
- High input data resolution (up to 24 bits)
- Slow response time—not suitable for fast-response applications such as overcurrent detection
- For comparison purposes, final data requires shift and offset correction
- Final data becomes available only after executing a normal or injected main conversion
- Operates with parallel input data sources (DATMPX[1:0] ≠ 0 in the R32_DFSDM_CHyCFGR1
register)  
● Option 2: In this case, the input data is taken from the output of any serial data receiver (AWFSEL=1). This  
choice has the following characteristics:  
- Serial data input is processed through a dedicated analog watchdog Sincx channel filter. The filter&#x27;s
oversampling rate (1..32) and filter order (1..3) are configurable (refer to the AWFOSR[4:0] and  
AWFORD[1:0] bits in the R32_DFSDM_CHyAWSCDR register).  
- Lower resolution (up to 16 bits)
- Fast response time—suitable for applications requiring rapid response, such as overcurrent/overvoltage
