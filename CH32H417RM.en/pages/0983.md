### 43.3.6 Layer Window and Blending Function

Color keys (RGB) can be configured to represent transparent pixels. At runtime, the color key value can be  
configured and used to replace the pixel RGB value.  
When the color key is enabled, the current pixel (the pixel after format conversion and before CLUT is mixed  
separately) will be compared with the color key. If the current pixel matches the programmed RGB value, all  
channels (ARGB) of the pixel are set to 0.  
Color keys are configured through the LTDC_LxCKCR register. The programmed value depends on the pixel  
format, because it will be compared with the current pixel after the pixel format is converted to ARGB888.  
For example, if medium yellow (50% red +50% green) is used as the transparent color key, then:  
- In RGB565, the mid-yellow value is 0x8400. Set LTDC_LxCKCR to 0x848200.
- In ARGB8888, the mid-yellow value is 0x808000. Set LTDC_LxCKCR to 0x808000.
- In all CLUT-based color modes (L8, AL88, AL44), set one of the palette entries to mid-yellow 0x808000 and set
LTDC_LxCKCR to 0x808000.  

### 43.3.7 Reloaded shadow register

Some configuration registers perform shadow operations. When writing to the active register, or at the beginning  
of the vertical blanking period after the configuration phase of R32_LTDC_SRCR register, the shadow register  
value can be reloaded into the active register immediately. If the immediate overload configuration is selected,  
overloading should only be activated after all new registers have finished writing.  
The shadow register should not be modified again before the overload is completed. Reading the shadow register  
will return the actual effective value. The newly written value can only be read after the overload occurs.  
If enabled in the R32_LTDC_IER register, a register overload interrupt can be generated.  
Shadow registers are Layer 1 and Layer 2 registers, except R32_LTDC_LxCLUTWR register.  

### 43.3.8 Interrupt

The LTDC provides three maskable interrupts, which are logically ORed into a single interrupt vector.  
Interrupt sources can be individually enabled or disabled via the R32_LTDC_IER register; corresponding interrupt  
flags can be read through the R32_LTDC_ISR register; and the corresponding interrupt flag bits can be cleared by  
setting the R32_LTDC_ICR register to 1.  
Interrupts are generated when the following events occur:  
● Line interrupt: Generated upon reaching a programmed line. The interrupt position is programmed in the  
R32_LTDC_LIPCR register;  
● Register reload interrupt: Generated during shadow register reload execution within the vertical blanking  
interval;  
● FIFO underflow interrupt: Generated when requesting pixels from an empty layer FIFO.
