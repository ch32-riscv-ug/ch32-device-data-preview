### 36.3.6 Internal FIFO

Each SAI audio submodule contains an independent 8-word-wide synchronous FIFO to enhance transmission  
efficiency. These FIFOs can be accessed by either the CPU or DMA, with FIFO request interrupts used to request  
CPU and DMA access.  
Depending on whether the audio module is defined as a transmitter or receiver, corresponding reads or writes to  
the FIFO are executed. Regardless of the access size, each read or write operation to the FIFO operates on a single  
word-sized FIFO cell. Each FIFO word contains one audio slot. Following each access to the R32_SAI_xDATAR  
register, the FIFO pointer increments by one word. Consequently, only one FIFO request is associated with the  
FREQ bit (FIFO request flag) in the R32_SAI_xSR register.  
When the FREQIE bit in the R32_SAI_xINTENR register is enabled, an interrupt will be generated. The  
triggering conditions for this interrupt depend on the operating mode, FIFO threshold, FIFO status, and DMA  
burst transfer size.  
The specific interrupt triggering mechanism is detailed in Table 36-2 and the subsequent sections &#x27;Generating  
Interrupts in Transmit Mode&#x27; and &#x27;Generating Interrupts in Receive Mode&#x27;.
