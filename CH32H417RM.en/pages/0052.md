# Chapter 4 Central Processing Unit (CPU)

The CH32H417 series integrates a dual-core architecture, with both RISC-V5F and RISC-V3F cores supporting  
32-bit I, C, M, A, B, F, and extended instruction sets.  
The RISC-V3F core (C0/Core 0) employs a sequential single-issue architecture internally. Its fetch mode is  
configurable, supporting both pipelined and non-pipelined modes. Operating in non-pipelined mode reduces core  
power consumption.  
The RISC-V5F core (C1/Core 1) employs an out-of-order dual-issue architecture internally and integrates  
multiple branch predictors with instruction cache support, enabling superior performance for the V5. Additionally,  
RISC-V5 implements the WCH-X extended instruction set, delivering improvements in both code density and  
computational performance.  
Private peripherals include system timers, inter-core communication, and hardware semaphore modules. External  
debugger support is provided, with the debugger enabling single-wire/dual-wire communication modes.  
Single-wire communication speed is adjustable across 4 levels.  

## 4.1 Main Features

<strong>RISC-V3F</strong>  
● Sequential single-issue architecture  
● 3-stage pipeline  
● Low clock frequency, low power consumption, control-focused  
● Provides one non-maskable interrupt (NMI)  
● 4-channel physical memory protection (PMP)  
● 4-channel hardware breakpoints  
● 2-level interrupt nesting  
● Programmable Fast Interrupt Controller (PFIC)  
● Custom extendable instructions  
● Hardware stack  
<strong>RISC-V5F</strong>  
● Out-of-order multiple-issue architecture  
● Built-in 32KB instruction cache  
● High clock frequency, high performance, focused on computation  
● Provides one non-maskable interrupt (NMI)  
● 4-channel physical memory protection (PMP)  
● 4-channel hardware breakpoints  
● 8-level interrupt nesting  
● Programmable Fast Interrupt Controller (PFIC)  
● Customizable extended instructions  
● Hardware stack  

### 4.1.1 V5F Core Memory Operation Model

V5F core is a kind of out-of-order superscalar processing, and its access to memory has reordering function.
