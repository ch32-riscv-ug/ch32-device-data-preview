## 40.7 SDRAM Controller


### 40.7.1 Main Features of SDRAM Controller

The main features of SDRAM controller are as follows:  
● Support word, half-word, and byte access  
● Power-down mode  
● CAS delays 1, 2, 3  
● Self-refresh mode  
● Programmable timing parameters  
● Software-configurable SDRAM power-up initialization  
● 2 independently configurable SDRAM storage regions  
● Multi-region ping-pong access  
● SDRAM clock can be HCLK, HCLK/2, or HCLK/3  
● Supports automatic refresh operation with programmable refresh rate  
● 8-bit, 16-bit, 32-bit memory data bus width  
● Automatic storage region boundary management  
● Read FIFO cache with 6 lines × 32-bit depth (6 × 14-bit address tags)  
● 13-bit address row, 11-bit address column, 4 internal storage regions: 4*16M*32bit (256MB), 4*16M*16bit  
(128MB), 4*16M*8bit (64MB)  

### 40.7.2 SDRAM External Memory Interface Signal

At startup, the SDRAMI/O pin used to connect the FMCSDRAM controller with the external SDRAM device  
must be configured through the user application. Unused SDRAM controller I/O pins of application programs can  
be used for other purposes.
