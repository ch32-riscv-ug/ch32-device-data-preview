### 12.2.5 HSADC Conversion Mode

The HSADC supports only continuous conversion. In continuous conversion mode, a new conversion is initiated  
immediately upon completion of the previous ADC conversion. This mode is activated by setting the START bit  
to 1 in the R32_HSADC_CTLR1 register. Once conversion for the selected channel completes, the converted data  
is stored in the 10-bit R32_HSADC_DATAR register. The EOC flag is set, and if the EOCIE bit is enabled, an  
ADC interrupt is triggered.
