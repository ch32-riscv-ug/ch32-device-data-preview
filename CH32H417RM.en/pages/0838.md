Subsequently, the user performs the following operations:  
1) Set the TXDMA bit in the R32_SWPMI_CR register to 1;  
2) Set the TXBEIE bit in the R32_SWPMI_IER register to 1;  
3) Populate buffers 1, 2, 3, and 4 in RAM (the number of data bytes in the payload is indicated by the least  
significant byte of the first word);  
4) Trigger the DMA transfer and frame transmission by enabling the data stream or channel within the DMA  
module.  
Within the SWPMI interrupt routine, the user must check the TXBEF bit in the R32_SWPMI_ISR register. If this  
bit is set to 1, the user should set the CTXBEF bit in the R32_SWPMI_ICR register to 1 to clear the TXBEF flag  
and update Buffer 1 in RAM memory. Upon the next SWPMI interrupt, the user updates Buffer 2, repeating this  
cycle.  
Software can also read the DMA counter (data volume to be transferred) in the DMA register to retrieve frames  
already transferred from RAM and sent. For example, if software uses 4 transmit buffers and the DMA counter  
value equals 17, this indicates two buffers in the RAM region are ready for update. This feature effectively  
addresses scenarios where the software must transmit multiple frames before handling the SWPMI interrupt. In  
such cases, the software must update multiple buffers.  
When no frames require transmission, the user must disable the DMA module&#x27;s cyclic mode. Transmission will  
cease upon completion of buffer 4.  
If transmission is terminated prematurely, such as upon completion of buffer 2, the user must set the least  
significant byte of the first word in both buffer 3 and buffer 4 to 0.  
When the data byte count in the least significant byte of the first word read is 0, the TXDMA bit in the  
R32_SWPMI_CR register will be cleared by hardware.  

### 38.3.7 Receive Processing

Before frame transmission, the user must activate the SWP. Refer to Section 38.3.1. After setting bit 1 of the  
SWPACT field in the R32_SWPMI_CR register, the “slave device recovery” state will set the SRF flag in the  
R32_SWPMI_ISR register to 1 and automatically enable the SWPMI for frame reception.  
If the SWP bus is in an &quot;active&quot; state, such as during frame transmission, the SWPMI core does not require a  
&quot;slave device recovery&quot; state and can immediately proceed with reception.
