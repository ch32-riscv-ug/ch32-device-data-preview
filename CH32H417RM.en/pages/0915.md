### 40.7.4 Low-power Mode

2 low-power modes are available:  
● Self-Refresh Mode  
The SDRAM device performs automatic refresh cycles to retain data without requiring an external clock.  
● Power-Down Mode  
The SDRAM controller performs automatic refresh cycles.  
<strong>Self-refresh mode</strong>  
This mode is selected by setting the MODE position to &#x27;101&#x27; and configuring the target storage area bits (CTB1  
and/or CTB2) in the R32_FMC_SDCMR register.  
The SDRAM clock ceases operation after the TRAS delay, while the internal refresh timer only stops counting  
when one of the following conditions is met:  
● A self-refresh command was issued to both devices.  
● One of the devices was not activated (the SDRAM storage area was not initialized).  
Before entering self-refresh mode, the SDRAM controller automatically issues a PALL command.  
If the write data FIFO is not empty, all data will be sent to memory before self-refresh mode activates, and the  
BUSY status flag remains set to 1.  
In self-refresh mode, all inputs to the SDRAM device are invalid except for SDCKE, which must remain low.  
SDRAM devices must remain in self-refresh mode for a minimum duration equal to the TRAS time and must be  
capable of sustaining self-refresh mode for extended periods. To ensure this minimum duration, the BUSY status  
flag remains high throughout the TRAS delay period following self-refresh activation.  
The SDRAM controller immediately generates a command sequence to exit self-refresh mode upon selection of  
an SDRAM device. After memory access completes, the selected device remains in normal mode.  
To exit self-refresh mode, the MODE bit must be set to “000” (normal mode) and the target storage area bits  
(CTB1 and/or CTB2) within the R32_FMC_SDCMR register must be configured.
