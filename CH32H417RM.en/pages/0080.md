#### 4.3.1.1 PMP Configuration Register (PMPCFG0)

CSR address: 0x3A0

Specifically, for address alignment and protected region selection, memory protection is applied to the range  
where A_ADDR ≤ region &lt; B_ADDR (requiring both A_ADDR and B_ADDR to be aligned to 4-byte  
boundaries):  
1. If B_ADDR – A_ADDR == 22, it is based on NA4;  
2. If B_ADDR – A_ADDR == 2(G+2), G≥1, and A_ADDR is aligned to 2(G+2), then use the NAPOT method;  
3. Otherwise it is based on TOR.
