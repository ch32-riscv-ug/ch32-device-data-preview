## 40.6 NAND Flash Controller

The FMC generates corresponding signal timing to drive the following device types: 8-bit and 16-bit NAND  
Flash.  
The NAND memory area is configured via dedicated registers (Section 40.6.7). Programmable memory  
parameters include access timing (as shown in the table below) and ECC configuration.
