### 44.2.12 GPHA Transmission Control (Start, Suspend, Stop and Complete)

After configuring the GPHA, setting the START bit to 1 in the R32_GPHA_CTLR register initiates data transfer.  
Upon completion, the START bit automatically resets and the TCIF flag is set in the R32_GPHA_ISR register. If  
the TCIE bit in the R32_GPHA_CTLR register is set to 1, an interrupt is also generated.  
The user application can suspend the GPHA at any time by setting the SUSP bit in the R32_GPHA_CTLR register  
to 1. The transaction can then be aborted by setting the ABORT bit in the GPHA_CTLR register to 1, or resumed  
by clearing the SUSP bit in the R32_GPHA_CTLR register.  
The user application may terminate a transaction in progress at any time by setting bit 1 of the ABORT field in the  
R32_GPHA_CTLR register. In this case, the TCIF flag will not be set.  
The CLUT automatic transfer process may also be terminated or suspended by setting the START bit in the  
R32_GPHA_FGPFCCR register or the R32_GPHA_BGPFCCR register itself.  

### 44.2.13 Watermark

The watermark can be programmed to generate an interrupt when the last pixel in a specified row is written to the  
target storage area.  
The row number is defined in bits LW[15:0] of the R32_GPHA_LWR register.  
Upon completion of the last pixel transfer in that row, the R32_GPHA_ISR will set the TWIF flag; an interrupt  
will also be generated if the TWIE bit in the R32_GPHA_CTLR register is set to 1.
