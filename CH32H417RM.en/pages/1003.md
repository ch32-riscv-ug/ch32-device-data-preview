### 44.2.9 GPHA HB Master Port Timer

An 8-bit timer is embedded in the port of HB master device, which aims to limit the bandwidth of crossbar matrix  
optionally. This timer is driven by HB clock, and is responsible for counting the dead zone between 2 consecutive  
accesses, so as to limit the bandwidth usage.  
The enabling of the timer and the dead-time value can be configured through the EN bits and DT[7:0] bits of  
R32_GPHA_AMTCR register. Please refer to Chapter 44.2.15 for the setting of HB dead-time.  

### 44.2.10 GPHA Transaction

GPHA transaction consists of a series of data transmission sequences with a preset number. The quantity and  
width of data can be programmed by software.  
Each GPHA data transmission project needs at most 4 steps:  
1) Load data from the memory location specified by the R32_GPHA_FGMAR register and perform pixel format  
conversion as defined in the R32_GPHA_FGPFCCR register.  
2) Load data from the memory location specified by the R32_GPHA_BGMAR register and perform pixel format  
conversion as defined in the R32_GPHA_BGPFCCR register.  
3) Process alpha values using PFC operations to obtain alpha channel information, then blend all retrieved pixels.  
4) Perform pixel format conversion on the blended pixels according to the R32_GPHA_OPFCCR register, then  
program the converted data into memory cells addressed via the R32_GPHA_OMAR register.  

### 44.2.11 GPHA Configuration

Source and destination data transmission can address peripherals and memory in the entire 4GB area (address  
range between 0x00000000 and 0xFFFFFFFF).  
GPHA can work in the following three modes, and the working mode can be selected through bits MODE[1:0] of  
R32_GPHA_CTLR register:  
- Register to Memory
- Memory to Memory with PFC Execution
- Memory to Memory with PFC and Hybrid Execution
