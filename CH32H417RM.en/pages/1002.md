### 44.2.7 GPHA Output PFC

The output PFC converts the pixel format from 32 bits to the specified output format, and the output format can be  
configured through bits CM[2:0] in R32 _ GPHA _ OPFC CCR register.

<em>This operation also applies to the RGB order used in the R32_GPHA_OCOLR register.</em>

defined by the following registers:  
- GPHA Output Memory Address Register (R32_GPHA_OMAR)
- GPHA Output Offset Register (R32_GPHA_OOR)
- GPHA Number of Lines Register (Number of Lines and Pixels per Line) (R32_GPHA_NLR)
