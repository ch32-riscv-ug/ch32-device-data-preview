## 46.2 Flash Memory Programming and Safety


### 46.2.1 Two Program/Erase Methods

● Standard Programming: This is the default programming mode (compatibility mode). In this mode, the CPU  
executes programming in single 2-byte increments. When DBMODE=1, the chip performs erase operations  
in single 8K-byte increments; when DBMODE=0, the chip performs erase operations in single 4K-byte  
increments.  
● Fast Programming: This method employs a page operation mode (recommended). After unlocking via a  
specific sequence, it executes a single 256-byte programming operation. When DBMODE=1, the chip  
performs a single 64K-byte erase operation; when DBMODE=0, the chip performs a single 32K-byte erase  
operation.  

### 46.2.2 Security-preventing against Illegal Access (read, write and erase)

● Page write protection  
● Read protection  
When the chip is in read protection:  
1) When DBMODE=1, pages 0-31 (8K bytes) of the chip&#x27;s main memory are automatically write-protected and  
are not controlled by the R32_FLASH_WPR register. When read protection is disabled, all main memory pages  
are controlled by the R32_FLASH_WPR register.  
2) When DBMODE=0, pages 0-15 (4K bytes) of the chip&#x27;s main memory are automatically write-protected and  
not controlled by the R32_FLASH_WPR register. When read protection is disabled, all main memory pages are  
controlled by the R32_FLASH_WPR register.  
3) The system boot code area, SWD or SDI mode, and RAM regions cannot be erased or programmed. The  
user-selectable word area can be erased or programmed. If an attempt is made to disable read protection  
(programming user words), the chip will automatically erase the entire user area.  

## 46.3 FLASH Enhanced Read Mode

FLASH Enhanced Read Mode is suitable for user programs to run in FLASH, which can improve the access  
efficiency of FLASH. To enable this mode, set bit 1 of the EHMOD field in the R32_FLASH_ACTLR register.  
Then, read the ENHANCE_STATUS bit; if bit 1 of ENHANCE_STATUS is set, the enhanced read mode is active.  
To disable this mode, first clear bit 1 of EHMOD, then set RSENACT to 1.  
Note: When using FLASH enhanced reading mode, you should pay attention to the following points:  
1) Before performing any erase or program operations on the FLASH (including user programming such as read  
protection removal), you must first exit Enhanced Read Mode. Failure to do so will cause erase and program  
operations to fail.  
2) Before entering Stop Mode, you must first exit Enhanced Read Mode. Failure to do so may cause Stop Mode to  
malfunction.  
3) After a power reset or system reset completes, the chip automatically exits Enhanced Read Mode under  
hardware control.
