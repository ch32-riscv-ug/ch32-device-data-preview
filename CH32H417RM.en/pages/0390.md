### 22.3.3 I3C Slave Status and Programming Sequence

In this section, we provide a complete programming sequence when I3C peripheral is the slave device, covering  
state transition, main subtasks and conditions.  
<strong>Slave device initialization</strong>  
When the slave device is in the forbidden state (the EN bit in R32_I3C_CFGR register is 0), the software must  
follow the following steps to initialize:  
● Configure R32_I3C_CFGR register, set CRINIT to 0, and set I3C peripheral as slave.  
● Clear DEV_SIE_RST bit in R32_I3C_RESET register.  
● Set I3C bus timing through I3C timing register 1(R32_I3C_TIMINGR1): Write AVAL[7:0] to set:  
– Bus Available Condition Time (tAVAL), for IBI or master role requests  
– Bus Idle Condition Time (tIDLE), for hot join requests  
– tNEWCRLock, for master role transition process (after GETACCCRCCC)  
● Configure the request initiated by the device: write the following bits in I3C&#x27;s own device characteristic  
register (R32_I3C_DEVR0):  
– IBIEN: In-band interrupt (also known as IBI) request enable/disable  
– CREN: Controller role enable/disable  
– HJEN: Hot join enable/disable  
● Initialize slave device features and functions  
● Configure the execution mode of the transmission:  
In the R32_I3C_CFGR register, TXDMAEN and RXDMAEN enable/disable DMA mode for the TX-FIFO and  
RX-FIFO, respectively; TXTHRES and RXTHRES represent the byte/word thresholds for the TX-FIFO and  
RX-FIFO, respectively; SMODE bit 0 disables the S-FIFO.  
● Configure the R32_I3C_INTENR register to set interrupt generation or polling mode for any event  
● After initialization completes, set EN to 1 to enable the I3C peripheral  
<strong>Receive a message (broadcast CCC, direct read/write CCC or private read/write) from the master device</strong>  
When the slave device is in an idle state (the EN bit in the R32_I3C_CFGR register is 1), it means that it is ready  
to receive the communication message from the master device on the I3C bus and ready to switch to the working  
state.  
In the active state, the slave device first receives the broadcast ENTDAA CCC (possibly after receiving the  
optional broadcast ENEC/DISEC CCC), then is assigned a dynamic address. The DAUPF event in the  
R32_I3C_EVR register is set to 1, and a corresponding interrupt is generated (if enabled). The slave device  
subsequently returns to the idle state.  
Thereafter, the slave device in idle state is ready to receive any additional broadcast CCC messages, direct  
read/write CCC messages, or private read/write messages from the master device.  
<strong>Read message status register</strong>  
For each message received without errors, the hardware will update the I3C status register (R32_I3C_STATR) to  
report that an exchange message has been transmitted on the I3C bus, and the software will be notified by the  
corresponding flag in the I3C event register (R32_I3C_EVR) or the corresponding interrupt in the I3C interrupt  
enable register (R32_I3C_INTENR).
