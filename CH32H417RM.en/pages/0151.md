# Chapter 9 GPIO and Alternate Functions (GPIO/AFIO)

The chip incorporates six sets of GPIO ports (PA0~PA15, PB0~PB15, PC0~PC15, PD0~PD15, PE0~PE15,  
PF0~PF14), totaling 95 GPIO pins. Most pins can be software-configured as output (push-pull or open-drain),  
input (with or without pull-up/pull-down resistors), or as multiplexed peripheral function ports.  
Pins PA9 to PA12, PC13 to PC15, and PE3 to PE6 are powered by VDD33, rated at 3.3V. When VDD33 is  
de-energized, pins PC13 to PC15 automatically switch to being powered by VBAT.  
Pins PA0~PA8, PB2~PB7, PB15, PC4~PC5, PD8, PE2, and PF6–PF10 are powered by VDDIO, rated at 3.3V, and  
support 1.8V, 2.5V, and 3.3V power supplies.  
High-speed pins PA13~PA15, PB0~PB1, PB10~PB14, PC0~PC3, PC6~PC12, PD0~PD7, PD9~PD15, PE0~PE1,  
PE7 to PE15, PF0 to PF5, PF11 to PF14 are powered by VIO18. The built-in I/O pin voltage regulator supports  
1.2V, 1.8V, 2.5V, and 3.3V voltages with dynamic power supply voltage switching. It supports configuring the  
default voltage on the XO pin after power-up. For specific configuration details, refer to the [12:9] field of the  
PWR_CTLR register.  

## 9.1 Main Features

Each pin of the port can be configured into one of the following modes:  
● Floating input  
● Pull-up input  
● Pull-down input  
● Analog input  
● Open-drain output  
● Push-pull output  
● Input and output of alternate function  
Many pins have alternate functions, and many other peripherals map their own output and input channels to these  
pins. The specific application of these alternate pins needs to be with reference to each peripheral, and this chapter  
shall specify whether these pins are alternate and remapped.
