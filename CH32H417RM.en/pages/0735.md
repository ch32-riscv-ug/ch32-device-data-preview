# Chapter 33 SD/EMMC Controller (SDMMC)

<strong><em>This chapter&#x27;s module description applies only to the CH32H417, CH32H416 microcontroller product.</em></strong>  
The system provides one SDMMC controller host/slave interface with a maximum transmission clock of 200MHz.  
It supports 1-wire, 4-wire, and 8-wire communication modes, as well as dual-edge sampling. External devices  
such as SD/TF cards and eMMC cards can be connected. Application code can flexibly configure various  
parameters including data transmission/reception commands, response packet formats, valid data packet modes  
and lengths, and dual-buffer length switching thresholds.  
<em>Note: When using 1-wire or 4-wire mode, unused data lines corresponding to GPIO pins cannot be repurposed for</em>  
<em>output. They may be used for input multiplexing or as general-purpose GPIO outputs.</em>  

## 33.1 Main Features

● Support SD physical layer 1.0 and 2.0 specifications, as well as UHS-I SDR50, DDR50, and SDR104 modes  
compliant with SD 3.0 specifications  
● Compliant with EMMC Card Specifications 4.4 and 4.5.1; supports HS200 and HS400 modes per EMMC  
Card Specification 5.0  
● Communication modes support single-wire, four-wire, and eight-wire configurations  
● Maximum communication clock single-edge up to 200MHz, dual-edge up to 180MHz  
● Support dual-edge sampling  
● Flexible configurable packet length, command format, and response status  
● Provide hardware-automated clock stop function during data block intervals  
● Support SD cards, SDIO cards, eMMC cards, and other devices compliant with SD interface protocols  
● Support SDIO slave interface, enabling data exchange with chips featuring SDIO host interfaces  
● DMA dual-buffering capability  

## 33.2 Register Description


### 33.2.1 Communication Clock

<strong>● Frequency configuration</strong>  
The controller interface provides two clock modes: low-speed mode and high-speed mode. Generally, the SD  
protocol stipulates that the communication clock of about 400kHz should be used for the early initialization of the  
equipment with SD interface to ensure better communication compatibility. When the parameter information of  
the external equipment is obtained, it can be switched to a higher clock frequency for communication according to  
its internally supported configuration.  
Set the bit9 of R16_EMMC_CLK_DIV register to select the clock mode, and set the bit[4:0] frequency division  
value to get the final SDIO interface output clock. Bit8 controls whether the EMMC peripheral outputs a clock  
signal to the MSDCK pin, and it is necessary to ensure that the IO mode of the MSDCK pin is configured as  
push-pull output.  
<strong>● Phase configuration</strong>  
When communicating with external SDIO interface devices, due to high clock frequency, hardware wiring, device  
characteristics and other factors, signal sampling errors will occur.
