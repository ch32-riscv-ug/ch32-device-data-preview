#### 4.2.3.3 Machine Cycle Counter Register (MCYCLE)

CSR address: 0xB00  

<!-- p71-table-001 (table-4-6@1) -->
<table><tr><th>Bit</th><th>Name</th><th>Access</th><th>Description</th><th>Reset value</th></tr><tr><td>[31:0]</td><td>mcyle[31:0]</td><td>MRW</td><td style="text-align:left">Machine cycle counter, used to count the clock cycles of machine operation. Counting occurs when the CY bit in the MCOUNT_INHIBIT register is set to 0. Counting is disabled when the counter is stopped in debug mode.</td><td>0</td></tr></table>


#### 4.2.3.4 Machine Instruction Counter Register (MINSTRET)

CSR address: 0xB02  

<!-- p71-table-002 (table-4-6@1) -->
<table><tr><th>Bit</th><th>Name</th><th>Access</th><th>Description</th><th>Reset value</th></tr><tr><td>[31:0]</td><td>minstret[31:0]</td><td>MRW</td><td style="text-align:left">Instruction count register, used to count the number of instructions correctly executed and completed by the machine. Counting occurs when the IR bit in the MCOUNT_INHIBIT register is set to 0. Counting is disabled when the counter is stopped in debug mode.</td><td>0</td></tr></table>


#### 4.2.3.5 User Mode Cycle Counter Register (UCYCLE)

CSR address: 0xC00  

<!-- p71-table-003 (table-4-6@1) -->
<table><tr><th>Bit</th><th>Name</th><th>Access</th><th>Description</th><th>Reset value</th></tr><tr><td>[31:0]</td><td>ucyle[31:0]</td><td>RO</td><td style="text-align:left">User mode cycle counter, used to count the clock cycles during machine operation. Counting occurs when the CY bit in the MCOUNT_INHIBIT register is set to 0.<br>Counting is disabled when the counter is stopped in debug mode.</td><td>0</td></tr></table>

<em>Note: the user mode cycle counter has the same function as the mcycle register, and is used to read the number of</em>  
<em>running cycles of the machine in user mode.</em>  

#### 4.2.3.6 User Mode Instruction Counter Register (UINSTRET)

CSR address: 0xC02  

<!-- p71-table-004 (table-4-6@1) -->
<table><tr><th>Bit</th><th>Name</th><th>Access</th><th>Description</th><th>Reset value</th></tr><tr><td>[31:0]</td><td>uinstret[31:0]</td><td>RO</td><td style="text-align:left">Instruction count register, used to count the number of instructions correctly executed and completed by the machine. Counting occurs when the IR bit in the MCOUNT_INHIBIT register is set to 0. Counting is disabled when the counter is stopped in debug mode.</td><td>0</td></tr></table>
