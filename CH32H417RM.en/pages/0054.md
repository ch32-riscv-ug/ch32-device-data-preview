## 4.2 Privileged Register (CSR)

Both the RISC-V3F and RISC-V5F cores comply with the RISC-V standard privilege structure, supporting M and  
U modes, debug mode, and more. The cores define a subset of standard registers and custom registers.  

### 4.2.1 General Privilege Register

The RISC-V architecture defines a set of Control and Status Registers (CSRs) used to configure, identify, or  
record operational states. CSR registers are internal to the core and utilize a dedicated 12-bit address space.  
<em>Note: Registers marked with the “MRW, MRO, MRW1” attributes require the system to be in machine mode for</em>  
<em>access.</em>
