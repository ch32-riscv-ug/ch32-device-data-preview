# Chapter 11 Analog-to-digital Converter (ADC)

The ADC module contains two 12-bit n analog-to-digital converters with the highest 80MHz input clock. Support  
16 external channels and 2 internal signal source sampling sources. It can complete the functions of single  
conversion, continuous conversion, automatic scanning mode, discontinuous mode, external trigger mode and so  
on. You can monitor whether the channel voltage is within the threshold range by simulating the watchdog  
function.  

## 11.1 Main Features

● 12-bit resolution  
● 16 external channels and 2 internal signal sources for sample  
● Multiple sampling conversion modes for multiple channels: single, continuous, scan, trigger, discontinuous,  
etc.  
● Data alignment mode: Left alignment, right alignment  
● Sampling time can be programmed separately per channel  
● Both regular conversion and injected conversion support external trigger  
● Analog watchdog monitors the channel voltage  
● Dual mode  
● ADC channel input range: VSS≤VIN≤VDDIO  
● Adjustable input gain, to implement small signal amplification and sampling
