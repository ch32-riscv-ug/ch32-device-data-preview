### 2.3.2 Sleep Mode

In this mode, all IO pins keep their state in Run mode and all peripheral clocks are normal, so try to turn off  
useless peripheral clocks before entering Sleep mode to reduce low-power consumption. This mode takes the  
shortest time to wake up.  
Enter: Configure core register control bit SLEEPDEEP=0, LPDS determines internal regulator status, execute  
WFI or WFE, optionally SEVONPEND and SLEEPONEXIT.  
Exit: Any interrupt or wakeup event.  

### 2.3.3 Stop Mode

Sleep mode combines the clock control mechanisms of the peripherals with the fact that both the V3F and V5F  
cores enter deep sleep (SLEEPDEEP).  
When both V3F and V5F enter this mode: the high-frequency clock (HSE/HSI/PLL) domains are disabled, SRAM  
and register contents are preserved, and I/O pin states are maintained. Upon waking from this mode, the system  
can resume operation, with HSI serving as the default system clock.  
You can set LPDS=1 to switch the LDO regulator from normal mode to low-power mode, thereby achieving a  
state of lower power consumption.  
If flash programming is in progress, the system does not enter stop mode until access to memory is complete; if  
access to the PB is in progress, the system does not enter stop mode until access to the APB is complete.  
Modules that can operate in Stop mode: Independent Watchdog Dog (IWDG), Real Time Clock (RTC), Low  
Frequency Clock (LSI/LSE).
