If the original format does not include an alpha channel, the alpha value is automatically set to 0xFF (opaque).  
If the original format is in indirect color mode, a CLUT is required, and each pixel format converter is associated  
with a CLUT containing 256 32-bit entries.  
For specific alpha modes A4 and A8, neither color information is stored nor indexed. The colors used to generate  
the image are fixed, with the foreground layer pixel color defined in the R32_GPHA_FGCOLR register and the  
background layer pixel color defined in the R32_GPHA_BGCOLR register.

The ARGB8888 mode supports 32-bit alignment for 24-bit RGB888. After generating the 32-bit value, the alpha  
channel can be adjusted based on the AM[1:0] bits of the R32_GPHA_FGPFCCR/R32_GPHA_BGPFCCR  
registers. Specific configurations are detailed in Table 44-3.
