<strong>Input from memory (written directly by CPU/DMA)</strong>  
When CPU or DMA(DATMPX[1:0]=2) directly writes data into R32_DFSDM_CHyDATINR register, these data  
can be used as input to process digital data streams from memory or peripherals.  
Data can be written into R32_DFSDM_CHyDATINR register by CPU or DMA:  
1) CPU data writing:  
Input data is directly written into R32_DFSDM_CHyDATINR register by CPU.  
2) DMA data writing:  
DMA should be configured as a memory-to-memory transfer mode to transfer the data in the buffer area of the  
memory to the R32_DFSDM_CHyDATINR register. The target memory address is the address of the  
R32_DFSDM_CHyDATINR register. Data is transferred from memory to DFSDM parallel input at DMA transfer  
speed.  
This DMA is different from the DMA used to read the conversion result of DFSDM. These two DMA&#x27;s can be  
used at the same time. The first DMA (configured as memory-to-memory transfer) is used for input data writing,  
and the second DMA (configured as peripheral-to-memory transfer) is used for data result reading.  
The access to R32_DFSDM_CHyDATINR can be 16-bit or 32-bit wide, allowing one or two samples to be loaded  
in one write operation, respectively. The 32-bit input data register (R32_DFSDM_CHyDATINR) can be filled  
with one or two 16-bit data samples, depending on the data packing operation mode defined in the DATPACK[1:0]  
field of R32_DFSDM_CHyCFGR1 register:  
1) Standard Mode (DATPACK[1:0]=00b):  
Only one sample is stored in the INDAT0[15:0] field of the R32_DFSDM_CHyDATINR register, serving as input  
data for channel y. The upper 16 bits (INDAT1[15:0]) are ignored and write-protected. The digital filter must  
perform one input sample (via INDAT0[15:0]) to clear the data register after CPU/DMA fill. This mode combines  
with 16-bit CPU/DMA access to the R32_DFSDM_CHyDATINR register to load one sample per write operation.  
2) Interleaved Mode (DATPACK[1:0]=01b):  
The R32_DFSDM_CHyDATINR register functions as two sample buffers. The first sample is stored in  
INDAT0[15:0], and the second sample is stored in INDAT1[15:0]. The digital filter must perform two input  
samples through channel y to clear the R32_DFSDM_CHyDATINR register. This mode is combined with 32-bit  
CPU/DMA access to the R32_DFSDM_CHyDATINR register to load two samples per write operation.  
3) Dual-Channel Mode (DATPACK[1:0]=10b):  
Write 2 samples into the R32_DFSDM_CHyDATINR register. Data in INDAT0[15:0] is used for channel y, while  
data in INDAT1[15:0] is used for channel y+1. Data in INDAT1[15:0] is automatically copied to INDAT0[15:0]  
of the next (y+1) channel data register (DFSDM_CH[y+1]DATINR). The digital filter must perform two samples  
(one from channel y and one from channel (y+1)) to clear the R32_DFSDM_CHyDATINR register.  
Dual-channel mode configuration (DATPACK[1:0]=10b) is only possible for even channel numbers (y=0). If an  
odd channel (y=1) is set to dual-channel mode, both the INDAT0[15:0] and INDAT1[15:0] sections for that  
channel are write-protected. If an even channel is set to dual-channel mode, the next odd channel must be set to  
standard mode (DATPACK[1:0]=00b) to properly interface with the even channel.
