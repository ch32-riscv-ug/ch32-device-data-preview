Data Area: The first 64KB within the general/feature storage space; Command Area: The second 64KB within the  
general/feature storage space; Address Area: The next 128KB within the general/feature storage space.  
Application software utilizes these three areas to access the NAND Flash memory:  
● To send a command to NAND Flash, the software must write the command value to any memory cell within  
the command area.  
● To specify a read or write address for NAND Flash, the software must write the address value to any memory  
cell within the address area. Since the address length can be 4 or 5 bytes (depending on the actual memory  
size), specifying a complete address requires multiple consecutive write operations to the address area.  
● Read or write data: The software reads data from or writes data to any storage cell within the data region.  
● Since NAND Flash memory automatically increments addresses, it is unnecessary to increment addresses  
within the data region to access consecutive memory locations.  
Because NAND Flash memory will automatically increment the address, it can access continuous memory  
locations without incrementing the address of the data area.
