### 33.2.5 DMA Dual-buffer Function

The system provides DMA dual-buffering functionality, featuring two DMA address registers:  
R32_EMMC_DMA_BEG1 and R32_EMMC_DMA_BEG2, along with the data block length threshold  
RB_EMMC_DMATN_CNT for DMA switching. When the data block length threshold starting from the  
R32_EMMC_DMA_BEG1 register address completes transmission, the hardware switches to the address range  
set by R32_EMMC_DMA_BEG2 for data transfer. Upon reaching the transfer threshold, it cycles back to the  
R32_EMMC_DMA_BEG1 range. This process repeats until all data blocks configured by  
RB_EMMC_BKNUM_MASK are fully transferred.  
Each time non-zero data is written to the RB_EMMC_BKNUM_MASK field of the R32_EMMC_BLOCK_CFG  
register, a data transfer is initiated. Concurrently, the hardware directs DMA operations to the address range  
starting at R32_EMMC_DMA_BEG1. The flag-setting conditions during the transfer process remain consistent  
with the previously described behavior. Application code may optionally enable the corresponding interrupt flag  
to trigger the EMMC interrupt service routine.  

### 33.2.6 Slave Mode

<strong>Slave mode operation</strong>  
The hardware in slave mode only supports R1-type responses, so the R16_EMMC_CMD_SET register has no  
effect in slave mode.  
1) Host queries slave data status:  
The slave device pre-populates the ARGUMENT register with its desired data reception/transmission status. The  
host sends CMD13 to query the slave&#x27;s status and determines whether to read or write to the slave based on the  
response.  
<em>Note: The use of CMD13 and the bit definitions in the slave&#x27;s response are software-defined.</em>  
2) Host sends CMD18 to read multiple blocks:  
The CMD18 command parameter from the host no longer specifies a sector address but instead indicates the  
number of blocks to be read in this operation. Upon receiving the command interrupt, the slave configures the  
DMA address, sets the R32_EMMC_TRAN_MODE, reads the block count from the command parameter register,  
and writes it into the R32_EMMC_BLOCK_CFG register.  
2) Host sends CMD25 to write multiple blocks:  
The CMD25 command parameter from the host no longer specifies a sector address but instead indicates the  
number of blocks to be written in this operation. Upon receiving the command interrupt, the slave configures the  
DMA address and sets R32_EMMC_TRAN_MODE. It then reads the block count from the command parameter  
register and writes it into the R32_EMMC_BLOCK_CFG register.
