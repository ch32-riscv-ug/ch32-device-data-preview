### 42.3.15 Request Priority

Injected conversions take precedence over regular conversions. An ongoing regular conversion is immediately  
interrupted by an injected conversion request; this regular conversion will resume after the injected conversion  
completes.  
If an injected conversion is pending or in progress, no other injected conversion can be initiated: requests to start  
an injected conversion (via JSWSTART or trigger) are ignored as long as bit JCIP (in the R32_DFSDM_FLTxISR  
register) is set to 1.  
Similarly, if a regular conversion is pending or in progress, no other regular conversion can be initiated: requests  
to start a regular conversion (using RSWSTART) are ignored as long as bit RCIP (in the R32_DFSDM_FLTxISR  
register) is set to 1.  
However, if an injection conversion is requested during a regular conversion, the regular conversion stops  
immediately and the injection conversion begins. The regular conversion restarts afterward, and this delayed  
restart is indicated by the RPEND bit.  
Injection conversion takes precedence over regular conversion because it can temporarily interrupt a continuous  
sequence of regular conversions. Upon completing the injection conversion sequence, if RCONT remains set to 1,  
the continuous regular conversion will restart (the RPEND bit will issue a delayed start signal based on the result  
of the first regular conversion).  
Priority is also critical when initiating related operations through identical write operations to DFSDM, or if  
multiple operations remain pending at the conclusion of other operations. For example, assuming an injection  
conversion is in progress (JCIP=1), a single write operation to R32_DFSDM_FLTxCR1 writes 1 to RSWSTART  
to request a regular conversion. Upon completion of the injection sequence, the priority indicates execution of the  
subsequent regular conversion, with the corresponding delayed start indicated via the RPEND bit.  

### 42.3.16 Power Consumption Optimization in Running Mode

To reduce power consumption, the DFSDM filter and integrator automatically enter idle state (RCIP=0, JCIP=0)  
when not used for conversion.
