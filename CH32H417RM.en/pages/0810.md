<strong>Dual Flash Mode</strong>  
When the DFM bit (R32_QSPIx_CR[6]) is set to 1, QSPI enters dual flash mode. The QSPI utilizes 2 external  
four-wire SPIFLASHes (FLASH1 and FLASH2), transmitting/receiving 8 bits of data per cycle, effectively  
doubling throughput and capacity. Each FLASH uses the same SCK signal and may optionally share the same  
nCS signal, but their SIO0, SIO1, SIO2, and SIO3 signals are independent.  
Dual Flash mode can be combined with Single-bit mode, Dual-bit mode, Quad-bit mode, and SDR mode.  
Specify the FLASH size in FSIZE[4:0] (R32_QSPIx_DCR[20:16]). The specified parameter should reflect the  
total FLASH capacity, i.e., twice the capacity of a single component. When address X is even, the byte assigned  
by QSPI to address X is the byte stored at address X/2 in FLASH1. The byte assigned by QSPI to address X+1 is  
the byte stored at address X/2 in FLASH2. That is, bytes at even addresses are stored in FLASH1, while bytes at  
odd addresses are stored in FLASH2.  
In dual-flash mode, the number of bytes required to read the FLASH status register is twice that of single-flash  
mode. Specifically, since each FLASH provides 8 valid bits after executing the status register read instruction,  
QSPI must be configured for a data length of 2 bytes (16 bits), with QSPI receiving 1 byte from each FLASH. If  
each FLASH provides a 16-bit status, the QSPI must be configured to read 4 bytes to capture all status bits from  
both FLASHes in dual-flash mode. Consequently, the least significant byte in the data register is the least  
significant byte of FLASH1&#x27;s status register, while the next byte is the least significant byte of FLASH2&#x27;s status  
register. The third byte in the data register is the second byte of FLASH1, and the fourth byte is the second byte of  
FLASH2 (when the FLASH has a 16-bit status register).  
In dual flash mode, accesses must always be to an even number of bytes. Therefore, when DRM=1, bit 0 of the  
data length field (R32_QSPIx_DLR[0]) is always maintained as 1.  
In dual flash mode, the behavior of the FLASH1 interface signals is essentially identical to that in normal mode.  
During instruction, address, alternate byte, and empty instruction cycle phases, the waveforms of the FLASH2  
interface signals are identical to those of the FLASH1 interface signals. That is, each FLASH always receives the  
same instruction and address. Subsequently, during the data phase, the SIOx and SIOXx buses transmit data in  
parallel, but the data sent to (or received from) FLASH1 differs from that in FLASH2.  

### 37.3.3 QSPI Indirect Mode

In indirect mode, the command is triggered by writing to the QSPI register; Data is transmitted by reading and  
writing data registers in the same way as other communication peripherals.  
When FMODE=00b (R32_QSPIx_CCR[27:26]), the QSPI operates in indirect write mode, transmitting bytes to  
the FLASH during the data phase. Data is provided by writing to the data register (R32_QSPIx_DR). When  
FMODE=01b, QSPI operates in indirect read mode, receiving bytes from FLASH during the data phase. Data is  
acquired by reading from the data register (R32_QSPIx_DR).
