# Chapter 28 Controller Area Network (CAN)

Controller Area Network is a high-performance communication protocol for serial data communication. The CAN  
controller provides a complete implementation of the CAN protocol, supporting CAN protocols 2.0A and 2.0B.  
The CAN controller can be used to construct a powerful local area network to realize safe distributed real-time  
control, process a large number of data packets with a small CPU load, and has a wide range of applications in the  
industrial and automotive fields.  

## 28.1 Main Features

● Compatible with CAN specification 2.0A and 2.0B (active)  
● Programmable transfer rate up to 1Mbit/s  
● Support time-triggered communication function to avoid low-priority message blocking  
● Support 3 sending mailboxes, the priority of sending messages can be determined by the message identifier  
or the order of sending requests, and can record the time stamp of the SOF moment of sending the message  
● Each CAN group supports 2 receive FIFOs with 3 levels of mailbox depth. A total of 42 filter groups are  
available for configuration across three CANs. Each filter group can be configured in 32-bit or 16-bit mode,  
using mask bits or identifier list mode. This minimizes software intervention in message filtering. FIFO  
overflow handling is flexible and can record timestamps for the SOF moment of received messages.  
● Occupies 4 interrupt vectors, each interrupt source can be configured independently  

## 28.2 CAN Controller Operating Mode

The CAN controller can operate the SLEEP or INRQ bits in the register CAN_CTLR to switch between the  
initialization mode, sleep mode and normal mode.  

### 28.2.1 Initialization Mode

After reset, CAN works in sleep mode by default to reduce power consumption. At this time, the sending and  
receiving of messages is prohibited, the internal pull-up resistor of the TX pin is enabled, and the TX pin outputs a  
recessive bit. The INRQ bit in the register CANx_CTLR is set to 1, and the CAN controller is requested to enter  
the initialization mode. When the INAK bit of the register CANx_STATR is automatically set to 1, the  
initialization state is successfully entered. Similarly, clear the INRQ bit in the register CANx_CTLR to request the  
CAN controller to exit the initialization mode. When the INAK bit of the register CANx_STATR is automatically  
cleared to 0, the initialization state is successfully exited.  
The filter group can be initialized in the non-initialization mode, but the FINIT bit of the register CANx_FCTLR  
must be set to 1, and the reception of the message is prohibited at this time.  

### 28.2.2 Sleep Mode

For the SLEEP position 1 in the register CANx_CTLR, the CAN controller is requested to enter the sleep mode.  
When the SNAK bit of the register CANx_STATR is automatically set to 1, the CAN successfully enters the sleep  
mode, and the clock of the CAN controller stops, but the mailbox register can still be accessed.
