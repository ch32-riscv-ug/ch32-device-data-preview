#### 18.2.2.3 Data Format:

In single DAC channel mode, data formats include 8-bit right alignment, 12-bit left alignment and 12-bit right  
alignment.  
When 8-bit data is right-aligned, write data to DAC_R8BDHRx[7:0], and the module will load (after 1 HB clock  
cycle) its left-shifted data to the data output register DAC_DORx[11:4].  
When 12-bit data is right-aligned, write data to DAC_R12BDHRx[11:0], and the module will load (after 1 HB  
clock cycle) right-aligned data into the data output register DAC_DORx[11:0].  
When 12 data are left-aligned, write the data to DAC_L12BDHRx[15:4]. After the corresponding shift, the  
module will load (after 1 HB clock cycle) the left-aligned data to the data output register DAC_DORx[11:0].

In dual DAC channel mode, there are also three methods: 8-bit data right alignment, 12-bit data left alignment,  
and 12-bit data right alignment.  
For 8-bit data right-aligned, write data to DAC_RD8BDHR[7:0], the module will load (after 1 HB clock cycle)  
bits [7:0] shifted to DAC_DOR1[11:4] and bits [15:8] shifted to DAC_DOR2[11:4].  
For 12 data left-aligned, write data to DAC_LD12BDHR[31:0], the module will load (after 1 HB clock cycle)  
bit[15:4] data shifted to DAC_DOR1[11:0] and bit[31:20] data shifted to DAC_DOR2[11:0].  
12-bit data right-aligned, write data to DAC_RD12BDHR[31:0], the module will load (after 1 HB clock cycle)  
bit[11:0] data to DAC_DOR1[11:0] and bit[27:16] data to DAC_DOR2[11:0].

#### 18.2.2.4 DMA Capability:

DAC channel has the DMA capability. Set the DMAENx bit in the DAC_CTLR register to 1, to enable DMA of  
the corresponding channel. When a trigger event occurs (Software trigger not included), a DMA request is  
generated. And then the data in the DAC_DORx register can be updated.  

#### 18.2.2.5 Trigger Event Selection:

DAC conversion can be triggered by the following events. When the TENx bit in the DAC_CTLR register is set  
to 1, a trigger event to trigger DAC conversion can be selected by configuring the TSELx[2:0] bits.
