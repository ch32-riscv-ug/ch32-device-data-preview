### 34.4.14 System Configuration Register (SFR_CTRL_RD)

The System Configuration Register provides control bits for the host and status bits for bidirectional data  
exchange.  
SB_INT_REQ is fully controlled by the eMCU to request interrupts or cancel requests to the host. However, the  
host can clear SB_INT_REQ to 0 by performing a dummy write operation to the read-only register  
SFR_CTRL_RD. Writing to SFR_CTRL_RD has no practical effect on its data.  
After the eMCU writes to SFR_CTRL_RD, SB_DATA_SW_MR is automatically set to 1. After the host reads  
SFR_CTRL_RD, SB_DATA_SW_MR is automatically cleared to 0.  
After the host writes to SFR_CTRL_WR, SB_DATA_MW_SR is automatically set to 1. After the eMCU reads  
SFR_CTRL_WR, SB_DATA_MW_SR is automatically cleared to 0.  
SB_MST_CLK_GATE also controls the multiplexing of the eMCU program ROM. When SB_MST_CLK_GATE  
is 0, it is dedicated to the host-side system SRAM, totaling 4K bytes, enabling dynamic loading of new programs  
for the eMCU. When SB_MST_CLK_GATE is 1, it is dedicated to the eMCU program ROM, containing 2K  
instructions.  
Bits 0 to 4 of the system configuration register are fully controlled by the host and are read-only on the eMCU  
side.  
The following table describes the system configuration register SFR_SYS_CFG.
