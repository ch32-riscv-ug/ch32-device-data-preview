### 46.5.6 Main Memory Fast Programming

The fast programming (256 bytes) is made according to the page.  
1) Check the LOCK bit of the R32_FLASH_CTLR register. If it is &#x27;1&#x27;, you need to perform the &quot;unlock flash&quot;  
operation.  
2) Check the R32_FLASH_CTLR register FLOCK bit, if it is &#x27;1&#x27;, you need to perform a &quot;quick programming  
mode unlock&quot; operation.  
3) Check the BSY bit of the R32_FLASH_STATR register to confirm that there are no other programming  
operations in progress.  
4) Set the FTPG bit of the R32_FLASH_CTLR register to &#x27;1&#x27; to enable fast page programming mode.  
5) Write data to a FLASH address in a 32-bit manner, such as.  
- (uint32_t*) 0x80000000=0x12345678.
6) Wait for WRBSY of R32_FLASH_STATR register to be &#x27;1&#x27;, and write the next data.  
7) Repeat steps 5-6 64 times  
8) Set the FTPG bit in R32_FLASH_CTLR register to&#x27; 1&#x27; to start fast page programming.  
9) Waiting for the BSY bit to change to &#x27;0&#x27; or the EOP bit of the FLASH_STATR register to &#x27;1&#x27; means that a quick  
page programming is completed and the EOP bit is cleared to 0.  
10) Query the R32_FLASH_STATR register to see if there are any errors, or read the programming address data  
check.  
11) Continue fast page programming to repeat steps 5-10 and end the programming to clear the FTPG bit 0.  

### 46.5.7 Main Memory Fast Erasure

Fast erase erases in blocks.  
1) Check the R32_FLASH_CTLR register LOCK bit, if it is &#x27;1&#x27;, you need to perform the &quot;unlock flash memory&quot;  
operation.  
2) Check the R32_FLASH_CTLR register FLOCK bit, if it is &#x27;1&#x27;, you need to perform a &quot;fast programming mode  
unlock&quot; operation.  
3) Check the BSY bit of the R32_FLASH_STATR register to confirm that there are no other programming  
operations in progress.  
4) Set the FTER bit of the R32_FLASH_CTLR register to &#x27;1&#x27;, and turn on the fast page erasure mode function.  
5) Write the first address of the quick erase page to the R32_FLASH_ADDR register.  
6) Set the STAT bit of the R32_FLASH_CTLR register to &#x27;1&#x27; to start a quick page erase (256byte) action.  
7) Wait for the BSY bit to change to&#x27;0&#x27; or the EOP bit of the R32_FLASH_STATR register to &#x27;1&#x27; means the erasure  
is over, and the EOP bit is cleared to 0.  
8) Query the R32_FLASH_STATR register to see if there are any errors, or read the erase page address data  
check.  
9) Continue to quickly erase the page and repeat steps 5-8 to end the erase to clear the FTER bit 0.  
<em>Note: After successful erasure, the byte reads -0xe339e339, the half-byte reads -0xe339, the even-address byte</em>  
<em>reads -0x39, and the odd-address byte reads 0xe3.</em>
