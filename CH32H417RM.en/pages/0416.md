● R32_I3C_STATR contains the status of the last transmitted message.  
● The SCL clock does not pause if the status register is not read.  
When SMODE=0, that is, the slave device ends the private read transmission in advance under certain  
circumstances:  
● Notify the software by setting the RXTGTENDF bit in the R32_I3C_EVR register to 1 and triggering the  
corresponding interrupt (if enabled).  
● Then, before the software clears the event flag by writing a 0 to the CRXTGTENDF bit in the  
R32_I3C_CEVR register:  
–No further data bytes are received on the I3C bus and are written to the R32_I3C_RDR/R32_I3C_RDWR  
registers by hardware  
–The R32_I3C_STATR register cannot be updated  
–Pause the SCL clock (if necessary)  
Under normal circumstances, the R32_I3C_STATR register can be read when FCF=1, ERRF=1, or  
RXTGTENDF=1 in the R32_I3C_EVR register. After the slave device prematurely terminates the read transfer,  
the number of valid data bytes received during the private read transfer can be obtained by reading XDCNT[15:0]  
in the R32_I3C_STATR register.  
<strong>Read status register when S-FIFO is enabled</strong>  
If the SMODE bit in the R32_I3C_CFGR register is set to 1, the S-FIFO is enabled.  
Figure 22-18 illustrates how to manage the S-FIFO to queue and pop up the status word of each message executed  
on the I3C bus when the I3C peripheral is used as the master device.
