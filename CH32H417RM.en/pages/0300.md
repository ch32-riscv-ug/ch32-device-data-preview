### 16.2.2 Difference between Basic Timer and General-purpose Timer

Compared with the general timer, the basic timer lacks the following functions:  
1) The basic timer lacks count-down mode and count-up mode.  
2) The basic timer lacks 4-channel independent comparison capture channels.  
3) The basic timer does not support external signal control timer.  
4) The basic timer does not support incremental coding, cascade and synchronization between timers.  

### 16.2.3 Clock Input

The clock of the basic timer is provided by the internal clock CK_INT.  

### 16.2.4 Counter and Periphery

CK_PSC is input to the prescaler (PSC) for frequency division. The PSC is 16-bit, and the actual division factor  
corresponds to the value of R16_TIMx_PSC plus one. CK_PSC becomes CK_CNT after passing through the PSC.  
Changing the value of R16_TIM1_PSC does not take effect immediately but is updated to the PSC after an update  
event. Update events include clearing the UG bit and performing a reset. An Auto-Trigger Register (ATRLR) can  
be configured to set a counter threshold. When the CNT count value reaches the threshold stored in the ATRLR,  
the CNT is reset to zero.  

## 16.3 Debug Mode

When the system enters debug mode, the timer continues to run or stops according to the setting of the DBG  
module.
