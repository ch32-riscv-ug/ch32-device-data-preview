### 17.3.12 Debug Mode

When MCU enters modal mode (core stops), LPTIM continues to work properly.

## 17.4 LPTIM Interrupt

An interrupt / wake-up occurs if the following events are enabled through the LPTIM_IER register:  
● Compare match.  
● Automatic overload matching.  
● External trigger event.  
● Automatic overload register write complete.  
● Comparison register write complete.  
● Direction change (encoder mode)  

<!-- p314-table-002 (table-17-8@1) -->
<table><caption>Table 17-8 Interrupt event</caption><tr><th>Interrupt event</th><th>Description</th></tr><tr><td>Compare match</td><td style="text-align:left">An interrupt flag is generated when the value of the counter register LPTIMx_CNT is equal to the value of the comparison register LPTIM_CMP</td></tr><tr><td>Automatic overload match</td><td style="text-align:left">An interrupt flag occurs when the value of the counter register LPTIMx_CNT is equal to that of the automatic reload register LPTIMx_ARR</td></tr><tr><td>External trigger event</td><td style="text-align:left">An interrupt flag is generated when an externally triggered event is detected</td></tr><tr><td style="text-align:left">Automatic overload register write complete</td><td style="text-align:left">An interrupt flag is generated when the write operation to the LPTIMx_ARR register is completed.</td></tr><tr><td style="text-align:left">Comparison register write complete</td><td style="text-align:left">An interrupt flag is generated when the write operation to the LPTIMx_CMP register is completed.</td></tr><tr><td>Change of counting direction</td><td style="text-align:left">When used in encoder mode, two interrupt flags are embedded in the direction of the signal:<br>Up sign: indicates a change in the direction of the upward count.<br>Downward sign: indicates a change in the downward counting direction.</td></tr></table>
