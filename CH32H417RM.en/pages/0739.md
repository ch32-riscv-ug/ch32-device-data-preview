<strong>Slave error processing</strong>  
The slave responds to host commands with an R1-type acknowledgment, where the response parameter is the  
value of the slave&#x27;s ARGUMENT register. If the slave fails to acknowledge the host due to a CRC error during  
command reception, the host should retry the current command.  
If the slave experiences an internal FIFO overflow during transmission or reception, the hardware automatically  
forces the current data block to be CRC-erroneous, signaling transmission issues to the host. Alternatively,  
software can set RB_SLV_FORCE_ERR to force transmission of the erroneous CRC block.  
The slave hardware parses a special command, CMD63, to simplify the slave software&#x27;s handling of transmission  
errors. If a CRC error occurs during host transmission or reception, the host immediately sends CMD63. Upon  
receiving CMD63, the slave software must reset the data state machine. The hardware automatically sets the DMA  
address to the starting address of the previous erroneous packet. Once master-slave negotiation resumes  
transmission, for read operations, the slave software only needs to set the block count in  
R32_EMMC_BLOCK_CFG. For write operations, the software configures the block count in  
R32_EMMC_BLOCK_CFG and writes to the RESPONSE3 register to complete retransmission and resume data  
transfer.  
<strong>Dual buffer mode</strong>  
If the slave operates in dual-buffered mode, and an error occurs while the master reads the last block of data from  
buf0, the master will send CMD63 during the transmission of the first block of buf1 to indicate a CRC error in the  
previous packet. Therefore, the slave should only update the data in buf0 after the first block of buf1 has been  
successfully transmitted. The newly added interrupt bit RB_SIF_SLV_BUF_RELEASE is generated when the  
first sector of the new buffer is successfully transmitted.

<strong>DDR mode</strong>  
Support DDR mode under 4-wire and 8-wire.  
1) 4-wire DDR mode:  
That is, through the rising edge and falling edge of the clock, data is output and sampled to improve the data  
transmission rate. When applied, 4-wire mode register and DDR mode register should be enabled.
