Injection conversion or regular conversion at FAST=0 (or first conversion at FAST=1):  
For Sincx filters (x=1..5):  
t=CNVCNT/fDFSDMCLK=[FOSR*(2IOSR+FORD+1)+2]/fCKIN  
For FastSinc filters:

Regular conversion when FAST=1 (except first conversion):  
For Sincx and FastSinc filters:  
t = CNVCNT/fDFSDMCLK= [FOSR*2IOSR]/fCKIN  
If FOSR=FOSR[9:0]+1=1 (filter bypassed, only integrator active), then:  
t=2IOSR/fCKIN(...but CNVCNT=0)  
Among them:  
1) fCKIN is the channel input clock frequency (at the CKINy pin of the given channel) or the input data rate (for  
parallel data input);  
2) FOSR is the filter oversampling rate: FOSR= FOSR[9:0] + 1 (refer to the R32_DFSDM_FLTxFCR register);  
3) 2IOSR is the integrator oversampling rate (refer to the R32_DFSDM_FLTxFCR register);  
4) FORD is the filter order: FORD= FORD[2:0] (refer to the R32_DFSDM_FLTxFCR register).  
<strong>Channel Offset Settings</strong>  
Each channel has its own offset setting (in the register), which will eventually be subtracted from each conversion  
result (injection or normal) of a given channel. Offset correction is performed after the data is shifted to the right.  
The offset value is stored as a 24-bit signed value in the OFFSET[23:0] field of R32_DFSDM_CHyCFGR2  
register.  
<strong>Right Shift of Data</strong>  
To align the result with a 24-bit value, each channel defines a series of right shifts that will be applied to each  
conversion result (injection or normal) of a given channel. The right shift number is stored in bits DTRBS[4:0] of  
R32_DFSDM_CHyCFGR2 register.  
Shift right rounds the result to the nearest integer value. The sign of the shifted result is preserved, so as to obtain  
the result data in a valid 24-bit signed format.  

### 42.3.3 Configuration Input Serial Interface

The following parameters must be configured for the input serial interface:  
● Output clock prescaler. With the programmable prescaler, the output clock (range 2 to 256) can be generated  
from the DFSDM clock. This setting is determined by the CKOUTDIV[7:0] bits in the  
R32_DFSDM_CH0CFGR1 register.
