#### 27.2.6.8 U1 Wake-up LFPS Duration Configuration Register (R8_LINK_U1_WKUP_FILTER)

Offset address: 0x1D  

<!-- p583-table-003 (table-27-18@1) -->
<table><tr><th>Bit</th><th>Name</th><th>Access</th><th>Description</th><th>Reset value</th></tr><tr><td>[7:0]</td><td style="text-align:left">U1_WKUP_FILTER</td><td>RW</td><td style="text-align:left">The valid duration of the LFPS received during U1 exit. The port sends LFPS for handshaking.<br>When the received LFPS reaches this duration,<br>the received U1 EXIT is considered valid. Pull high the sent LFPS_last to indicate successful handshaking. Default is 600ns.<br>U1_WKUP_FILTER[7]: Controls the time unit of U1_WKUP_FILTER[6:0];<br>1: U1_WKUP_FILTER[6:0] unit is in us,<br>duration is (n)us;<br>0: U1_WKUP_FILTER[6:0] unit is 8ns,<br>duration is (8n)ns, where n ranges from 0 to 124;<br>Note: When the duration exceeds 1ns, the configuration method with U1_WKUP_FILTER[7] set to 1 must be used;<br>otherwise, U1 cannot be awakened.</td><td>0x4A</td></tr></table>


#### 27.2.6.9 U2 Wake-up LFPS Duration Configuration Register (R8_LINK_U2_WKUP_FILTER)

Offset address: 0x2C  

<!-- p583-table-004 (table-27-18@1) pages 583-584 -->
<table><tr><th>Bit</th><th>Name</th><th>Access</th><th>Description</th><th>Reset value</th></tr><tr><td>[7:0]</td><td style="text-align:left">U2_WKUP_FILTER</td><td>RW</td><td style="text-align:left">The valid determination duration for LFPS received during U2 wake-up and loopback exit.
