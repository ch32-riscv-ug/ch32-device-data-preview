# Chapter 35 Operational Amplifier (OPA) and Comparator (CMP)

The module consists of 3 independently configurable operational amplifier (OPA1/OPA2/OPA3) and 1  
independently configurable voltage comparator (CMP). The operational amplifier (OPA) supports gain selection  
or can be used as a voltage comparator.  
The input and output of each operational amplifier are connected to the I/O port, and the input pin or gain is  
optional, and the output pin can be optionally configured to the universal I/O port or multiplexed as an ADC  
sampling channel. The external analog small signal is amplified into the ADC to achieve small-signal ADC  
conversion.  
The input and output of each voltage comparator are connected to the I/O port, and the input pins are optional, and  
the output pins can be optionally configured to the universal I/O port or multiplexed as an TIM internal sampling  
channel (without using the I/O pin).  

## 35.1 Main Features

● OPA input pin/output channel can be selected.  
● OPA1 output channel directly connected to comparator input  
● OPA supports voltage buffer (BUFFER) and programmable gain amplifier (PGA)  
● CMP input pin selectable  
● CMP positive input supports selectable DAC output; negative input supports selectable internal self-bias  
voltage  
● CMP supports selectable digital filtering and hysteresis  
● CMP output pin selectable as general-purpose I/O port or TIM internal sampling channel  

## 35.2 Function Description


### 35.2.1 OPA1/OPA2/OPA3

OPA1, OPA2, and OPA3 support voltage buffers (BUFFER) and programmable gain amplifiers (PGA). As shown  
in Figure 35-1, these 3 OPAs share essentially identical functionality. Compared to OPA2 and OPA3, OPA1  
features an additional output channel connected to the CMP_P2 input of the voltage comparator.  
In the R32_OPA_CTLR1 register: Setting the EN1 bit enables OPA1; Setting the PSEL1 bit selects the positive  
input channel for OPA1; Setting the NSEL1 bit selects the negative input channel for OPA1 or enables PGA mode  
to configure the internal gain of OPA1. Configuring the FB_EN1 bit enables the PGA mode feedback for OPA1.  
Configuring the PGADIF1 bit enables the differential input PGA mode, allowing OPA1 to function as a PGA in  
conjunction with NSEL1, with the N terminal connected to PA7. Configuring the HS1 bit enables high-speed  
mode, which improves slew rate in this mode. Configuring the MODE1[1:0] bits selects the output channel as  
either a GPIO or the positive input of a comparator.
