## 4.6 System Counter (SysTick)

The core incorporates two 32-bit up/down counters (SysTick) that can independently generate interrupt signals  
and are configurable to send interrupt requests to specified cores. The system counter operates at the same  
frequency as HCLK (V3F core frequency), while the RTC counter operates at HCLK/8.  
● Dual 32-bit timers  
● Up/down counting capability  
● •Configurable main clock and RTC clock counting  
● Configurable interrupt request core  
● • Configurable automatic reload
