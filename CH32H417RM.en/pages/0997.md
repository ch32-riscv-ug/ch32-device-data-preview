# Chapter 44 Graphics Processing Hardware accelerator (GPHA)

Image Processing Hardware Accelerator (GPHA) is a DMA dedicated to image processing, which supports  
indexed color mode or direct color mode and all classical color coding schemes. In addition, the GPHA module  
also has its own exclusive CLUT (Color Lookup Table).  

## 44.1 Main Features

● Support single HB master bus architecture  
● HB slave programming interface supports 8/16/32-bit access (except for 32-bit CLUT access)  
● Support programmable source and destination region sizes and offsets  
● Support programmable source and destination addresses across entire memory space  
● Support adjustable alpha values (source value, fixed value, modulation value)  
● Support hybrid operations with up to 2 sources  
● Support programmable source and target color formats, accommodating up to 11 color formats with a  
maximum of 32 bits per pixel  
● Support two internal memories for storing CLUTs in indirect color mode  
● Support programmable CLUT size, with CLUTs automatically loaded via CPU or programmed manually  
● Support internal timer control for HB bandwidth  
● Support three operating modes: register-to-memory, memory-to-memory with pixel format conversion, and  
memory-to-memory with pixel format conversion and mixing  
● Support filling specified portions or the entire area of the target image with a specific color  
● Support copying portions or the entire content of the source image to corresponding portions or the entire  
target image  
● Support copying portions or the entire content of the source image to portions or the entire target image with  
pixel format conversion  
● Support blending two source image sections and/or entire images with differing pixel formats, then copying  
the result to sections or the entire target image with differing color formats  
● Support canceling or suspending GPHA operations  
● Support generating interrupts upon bus errors or access conflicts  
● Support generating interrupts upon process completion  

## 44.2 Function Description


### 44.2.1 Overview

The foreground layer (FG)FIFO and background layer (BG)FIFO of GPHA acquire the input data to be copied  
and processed. These FIFO acquire pixels according to the preset color format in the corresponding pixel format  
converter (PFC), perform color format conversion, wherein the foreground layer and background layer can be  
processed separately or mixed, and finally output the converted color data. As shown in Figure 44-1, it shows the  
structural block diagram of GPHA in detail.
