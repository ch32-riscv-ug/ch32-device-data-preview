● Peripheral size set to 32 bits;  
● Enable memory increment mode;  
● Disable cycle mode;  
● Disable peripheral increment mode;  
● Disable memory-to-memory mode;  
● Set the number of words transferred to 8;  
● The destination address is the SWP frame buffer in RAM;  
● Set the data transfer direction to read from memory;  
● The source address is the R32_SWPMI_RDR register.  
Subsequently, the user performs the following actions:  
1) Set bit 1 in the RXDMA field of the R32_SWPMI_CR register;  
2) Set bit 1 in the RXBEIE field of the R32_SWPMI_IER register;  
3) Enable the data stream or channel within the DMA module.  
When the RXNE flag in the R32_SWPMI_ISR is set to 1, the SWPMI initiates a DMA request. During the DMA  
write operation to the R32_SWPMI_RDR register, the RXNE flag is automatically cleared.  
Within the SWPMI interrupt service routine, the user must check the RXBEF bit in the R32_SWPMI_ISR register.  
If this bit is set and additional frames remain to be transmitted, the user must perform the following actions:  
Disable data streams or channels in the DMA module;  
2) Read the number of bytes of frame payload received from the R32_SWPMI_RFL register;  
3) Read the frame payload from the RAM buffer;  
4) Enable the data stream or channel in the DMA module;  
5) Clear the RXBEF flag by setting bit CTXBEF in the R32_SWPMI_ICR register to 1. Refer to Figure 38-8 for  
details.
