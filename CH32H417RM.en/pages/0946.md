During input channel monitoring (AWFSEL=1), data for threshold comparison is sourced from the channel  
selected via the AWDCH[1:0] field (R32_DFSDM_FLTxCR2 register). The filter result from each selected  
channel is compared against a threshold pair (AWHT[23:0]/AWLT[23:0]). At this point, only the upper 16 bits  
(AWHT[23:8]/AWLT[23:8]) define the 16-bit threshold compared against the analog watchdog filter output, as  
the data from the analog watchdog filter has a maximum resolution of 16 bits. In this case (AWFSEL=1), the  
AWHT[7:0]/AWLT[7:0] bits are not compared.  
The parameters for the analog watchdog filter configuration of each input channel (filter order AWFORD[1:0] and  
filter oversampling rate AWFOSR[4:0]) are set in the R32_DFSDM_CHyAWSCDR register.  
The analog watchdog filter data for channel y can be read via firmware from the WDATA[15:0] field of the  
DFSDM_CHyWDATR register. If CHEN=1 in the R32_DFSDM_CHyCFGR1 register, this analog watchdog  
filter data is continuously converted at a data rate determined by the analog watchdog filter settings and the  
channel input clock frequency.  
The analog watchdog filter operates similarly to a conventional fast continuous conversion (without integrator).  
The number of serial samples required for the analog watchdog filter to output a result (with channel input clock  
frequency fCKIN) is:  
First conversion:  
For Sincx filters (x=1..5): Number of samples = [FOSR*(FORD+1)+2]  
For FastSinc filters: Number of samples = [FOSR*4+2+1]  
Subsequent conversion:  
For Sincx and FastSinc filters: Number of samples = [FOSR*FORD]  
Among them:  
FOSR, or Filter Oversampling Ratio: FOSR= AWFOSR[4:0] + 1 (refer to the R32_DFSDM_CHyAWSCDR  
register)  
FORD, or Filter Order: FORD= AWFORD[1:0] (refer to the R32_DFSDM_CHyAWSCDR register)  
For output data register monitoring (AWFSEL=0), comparison occurs after completing the final data right shift  
and offset correction (refer to the OFFSET[23:0] and DTRBS[4:0] fields in the R32_DFSDM_CHyCFGR2  
register). The comparison occurs after each injection or regular conversion of the channel selected by the  
AWDCH[1:0] field (in the R32_DFSDM_FLTxCR2 register).  
The status of simulated watchdog events is reflected in the R32_DFSDM_FLTxAWSR register, which locks the  
given event. The AWHTF[y]=1 flag indicates whether the AWHT[23:0] value has been exceeded on channel y.  
The AWLFTF[y]=1 flag indicates whether the AWLT[23:0] value has been exceeded on channel y. Events latched  
in the R32_DFSDM_FLTxAWSR register are cleared by writing a 1 to the corresponding clear bit CLRAWHTF[y]  
or CLRAWLTF[y] in the R32_DFSDM_FLTxAWCFR register.  

### 42.3.9 Short Circuit Detector

The purpose of the short-circuit detector is to signal within an extremely fast response time when an analog signal  
reaches saturation (exceeds full-scale range) and remains there for a specified duration. This feature detects  
short-circuit or open-circuit faults (e.g., overcurrent or overvoltage). Interrupts/events/open-circuit generation can  
be invoked.  
The short-circuit detector&#x27;s input data is derived from the channel transceiver output.  
Each input channel features an incrementing counter that tallies consecutive 0s or 1s on the serial data receiver  
output. If the received data stream changes (data signal transitions from 1 to 0 or from 0 to 1), the counter is reset.
