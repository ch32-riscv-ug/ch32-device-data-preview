The system SDIO controller&#x27;s host interface provides an output clock phase inversion (180° offset) function.  
Setting bit 10 of register R16_EMMC_CLK_DIV to 1 physically inverts the output clock signal, while the  
controller&#x27;s internal clock remains unchanged. This method allows adjustment of communication timing.  
<em>Note: At higher SDCLK frequency, if the recommended timing adjustment register value can&#x27;t communicate stably,</em>  
<em>users need to initiate a bus sampling tuning sequence to find a better sampling point.</em>  

### 33.2.2 Command Sending and Response

The 48-bit data packet with fixed command length sent by SDIO host interface to slave machine is transmitted  
serially on MCMD line. Some commands don&#x27;t need the slave to respond, and some commands need the slave to  
respond to reply packets or data packets with different lengths.  
● General command format: Start bit (0)+ Transmission bit (1)+ Command index+ Parameter +CRC7+ End bit  
- (1)
The start bit, data bits, CRC7, and stop bit are automatically filled by the hardware. The command index and  
parameters vary depending on the command and must be passed to the hardware controller by the application  
code. Configure the parameter field in the SD command by writing to the R32_EMMC_ARGUMENT register;  
Writing bits [5:0] of the R16_EMMC_CMD_SET register populates the command index, while bits [11:8] of this  
register configure the hardware&#x27;s expected response packet detection for this command. Writing to the  
R16_EMMC_CMD_SET register triggers the hardware to transmit the command packet sequence on the MCMD  
signal line.  
● Short Response Format: Start bit (0) + Transmission bit (0) + Command Index + Parameters + CRC7 + Stop  
bit (1)  
● Long Response Format: Start bit (0) + Transmission bit (0) + Reserved field (111111b) + Data + Stop bit (1)  
Slave response packets are categorized by length into 48-bit and 136-bit packets, with 32 bits and 128 bits of  
user-valid data respectively. After sending a host command, the R16_EMMC_INT_FG register can be queried. If  
the RB_EMMC_IF_CMDDONE flag is set to 1, the R32_EMMC_RESPONSE register can be read to obtain the  
valid data from the slave interface response packet. If the response packet is abnormal, corresponding flags in bits  
[2:0] of the R16_EMMC_INT_FG register will be set.  

### 33.2.3 Read Multiple Data Blocks Consecutively

For the operation of reading data (transmitted through data lines) in the SD protocol command, the following  
configuration is required:  
1) Initialization: Configure the R16_EMMC_CONTROL register to set the sampling edges for commands and  
data, the data bus width for transmission and reception, and enable DMA functionality. Configure the  
RB_EMMC_TOCNT_MASK bit in the R8_EMMC_TIMEOUT register to set the command timeout and data  
timeout durations. Configure the R32_EMMC_DMA_BEG1 register to set the DMA start address for storing  
read data. Configure the R32_EMMC_BLOCK_CFG register to set the single data block length during  
transfer and the total number of data blocks to be read. Configure the R32_EMMC_TRAN_MODE register to  
set the DMA transfer direction to “SD to Controller.” Optionally configure whether to automatically stop the  
clock during block transfer intervals, allowing sufficient time for application code to perform processing tasks  
before software resumes the transfer.  
2) Send commands to the SDIO slave interface device. These commands instruct the slave device to transmit  
data from the data bus to the host interface, such as CMD17 and CMD18 in the SD protocol.
