<strong>● Multiple timers ● 1 CAN interface (2.0B active):</strong>  
- 1×16-bit advanced-control timers, with dead zone - Some models support CAN FD protocol
control and emergency brake; can offer PWM ● USB 2.0 full-speed controller and PHY:  
complementary output for motor control - Support USB Host and USB Device  
- 2×16-bit general-purpose timers, provide input ● USB PD and Type C controller and PHY:
capture/output comparison/PWM - Support DRP, Sink and Source  
- 1×32-bit general-purpose timer - Support PDUSB
- 2 watchdog timers (independent watchdog and ● Fast GPIO port
window watchdog) - 37 I/O ports, support 16 external interrupts  
- <strong>SysTick: 64-bit counter ● Security features: Chip unique ID</strong>
<strong>● 4-group UART: Support LIN and ISO7816 ● Debug mode: 2-wire serial debug interface</strong>  
<strong>● 2 I2C interface: Support SMBus/PMBus (SDI)</strong>  
<strong>● 2 SPI interface ● Package: LQFP, QFN, QSOP, TSSOP</strong>
