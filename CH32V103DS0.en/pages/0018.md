<em>Note 1: Pin Type:</em>  
<em>I=TTL/CMOS Schmitt input; O=CMOS three-state output;</em>  
<em>A=Analog signal input or output; P= Power.</em>  
<em>Note 2: The value after the underscore of the remap function indicates the configuration value of the corresponding</em>  
<em>bit in the AFIO register. For example: TIM1_BKIN_1 indicates that the corresponding bit in the AFIO register is</em>  
<em>configured as 01b.</em>  
<em>Note 3: When the backup domain is powered by VDD(internal analog switch connected to VDD): PC14 and PC15</em>  
<em>can be used for GPIO or LSE pins, PC13 can be used as a GPIO, a TAMPER pin, an RTC calibration clock, an</em>  
<em>RTC alarm clock, or a second output; when used as an output pin, it can only work in the 2MHz mode with a</em>  
<em>maximum drive load of 30pF; when the backup domain is powered by VBAT(analog switch connected to BAT after</em>  
<em>VDD disappears): PC14 and PC15 can only be used for LSE pin, PC13 can be used as TAMPER pin, RTC alarm</em>  
<em>clock or seconds output.</em>  
<em>Note 4: For CH32V103 chip, pin 5 and pin 6 are configured as OSC_IN and OSC_OUT function pins by default</em>  
<em>after chip reset. Software can reset these two pins to PD0 and PD1 functions. For more detailed information, please</em>  
<em>refer to the Multiplexed Function I/O section and the Debug Setup section of the CH32xRM manual.</em>  
<em>Note 5: For the CH32V103R8T6 chip, pin 46 and pin 49 are configured as SWDIO and SWCLK function pins by</em>  
<em>default after chip reset. Software can reset these two pins for PA13 and PA14 functions; for CH32V103C6T6,</em>  
<em>CH32V103C8T6 and CH32V103C8U6 chips, pin 34 and pin 37 are configured as SWDIO and SWCLK function</em>  
<em>pins by default after chip reset. Software can reset these two pins to function as PA13 and PA14. Refer to the</em>  
<em>Multiplexed Function I/O section and the Debug Setup section of the CH32xRM manual for more details.</em>
