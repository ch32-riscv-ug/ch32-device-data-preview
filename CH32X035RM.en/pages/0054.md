### 7.5.4 Physical Memory Protection Unit (PMP)

To improve system security, a set of physical address access restrictions are defined in RISC-V&#x27;s architecture,  
which can set their read, write and execute attributes for the physical memory in the region, with a minimum  
region length of 4 bytes protected. the PMP unit is always in effect in user mode, and optionally in machine mode,
