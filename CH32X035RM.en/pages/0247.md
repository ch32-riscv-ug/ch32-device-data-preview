### 20.4.6 Main Memory Fast Erase

Fast erase is performed by page (256 bytes).  
1) Check the LOCK bit of FLASH_CTLR register, if it is 1, you need to perform the &quot;Unlock Flash Memory&quot;  
operation.  
2) Check the FLASH_CTLR register FLOCK bit, if it is 1, you need to perform the &quot;fast programming mode  
unlock&quot; operation.  
3) Check the BSY bit of FLASH_STATR register to make sure there is no other programming operation in  
progress.  
4) Set the FTER bit of FLASH_CTLR register to &#x27;1&#x27; to enable the fast page erase (256 bytes) mode function.  
5) Write the first address of the fast erase page to the FLASH_ADDR register.  
6) Set the STRT bit of FLASH_CTLR register to &#x27;1&#x27; to start a fast page erase (256 bytes) action.  
7) Wait for the BSY bit to become &#x27;0&#x27; or the EOP bit of FLASH_STATR register to become &#x27;1&#x27; to indicate the end  
of erase, and clear the EOP bit to 0.  
8) Query the FLASH_STATR register to see if there is an error or read the erase page address data checksum.  
9) Continue fast page erase can repeat steps 5-8, end erase to clear the FTER bit to 0.  
<em>Note: After a successful erase, the word reads - 0xFF.</em>  
Fast erase is performed by block (32K bytes).  
1) Check the FLASH_CTLR register LOCK bit, if it is 1, you need to perform the &quot;Unlock Flash&quot; operation.  
2) Check the FLASH_CTLR register FLOCK bit, if it is 1, you need to perform the &quot;fast programming mode  
unlock&quot; operation.  
3) Check the BSY bit of FLASH_STATR register to make sure there is no other programming operation in  
progress.  
4) Set the BER32 bit of FLASH_CTLR register to &#x27;1&#x27; to enable the fast block erase (32K bytes) mode function.  
5) Write the first address of the fast erase block to the FLASH_ADDR register.  
6) Set the STRT bit of FLASH_CTLR register to &#x27;1&#x27; to initiate a fast block erase (32K bytes) action.
