Master receive mode:  
The I2C module will receive data from the SDA line and write it into the data register via a shift register. After  
each byte, if the ACK bit is set, then the I2C module will send an answer low, and the RxNE bit will be set, and an  
interrupt will be generated if ITEVTEN and ITBUFEN are set. If RxNE is set and the original data is not read  
before the new data is received, the BTF bit will be set and SCL will remain low until the BTF is cleared, and  
reading R16_I2C1_STAR1 and then reading the data register will clear the BTF bit.
