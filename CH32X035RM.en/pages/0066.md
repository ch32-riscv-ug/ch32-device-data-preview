### 8.2.11 BC Function Configuration

The AFIO_CTLR register includes the control bits for the UDM/UDP pin of the BC interface, the source voltage  
and the port pull-up mode.  
Before the set operation of the BC_VSRC bit of UDM/UDP, it is necessary to operate the PUE[1:0] bits of  
UDM/UDP to set the pin to the pull-up mode, and this operation can enable the output of the BC protocol source  
voltage, VBC_SRC; and the read operation of the BC_CMPO bit of UDM/UDP can read the voltage of the pin with  
the BC protocol reference value VBC_REF status.
