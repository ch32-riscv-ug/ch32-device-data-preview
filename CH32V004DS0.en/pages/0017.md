<em>Note 1: Explanation of table abbreviations:</em>  
<em>I = TTL/CMOS level Schmitt input; O = CMOS level tri-state output.</em>  
<em>A = Analog signal input or output; P = Power supply.</em>  
<em>Note 2: The underlined value of the remapping function indicates the configuration value of the corresponding bit</em>  
<em>in the AFIO register. For example, TIM1_CH4_3 indicates that the corresponding bit in the AFIO register is</em>  
<em>configured as 011b.</em>  
<em>Note 3: For the CH32V004 chip, the PA4 and PD7 pins are shorted inside the chip to prevent both I/Os from</em>  
<em>being configured as output functions.</em>
