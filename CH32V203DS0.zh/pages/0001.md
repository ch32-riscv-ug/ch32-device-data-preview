# 概述

CH32V 系列是基于青稞 32位 RISC-V设计的工业级通用微控制器。全系产品加入硬件堆栈区、快  
速中断入口等设计，相比传统MCU提高了中断响应速度。CH32V203是基于32位RISC-V内核设计的工  
业级增强型低功耗通用微控制器，搭载青稞V4B内核，每MHz的工作和睡眠功耗同比大幅下降；支持  
144MHz主频零等待高性能运行，跑分性能/功耗比值远超传统MCU。CH32V203系列集成双路USB接口，  
支持USB Host 主机及 USB Device设备功能，具有1路 CAN 接口（2.0B 主动）、双路 OPA运放、4组  
USART、双路I2C，12位ADC，10路Touchkey等丰富外设资源。  

# 产品特性

● 内核Core： ● 2组运放、比较器：连接ADC和TIMx  
- 青稞32位RISC-V内核，多种指令集组合 ● 2组12位模数转换ADC：
- 快速可编程中断控制器+硬件中断堆栈 - 模拟输入范围：VSSA～VDDA
- 分支预测、冲突处理机制 - 16路外部信号+2路内部信号通道
- 单周期乘法、硬件除法 - 片上温度传感器
- 系统主频144MHz，零等待，高性能 - 双ADC转换模式
● 存储器： ● 16路TouchKey通道检测  
- 可配最大64KB易失数据存储区SRAM ● 双USB接口：
- 可配224KB程序存储区CodeFlash - USB2.0 全速设备接口（全速和低速）
（零等待应用区+非零等待数据区） - USB2.0 全速Host主机或设备接口  
- 28KB系统引导程序存储区BootLoader ● 多种通讯接口：
- 128B系统非易失配置信息存储区 - 4组USART接口
- 128B用户自定义信息存储区 - 2个I2C接口（支持SMBus/PMBus）
● 电源管理和低功耗： - 2个SPI接口  
- 系统供电VDD 供电范围：2.4～3.6V - 1组CAN接口（2.0B主动）
- 低功耗模式：睡眠、停止、待机 ● 多组定时器：
- VBAT 电源独立为RTC和后备寄存器供电 - 1个16位高级定时器，增加死区控制和紧急
- 待机模式典型电流0.5uA 刹车，提供用于电机控制的PWM互补输出
- 运行功耗低，约52uA/MHz - 3个16位通用定时器，提供输入捕获/输出比
● 系统时钟、复位： 较/PWM/脉冲计数及增量编码器输入  
- 内嵌出厂调校的8MHz的RC振荡器 - 1个32位通用定时器（适用于CH32V203RBx）
- 内嵌40KHz的RC振荡器 - 2个看门狗定时器（独立和窗口型）
- 内嵌PLL，可选CPU时钟达144MHz - 系统时基定时器：64位计数器
- 外部支持3～25MHz高速振荡器 ● 快速GPIO端口：
- 外部支持32.768KHz低速振荡器 - 37个I/O口，映射16个外部中断
- 上/下电复位、可编程电压监测器 ● 安全特性：CRC计算单元，96位芯片唯一ID
● 实时时钟RTC：32位独立定时器 ● 调试模式：串行2线调试接口  
● 1组8路通用DMA控制器 ● 封装形式：LQFP、QFN、TSSOP和QSOP  
- 8个通道，支持环形缓冲区管理
- 支持TIMx/ADC/USART/I2C/SPI
