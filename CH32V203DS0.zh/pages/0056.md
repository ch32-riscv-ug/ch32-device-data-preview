# 系列产品命名规则

举例： CH32 V 3 03 R 8 T 6  
产品系列  
F = 基于ARM内核，通用MCU  
V = 基于青稞RISC-V内核，通用MCU  
L = 基于青稞RISC-V内核，低功耗MCU  
X = 基于青稞RISC-V内核，专用架构或特殊IO  
产品类型  
0 = 青稞V2/V4内核，主频@48M  
1 = M3/青稞V3/V4内核，主频@72M  
2 = M3/青稞V4非浮点内核，主频@144M  
3 = 青稞V4F浮点内核，主频@144M  
产品子系列  
03 = 通用型  
05 = 连接型（USB高速、SDIO、双CAN）  
07 = 互联型（USB高速、双CAN、以太网、SDIO、FSMC）  
08 = 无线型（蓝牙BLE5.X、CAN、USB、以太网）  
35 = 连接型（USB、USB PD）  
引脚数目  
J = 8脚 A = 16脚 F = 20脚  
G = 28脚 K = 32脚 T = 36脚  
C = 48脚 R = 64脚 W = 68脚  
V = 100脚 Z = 144脚  
闪存存储容量  
4 = 16K闪存存储器  
6 = 32K闪存存储器  
7 = 48K闪存存储器  
8 = 64K闪存存储器  
B = 128K闪存存储器  
C = 256K闪存存储器  
封装  
T = LQFP U = QFN R = QSOP P = TSSOP M = SOP  
温度范围  
6 = -40℃～85℃  
7 = -40℃～105℃  
3 = -40℃～125℃  
D = -40℃～150℃
