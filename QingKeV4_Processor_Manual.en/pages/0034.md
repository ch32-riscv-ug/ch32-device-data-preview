## 7.2 Debug Interface

Different from the standard RISC-V defined JTAG interface, QingKe V4 series microprocessor using single /  
two-wire debugging interface, follow the WCH debugging interface protocol. The two-wire interface of V4A  
follows the interface protocol V1.0, while V4B, V4C, V4F, V4J follow the interface protocol V1.1. The  
debugging interface is responsible for the communication between the debug host and the debug module,  
and realizes the read/write operation of the debug host on the registers of the debug module. WCH designed  
WCH_Link and open source its schematic and program binary files, which can be used for debugging all
