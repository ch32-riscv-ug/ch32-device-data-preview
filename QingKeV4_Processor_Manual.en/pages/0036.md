# Chapter 8 CSR Register Lists

The RISC-V architecture defines a number of Control and Status Registers (CSRs) for controlling and  
recording the operating status of the microprocessor. Some of the CSRs have been introduced in the previous  
section, and this chapter will detail the CSR registers implemented in the QingKe V4 series microprocessors.

## 8.2 RISC-V Standard CSR Registers

<strong>Architecture Number Register (marchid)</strong>

which is mainly composed of vendor code, architecture code, series code, and version code. Each of them is
