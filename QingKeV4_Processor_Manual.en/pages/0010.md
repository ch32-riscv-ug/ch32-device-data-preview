<em>Note: 1. The default value of PFIC_ISR0 register is 0xC, which means that NMI and exception are always</em>  
<em>enabled by default.</em>  
<em>2.ECALL-M, ECALL-U, BREAKPOINT are all a case of EXC, the status is indicated by the status bit 3</em>  
<em>of EXC.</em>  
<em>3. NMI and EXC support interrupt pending clear and setup operation, but not interrupt enable clear</em>  
<em>and setup operation.</em>  
<em>4.ECALL-M, ECALL-U, BREAKPOINT do not support interrupt pending clear and set, interrupt enable</em>  
<em>clear and set operation.</em>  
Each register is described as follows.
