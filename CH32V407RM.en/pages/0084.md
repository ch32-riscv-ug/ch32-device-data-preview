## 9.4 Interrupt and Event (PFIC)


### 9.4.1 PFIC Controller

● Each interrupt request has independent trigger and mask control bits, and a dedicated status bit  
● Support up to configurable 2-level interrupt nesting  
● Unique fast interrupt entry and exit mechanism, automatic hardware push and restore, maximum  
hardware push depth of 2 levels, no instruction overhead  
● Vector Table Free (VTF) interrupt response mechanism, 4 programmable direct interrupt vector  
addresses
