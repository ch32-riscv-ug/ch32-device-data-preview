# Chapter 1 Memory and Bus Architecture


## 1.1 Bus Architecture

This series of chips is an industrial general-purpose microcontroller based on QingKe RISC-V3V core. Within  
this architecture, components such as the cores, arbitration unit, DMA module, and SRAM storage interact via  
multiple bus groups. The system block diagram is shown in Figure 1-1-1 and Figure 1-1-2.
