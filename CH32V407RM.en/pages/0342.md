# Chapter 20 Serial Peripheral Interface (SPI/I2S)

SPI supports data interaction in 3-wire synchronous serial mode, and the chip select line supports hardware  
switching between master and slave modes, supporting communication with a single data line.  
I2S is also a 3-wire synchronous serial interface communication protocol, which supports 4 audio standards,  
including Philips I2S standard, MSB alignment standard, LSB alignment standard and PCM standard.  

## 20.1 Main Features


### 20.1.1 SPI Features

● Support full-duplex synchronous serial mode  
● Support 1-wire half-duplex mode  
● Support master mode and slave mode, multi-slave mode  
● Support 8-bit or 16-bit data structures  
● The highest clock frequency is supported to half of Fpclk  
● Data ordering supports MSB or LSB first  
● Support hardware or software control of the NSS pin  
● Transceiver supports hardware CRC  
● Transceiver buffer supports DMA transfer  
● Support modifying clock phase and polarity  

### 20.1.2 I2S Features

● Support simplex communication  
● Support master mode and slave mode  
● Support 16-bit, 24-bit and 32-bit data formats  
● Audio sampling frequency support range 8kHz-562.2kHz  
● Support clock polarity programmable  
● Support common I2S protocols: Philips standard, MSB alignment standard, LSB alignment standard  
and PCM standard  
● Transceiver buffer supports DMA transfer  
● Support master clock output to external audio equipment
