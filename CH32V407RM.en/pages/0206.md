An update event will also be generated when the UG bit of the R16_TIMx_EGR register is set (either by  
software or using a slave mode controller).  
UEV update events can be disabled by software by setting the UDIS bit in the R16_TIMx_CTLR1 register.  
This avoids updating the shadow register when a new value is written to the preload register. No update event  
will be generated until the UDIS bit is written to 0. However, the counter will restart from the current auto-  
reload value and the prescaler counter will restart from 0 (but the prescaler ratio remains unchanged).  
Additionally, if the URS bit (update request selection) in the R16_TIMx_CTLR1 register is set, setting the UG  
bit generates an update event UEV but does not set the UIF flag (therefore, no interrupt or DMA request is  
sent). In this way, if the counter is cleared when a capture event occurs, the update interrupt and capture  
interrupt will not be generated at the same time.  
When an update event occurs, all registers are updated and the update flag (UIF bit in the R16_TIMx_INTFR  
register) is set (depending on the URS bit):  
1) The repetition counter will be reloaded with the contents of the R16_TIMx_RPTCR register  
2) The prescaler buffer will be reloaded with the preload value (contents of the R16_TIMx_PSC register)  
3) The auto-reload activity register will be updated with the preload value (contents of the  
R16_TIMx_ATRLR register).  
<em>Note: The auto-reload register is updated before the counter is reloaded, so the next count cycle is the desired</em>  
<em>new cycle length.</em>  
<strong>Center-aligned mode (up/down counting)</strong>  
In center-aligned mode, the counter counts from 0 to the auto-reload value (contents of the R16_TIMx_ATRLR  
register) - 1, generating a counter overflow event; then it counts down from the auto-reload value to 1 and  
generates a counter underflow event. Then the count starts again from 0.  
Center-aligned mode is valid when the CMS bit in the R16_TIMx_CTLR1 register is not &#x27;00&#x27;. When a channel  
is configured in output mode, its output compare interrupt flag will be set in the following modes: counter  
counting down (center-aligned mode 1, CMS=&#x27;01&#x27;), counter counting up (center-aligned mode 2, CMS=&#x27;10&#x27;),  
and counter up/down counting (center-aligned mode 3, CMS=&#x27;11&#x27;).  
In this mode, the DIR direction bit of the R16_TIMx_CTLR1 register cannot be written to a value, but is  
updated by hardware and indicates the current counter direction.  
An update event is generated each time a counter overflow and underflow occurs, or can be generated by  
setting the UG bit in the R16_TIMx_SWEVGR register (either through software or using a slave mode  
controller). In this case, the counter and the prescaler counter will start counting from 0 again.  
UEV update events can be disabled by software by setting the UDIS bit in the R16_TIMx_CTLR1 register.  
This avoids updating the shadow register when a new value is written to the preload register. No update event  
will be generated until the UDIS bit is written to 0. However, the counter will still increment and decrement  
based on the current auto-reload value.  
Additionally, if the URS bit (update request selection) in the R16_TIMx_CTLR1 register is set, setting the UG  
bit generates a UEV update event but does not set the UIF flag (therefore, no interrupt or DMA request is sent).  
In this way, if the counter is cleared when a capture event occurs, the update interrupt and capture interrupt  
will not be generated at the same time.
