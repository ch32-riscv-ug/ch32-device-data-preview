# Chapter 28 Addressable RGB (ARGB)

The chip has a built-in set of ARGB (Addressable RGB) modules that support the configurable output of code 0  
and code 1 high- and low-level time and period, and supports DMA.  
The ARGB module can realize timing control of single data line RGB light strips and supports single line RGB  
cascade. Compared with traditional RGB, it can support driving more different types of ARGB light control ICs to  
produce more light effects.  

## 28.1 Main Features

● Support configurable output of code 0 and code 1 high- and low-level time and period  
● Support DMA  

## 28.2 Function Description


### 28.2.1 Polling and Interrupts

When using polling or interrupt mode to drive this peripheral, it is important to note that the ARGB internal buffer  
is only a single byte. During a data transmission cycle, the hardware will not detect whether new data is written to  
the R32_ARGB_DATAR register; when the 1-byte data transmission is completed, if the new data cannot be filled  
in time, the hardware will repeatedly send the last byte that has been sent.  
Therefore, in order to ensure that the data sent is correct, the real-time nature of data writing must be ensured, and  
the writing operation of the next byte needs to be completed within the time window when TXEIF is set and BYTEIF  
is set.  
<strong>Configuration phase</strong>  
● Configure the MODE and LSB bits of the R32_ARGB_CTRL register to select the data frame structure.  
● Configure the R32_ARGB_CCRL, R32_ARGB_CCRH, R32_ARGB_DAT_ARR, and  
R32_ARGB_RST_ARR registers to set the physical protocol parameters.  
● Configure the R32_ARGB_DAT_CYC register to set the data frame transmission length.  
● Enable the TX_EN bit in the R32_ARGB_CTRL register.  
<em>If using the interrupt method: Since the status of the TXEIF flag must be monitored during data transmission, you</em>  
<em>must additionally set the TXEIE bit in the R32_ARGB_CTLR register and enable the ARGB interrupt.</em>  
<strong>Data transmitting phase</strong>  
● Check the STATUS bit in the R32_ARGB_STATR register to confirm that the controller is currently in the  
IDLE state.  
● Write data to the R32_ARGB_DATAR register to trigger a new frame transmission.
