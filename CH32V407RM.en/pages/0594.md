### 32.6.1 User Option Bytes Unlock

The user option bytes operation can be unlocked by writing the sequence to the FLASH_OBKEYR register. After  
unlocking, the OBWRE bit in the FLASH_CTLR register will be set to 1, indicating that user option bytes can be  
erased and programmed. By setting the OBWRE bit in the FLASH_CTLR register, it will be cleared to 0 by software  
to lock again.  
Unlocking sequence  
1) Write KEY1 = 0x45670123 to the FLASH_OBKEYR register;  
2) Write KEY2 = 0xCDEF89AB to the FLASH_OBKEYR register.  
<em>Note: The user needs to unlock the 2 layers: &quot;LOCK&quot; and &quot;OBWRE&quot; for word selection.</em>  

### 32.6.2 User Option Bytes Programming

Only standard programming mode is supported, and half word (2 bytes) is written at a time. In the actual process,  
when programming the user-selected word, FPEC only uses the low byte in the half word, and automatically  
calculates the high byte (the high byte is the anti-code of the low byte), and then starts the programming operation,  
which will ensure that the byte in the user option byte and its anti-code are always correct.  
1) Check the LOCK bit in the FLASH_CTLR register. If it is set to 1, perform the “Unlock Flash” operation.  
2) Check the BSY bit in the FLASH_STATR register to confirm no other programming operations are in progress.  
3) Check the OBWRE bit in the FLASH_CTLR register. If it is 0, perform the “User Option Byte Unlock” operation.  
4) Set the OBPG bit in the FLASH_CTLR register to &#x27;1&#x27;.  
5) Write the half-word (2 bytes) to be programmed to the specified address.  
6) Wait for the BSY bit to become &#x27;0&#x27; or for the EOP bit in the FLASH_STATR register to become &#x27;1&#x27;, indicating  
programming completion. Then clear the EOP bit.  
7) Read the programming address data for verification.  
8) To continue programming, repeat steps 5-7. To end programming, clear the OBPG bit.  
<em>Note: when &quot;read protected&quot; in the modified selection word is changed to &quot;unprotected&quot; state, an entire erase main</em>  
<em>storage area operation is automatically performed. If you modify a selection other than read Protection, the whole</em>  
<em>erase operation will not occur.</em>  

### 32.6.3 User Option Bytes Erasure

Erase the entire 128-byte user option bytes area directly.  
1) Check the LOCK bit in the FLASH_CTLR register. If it is set to 1, perform the &quot;Unlock Flash&quot; operation.  
2) Check the BSY bit in the FLASH_STATR register to confirm no programming operation is in progress.  
3) Check the OBWRE bit in the FLASH_CTLR register. If it is 0, perform the &quot;User Option Byte Unlock&quot; operation.  
4) Set the OBER bit in the FLASH_CTLR register to &#x27;1&#x27;. Subsequently, set the STRT bit in the FLASH_CTLR  
register to &#x27;1&#x27; to initiate user-selected word erase.  
5) Wait for the BSY bit to become &#x27;0&#x27; or for the EOP bit in the FLASH_STATR register to become &#x27;1&#x27; indicating  
erase completion, then clear the EOP bit to 0.  
6) Read the erased address data for verification.  
7) Clear the OBER bit to 0 to conclude the operation.  
<em>Note: After successful erasure, the character reads -0xe339e339, the half-character reads -0xe339, and the byte</em>  
<em>reads -0x39.</em>
