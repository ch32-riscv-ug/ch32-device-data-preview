# Chapter 35 Dubug Support (DBG)


## 35.1 Main Features

This register allows configuration of the MCU in debug state. include:  
● Counters that support an independent watchdog (IWDG)  
● Counters that support a window watchdog (WWDG)  
● Counters that support timers  
● Support I2C SMBus timeout control  
● Support CAN communication  

## 35.2 Register Description


### 35.2.1 Debug MCU Configuration Register (DBGMCU_CR)

Offset address: 0x7C0(CSR)
