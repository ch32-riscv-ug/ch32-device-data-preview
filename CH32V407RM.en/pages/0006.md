## 1.2 Memory Map

The chip contains program memory, data memory, core registers, peripheral registers, and more, all addressed  
in a 4GB linear space.  
System storage stores data in small-end format, i.e., low bytes are stored at the low address and high bytes are  
stored at the high address.
