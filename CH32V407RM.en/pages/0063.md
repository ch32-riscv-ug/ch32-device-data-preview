#### 9.2.1.3 Custom Delay Instructions

The custom delay instruction is a precise delay instruction at the expense of a single instruction overhead. It  
can delay the specified matching instruction to the accuracy of the clock cycle, avoiding the uncertainty of  
instruction jump execution in timers, delay and other operations. The instruction can automatically match the  
instruction encoding, configure the delay period, and clock division coefficient. It is flexible to use and has  
obvious advantages in applications such as precise control, process management, and low-overhead delay.

#### 9.2.1.4 Custom mcpy instructions

The mcpy instruction is used to replace the memcpy function to implement continuous memory transfer  
functions. The instruction register stores the address information of the start address, target address, and end  
address. All addresses have no alignment requirements.
