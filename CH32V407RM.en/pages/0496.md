#### 27.3.4.3 Color Frame Buffer Spacing

The color frame buffer of each layer has a configurable spacing, which is the distance (in bytes) from the beginning  
of one line to the beginning of the next line. It is configured through the R32_LTDC_LCFBLR register.  

### 27.3.5 Chroma Key

Chroma key (RGB) configurable for pixel replacement. At runtime, pixel values can be replaced by matching pixels  
using color key values.  
When chroma key is enabled, the current pixel (pixel after format conversion and before CLUT mixing) will be  
compared with the chroma key. If the current pixel matches the programmed RGB value, that pixel&#x27;s RGB channel  
is configured as the default color.  
The chroma key is configured through the LTDC_LCKCR register. The programmed value depends on the pixel  
format as it is compared to the current pixel after the pixel format is converted to RGB888.  
For example, if you use medium yellow (50% red + 50% green) as the replacement chroma key, then:  
- In RGB565, medium yellow is 0x8400. Set LTDC_LCKCR to 0x848200.
- In ARGB8888, medium yellow is 0x808000; set LTDC_LCKCR to 0x808000.
- In all CLUT-based color modes (L8, AL88, AL44), set one of the palette entries to medium yellow (0x808000)
and set LTDC_LCKCR to 0x808000.  

### 27.3.6 Reloaded Shadow Register

Some configuration registers perform shadow operations. When writing to the active register, or at the beginning of  
the vertical blanking period after the configuration phase of R32_LTDC_SRCR register, the shadow register value  
can be reloaded into the active register immediately. If the immediate overload configuration is selected, overloading  
should only be activated after all new registers have finished writing.  
The shadow register should not be modified again before the overload is completed. Reading the shadow register  
will return the actual effective value. The newly written value can only be read after the overload occurs.  
If enabled in the R32_LTDC_IER register, a register overload interrupt can be generated.  
Shadow registers are Layer 1 and Layer 2 registers, except R32_LTDC_LCLUTWR register.  

### 27.3.7 Interrupt

The LTDC provides 3 maskable interrupts, which are logically ORed into a single interrupt vector.  
Interrupt sources can be individually enabled or disabled via the R32_LTDC_IER register; corresponding interrupt  
flags can be read through the R32_LTDC_ISR register; and the corresponding interrupt flag bits can be cleared by  
setting the R32_LTDC_ICR register to 1.  
Interrupts are generated when the following events occur:  
● Line interrupt: Generated upon reaching a programmed line. The interrupt position is programmed in the  
R32_LTDC_LIPCR register;  
● Register reload interrupt: Generated during shadow register reload execution within the vertical blanking
