<strong>● Forbidden state</strong>  
Operating Conditions: After the I3C peripheral is reset (by setting bit 1 of I3CRST in the RCC module), the  
peripheral enters a disabled state.  
Transition from disabled to idle state: When the software sets bit 1 of the R32_I3C_CFGR register&#x27;s EN  
field, the peripheral transitions from the disabled state to the idle state after completing verification of its  
internal configuration parameters.  
● Idle state  
In the idle state, the software can partially update the I3C peripheral configuration.  
<strong>Transition from idle state to working state:</strong>  
1) Software-controlled triggering:  
In master mode, triggered when frame transmission starts via software write operation setting TSFSET bit 1  
in the R32_I3C_CFGR register;  
In slave mode, triggered when software issues an IBI/CR/HJ request;  
2) Hardware Event Triggering:  
The master device triggers upon receiving a start request and maximum TCAS time from the slave device  
during bus arbitration;  
The slave device triggers upon detecting broadcast/direct CCC or private read/write operations via the  
SDA/SCL lines.  
<strong>● Working state</strong>  
In the working state, the peripheral performs transmission on the bus.  
In the working state, when the requested transmission is completed, the software will be notified by the event  
in the R32_I3C_EVR register, and the corresponding interrupt will be enabled through the R32_I3C_INTENR  
register. After the peripheral is switched from the working state to the idle state, it can still communicate on  
the bus and can be partially reconfigured.  
As master device: In the working state, the event/flag generated after the requested transmission is completed  
can be Frame Complete (FCF), IBI/Master Device Role/Hot Join Request Complete (IBIF/CRF/HJF) or  
Transmission Error (ERRF).  

### 19.3.2 I3C Master Status and Programming Sequence

In this section, we provide a complete programming sequence when I3C peripheral is the master device,  
covering state transition, main subtasks and conditions.  
<strong>Master device initialization</strong>  
When the master device is in the forbidden state (the EN bit in R32_I3C_CFGR register is 0), the software  
must follow the following steps to initialize:  
● Configure the R32_I3C_CFGR register, set CRINIT to 1 to mark the master device role  
● Clear the HST_SIE_RST bit in the R32_I3C_RESET register  
● Configure I3C bus timing:  
1) Configure the R32_I3C_TIMINGR0 register to set the SCL clock high-level duration and low-level  
duration for the open-drain/push-pull stages of traditional I2C and I3C.  
2) Configure the R32_I3C_TIMINGR1 register to set the SDA hold time (tHD_PP) for the push-pull phase,  
the bus idle condition time (I3C tCAS, traditional I2C tBUF), the I3C repeat start bit timing (tCASr, tCBSr),
