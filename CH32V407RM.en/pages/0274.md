## 17.8 DMA

The USART module supports DMA, and can use DMA to implement fast continuous reception and  
transmission. When DMA is enabled and the TXE bit is set, DMA writes data to the transmit buffer from the  
set memory space. When DMA is used for reception, DMA transfers the data in the receive buffer to a specific  
memory space each time the RXNE bit is set.  

## 17.9 Interrupt

The USART module supports multiple interrupt sources, including transmit data register empty (TXE), CTS,  
transmission complete (TC), received data ready (RXNE), data overrun error (ORE), idle line (IDLE), parity  
check error (PE), break flag (LBD), noise (NE), multi-buffer communication overrun (ORT) and framing error  
(FE).
