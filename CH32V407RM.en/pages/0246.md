### 15.3.9 Dual Edge Capture Mode

The pulses can be measured via the TIMx_AUX register.  
For example: capture the pulse width through channel 2. In the capture function configuration, select the source  
of the IC2 signal (the CC2S bit of the TIMx_CHCTLR1 register is 11b), and enable the dual-edge capture  
function of channel 2 (the CAP_ED_CH2 bit of the TIMx_AUX register is 1). At this point, the dual edge  
capture configuration has been completed.  
The captured dual-edge pulse width value can be read through the CCR2 bit of the TIMx_CH2CVR register.  

### 15.3.10 Debug Mode

When the system enters debug mode, the timer continues to run or stops according to the setting of the DBG  
module.
