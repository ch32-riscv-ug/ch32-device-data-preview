### 16.2.2 Difference between Basic Timer and General-purpose Timer

Compared with the general timer, the basic timer lacks the following functions:  
1) The basic timer lacks down-counting mode and up-down counting mode.  
2) The basic timer lacks 4-channel independent compare capture channels.  
3) The basic timer does not support external signal control timer.  
4) The basic timer does not support incremental coding, cascade and synchronization between timers.  

### 16.2.3 Clock Input

The clock of the basic timer is provided by the internal clock CK_INT.  

### 16.2.4 Counter and Periphery

CK_PSC is input to the prescaler (PSC) for frequency division. PSC is 16 bits, and the actual frequency  
division coefficient is equivalent to the value of R16_TIMx_PSC + 1. CK_PSC will become CK_CNT after  
passing through PSC. Changing the value of R16_TIM1_PSC will not take effect in real time, but will be  
updated to PSC after the update event. Update events include clearing and resetting the UG bit.  

## 16.3 Debug Mode

When the system enters debug mode, the timer continues to run or stops according to the setting of the DBG  
module.
