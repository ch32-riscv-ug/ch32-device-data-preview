### 28.2.2 DMA

The DMA configuration process is different from the polling method. The main difference is: in DMA mode, the  
detection and data filling of TXEIE during the data transmission phase are completed by the ARGB peripheral and  
the DMA controller hardware. As long as the bus is not continuously occupied by a very high priority, the hardware  
can always complete data filling in time. Therefore, it is recommended to use DMA to drive external devices, which  
can improve the reliability of data transmission.  
<strong>Configuration phase</strong>  
● Configure the MODE and LSB bits of the R32_ARGB_CTRL register to select the data frame structure, and  
enable the DMA_EN bit.  
● Configure the R32_ARGB_CCRL, R32_ARGB_CCRH, R32_ARGB_DAT_ARR, and  
R32_ARGB_RST_ARR registers to set the physical protocol parameters.  
● Configure the R32_ARGB_DAT_CYC register to set the data frame transmission length.  
● Configure the DMA-related parameters and set the DMA transfer width to 1 byte.  
<strong>Data transmitting phase</strong>  
● Enable the TX_EN bit in the R32_ARGB_CTRL register to initiate data transmission.  
● Check the TCIF flag, or wait for the TCIF and RSTIF flags according to the frame protocol, to determine the  
current transmission status.  
● If you need to update the display content of the lighting control IC, simply repeat the configuration and  
transmission steps described above.
