### 11.2.2 Programmable Data Transmission Total Size/Data Bit Width/Alignment

The total amount of data transferred in one round of each DMA channel is programmable, up to 65535 times.  
The number to be transferred is indicated in the DMAy_CNTRx register. When EN=0, write the setting value.  
After EN=1 turns on the DMA transmission channel, this register becomes a read-only attribute, and the value  
decreases after each transmission.  
The transmission data value of peripherals and memory supports the automatic increment function of the  
address pointer, and the pointer increment is programmable. The first transferred data address they access is  
stored in the DMAy_PADDRx and DMAy_MADDRx registers. By setting the PINC bit or MINC bit of the  
DMAy_CFGRx register to 1, the peripheral address auto-increment mode can be turned on respectively. Or  
the memory address auto-increment mode, PSIZE[1:0] sets the data size of the peripheral address and the  
address auto-increment size, MSIZE[1:0] sets the memory address data size and the address auto-increment  
size, including 4 options: 8-bit, 16-bit, 32-bit, 64-bit. The specific data transfer methods are as follows:
