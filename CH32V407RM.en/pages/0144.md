Each channel has 3 DMA data transfer modes:  
● Peripheral to memory (MEM2MEM=0, DIR=0)  
● Memory to peripheral (MEM2MEM=0, DIR=1)  
● Memory to memory (MEM2MEM=1)  
<em>Note: Memory-to-memory mode does not require a peripheral request signal, after configuring this mode</em>  
<em>(MEM2MEM=1), the channel is turned on (EN=1) to start data transfer. This method does not support cyclic</em>  
<em>mode.</em>  
The configuration process is as follows:  
1) Set the first address of the peripheral register or the memory data address in the memory-to-memory mode  
(MEM2MEM=1) in the DMAy_PADDRx register. When an DMA request occurs, this address will be the  
source or destination address of the data transfer.  
2) The memory data address is set in the DMAy_MADDRx register. When a DMA request occurs, data will  
be read from or written to this address.  
3) Set the amount of data to be transferred in the DMAy_CNTRx register. After each data transmission, this  
value decreases.  
4) Set the channel priority in the PL[1:0] bit of the DMAy_CFGRx register.  
5) Set the data transfer direction, loop mode, incremental mode of peripherals and memory, data width of  
peripherals and memory, transmission halfway, transmission completion, transmission error interrupt enable  
level in DMAy_CFGRx register.  
6) Set the EN bit of the DMAy_CFGRx register and start the channel x.  
<em>Note: The control bits in the DMAy_PADDRx/DMAy_MADDRx/DMAy_CNTRx register and the data transfer</em>  
<em>direction (DIR), loop mode (location), peripheral and memory incremental mode (MINC/PINC) in the</em>  
<em>DMAy_CFGRx register can be configured to write only when the DMA channel is turned off.</em>  
<strong>3) Cycle mode</strong>  
Set the CIRC location 1 of the DMAy_CFGRx register to enable the circular mode function of channel data  
transfer. In circular mode, when the number of data transfers becomes 0, the contents of the DMAy_CNTRx  
register are automatically reloaded to their initial values, the internal peripherals and memory address registers  
are also reloaded to the initial address values set by the DMAy_PADDRx and DMAy_MADDRx registers, and  
the DMA operation continues until the channel is closed or DMA mode is turned off.  
<strong>4) DMA processing status</strong>  
● Transfer more than half: corresponding to the HTIFx bit hardware setting in the DMAy_INTFR register.  
When the number of DMA transmissions is reduced to less than half of the initial setting value, more  
than half of the DMA transfer flag will be generated, and if HTIE is set in the DMAy_CFGRx register,  
an interrupt will occur. The hardware uses this flag to remind the application that it can prepare for a new  
round of data transfer.  
● Transfer completed: corresponding to the TCIFx bit hardware setting in the DMA_INTFR register. When  
the number of DMA transmissions is reduced to 0, the DMA transfer completion flag will be generated,  
and if TCIE is set in the DMAy_CFGRx register, an interrupt will occur.
