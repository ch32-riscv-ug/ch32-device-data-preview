# Chapter 34 Pseudo-static Random Access Memory (PSRAM)

<strong><em>Chapter module description is only applicable to CH32V467 microcontroller product.</em></strong>  
Based on the CH32V407, the CH32V467 chip also has built-in 4M or 8M bytes of extended PSRAM memory,  
which supports data storage through addresses and read and write instructions, and supports DMA.  

## 34.1 Main Features

● 8-bit hardware width, supports 8-bit, 16-bit or 32-bit random or block read and write  
● Support a maximum clock rate of 300MHz, supports double edges, and a maximum data transfer rate of  
600MB/s  
● Support write data masking  
● Support high-speed read operations with data strobes  
● Support register-configurable write and read initial delays  
● Support half sleep mode and deep sleep mode
