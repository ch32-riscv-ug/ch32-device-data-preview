### 1.2.1 Memory Allocation

Built-in SRAM with zero waiting 200K bytes is used to store data, and the data will be lost after power failure.  
The starting address is 0x20000000, which supports byte, half word (2 bytes) and whole word (4 bytes) access.  
Built-in 992K bytes program flash storage area (Code FLASH), the user area, is used for user application and  
constant data storage. Including 480K bytes of non-zero wait program area and 512K bytes of zero wait  
program running area.  
There are 64KB of zero-wait data SRAM that can be configured for zero-wait programs, namely, 416KB of  
non-zero-wait program area, 576KB of zero-wait program running area and 136KB of zero-wait data SRAM  
area.  
Built-in 28K byte System FLASH, namely the BOOT area, is used for storing system boot programs (the  
bootloader is solidified by the manufacturer).  
128 bytes are used in the nonvolatile configuration information storage area of the system, and are used to  
store the manufacturer&#x27;s configuration words. They are solidified before leaving the factory and cannot be  
modified by users.  
128 bytes are used for user-defined information storage area and for user option byte storage.  
<em>Note: For chips whose fifth digit from the bottom of the lot number is greater than 0, their non-zero waiting</em>  
<em>area supports both RVV instructions and DMA 64-bit access.</em>  

## 1.3 Memory Map

The system can select 3 different boot modes through the BOOT0 and BOOT1 pins.  

<!-- p8-table-001 (table-1-1@1) -->
<table><caption>Table 1-1 Boot mode</caption><tr><th>BOOT0</th><th>BOOT1</th><th>Boot mode</th></tr><tr><td>0</td><td>X</td><td>Boot from program flash memory</td></tr><tr><td>1</td><td>0</td><td>Boot from system memory</td></tr><tr><td>1</td><td>1</td><td>Boot from internal SRAM</td></tr></table>

The user selects the BOOT mode after reset by setting the state value of the boot pin. After system reset or  
power reset, the value of the BOOT pin will be re-latched.  
With different startup modes, program flash memory, system memory and internal SRAM have different  
access modes:  
● When booting from program flash memory, the program flash memory addresses are mapped to the  
0x00000000 address space, and can also be accessed in the original address space at 0x08000000.  
● When booting from system memory, the system memory address is mapped to the 0x00000000 address  
space, and can also be accessed in the original address space at 0x1FFF0000.  
● When booting from internal SRAM, access is limited to the 0x20000000 address space.
