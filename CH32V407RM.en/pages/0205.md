The compare/capture register is composed of a preload register and a shadow register, and only the preload

## 14.3 Function and Implementation

The advanced-control timer complex functions are implemented by the operation of compare/capture channel,  
clock input circuit, counter and peripheral parts of the timer. The timer&#x27;s clock input can come from multiple  
clock sources including the input of the compare/capture channel. The operation of compare/capture channel  
and the clock source selection directly determines its function. The compare/capture channel is bidirectional  
and can work in input and output modes.  

### 14.3.1 Counter Mode

<strong>Up counting mode</strong>  
In up-counting mode, the counter counts from 0 to the auto-reload value (contents of the R16_TIMx_ATRLR  
register), then restarts counting from 0 and generates a counter overflow event.  
If a repeat counter is used, an update event (UEV) is generated when the number of incremented repeats  
reaches the number programmed in the repeat counter register plus one (R16_TIMx_RPTCR+1). Otherwise,  
an update event will be generated every time the counter overflows.  
An update event will also be generated when the UG bit of the TIMx_SWEVGR register is set (either by  
software or using a slave mode controller).  
UEV events can be disabled by software by setting the UDIS bit in the R16_TIMx_CTLR1 register. This  
avoids updating the shadow register when a new value is written to the preload register. No update event will  
be generated until the UDIS bit is written to 0. However, both the counter and the prescaler counter will restart  
counting from 0 (while the prescaler ratio remains unchanged). Additionally, if the URS bit (update request  
selection) in the R16_TIMx_CTLR1 register is set, setting the UG bit generates an update event UEV but does  
not set the UIF flag (therefore, no interrupt or DMA request is sent). In this way, if the counter is cleared when  
a capture event occurs, the update interrupt and capture interrupt will not be generated at the same time.  
When an update event occurs, all registers are updated and the update flag (UIF bit in the R16_TIMx_INTFR  
register) is set (depending on the URS bit):  
1) The repetition counter will be reloaded with the contents of the R16_TIMx_RPTCR register  
2) The auto-reload shadow register will be updated with the preload value (R16_TIMx_ATRLR)  
3) The prescaler buffer will be reloaded with the preload value (contents of the R16_TIMx_PSC register)  
<strong>Down counting mode</strong>  
In down-counting mode, the counter starts counting down from the auto-reload value (contents of the  
R16_TIMx_ATRLR register) to 0, then starts counting again from the auto-reload value and generates a  
counter underflow event.  
If a repeat counter is used, an update event (UEV) is generated when the number of count-down repeats reaches  
the number programmed in the repeat counter register plus one (R16_TIMx_RPTCR+1). Otherwise, an update  
event will be generated every time the counter underflows.
