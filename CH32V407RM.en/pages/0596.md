# Chapter 33 Extended Configuration (EXTEN)


## 33.1 Extended Configuration

The system provides the EXTEN extension configuration unit (EXTEN_CTR register). This unit uses the HB  
clock and only performs reset actions during system reset. It mainly includes the following extended control bit  
functions:  
1) Adjust the built-in voltage: Select the default value for the ULLDOTRIM field, and you can modify its value  
when adjusting performance and power consumption.  
2) Lock-up function monitoring: If the LKUPEN field is enabled, the system&#x27;s Lock-up situation monitoring will  
be turned on. Once a Lock-up situation occurs, the system will perform a software reset and set the  
LKUPRST field to 1. After reading, you can write 1 to clear this flag.  
3) Adjustment of VDD18: The voltage of VDD18 can be configured.
