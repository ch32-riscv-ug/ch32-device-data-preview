<em>Note: The LSEON, LSEBYP, RTCSEL and RTCEN bits in the backup domain control register (RCC_BDCTLR)</em>  
<em>are in the backup domain. Therefore, these bits are write-protected after reset and can only be changed after</em>  
<em>the DBP bit in the power control register (PWR_CTLR) is set to 1. These bits can only be cleared by a backup</em>  
<em>domain reset. These bits are not affected by any internal or external reset.</em>
