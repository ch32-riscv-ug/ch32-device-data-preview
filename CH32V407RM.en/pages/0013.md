### 2.3.3 Stop Mode

Sleep mode combines the clock control mechanisms of the peripherals with the fact that both the V3F and V5F  
cores enter deep sleep (SLEEPDEEP). The high-frequency clock (HSE/HSI/PLL) domains are disabled,  
SRAM and register contents are preserved, and I/O pin states are maintained. Upon waking from this mode,  
the system can resume operation, with HSI serving as the default system clock.  
If flash programming is in progress, the system does not enter stop mode until access to memory is complete;  
if access to the PB is in progress, the system does not enter stop mode until access to the PB is complete.  
Modules that can operate in Stop mode: Independent Watchdog Dog (IWDG), Real Time Clock (RTC), Low  
Frequency Clock (LSI/LSE).  
Entry: Configuration of the core register control bit SLEEPDEEP=1, optional LPDS bit, execute WFI or WFE,  
optional SEVONPEND and SLEEPONEXIT.  
Exit: Any external interrupt/event, external reset on the NRST pin, IWDG reset. The EXTI signal includes  
one of the 77 external I/O pins, the PVD output, the RTC alarm, the I3C wake-up signal, and the USB wake-  
up signal.  

### 2.3.4 Standby Mode

In standby mode, the main LDO of the system is turned off, and the low-power LDO supplies power to the  
wake-up circuit. All other digital circuits are powered off, and FLASH is in a power-off state. Waking up the  
system from standby mode will generate a reset and SBF (PWR_CSR) will be set. After waking up, query the  
SBF status to know the low power consumption mode before waking up. SBF is cleared by the CSBF  
(PWR_CR) bit. In standby mode, the contents of the 32KB SRAM can be retained (depending on the planning  
configuration before sleep), and the contents of the back-up register are retained.  
Modules that operate in standby mode: Independent Watchdog (IWDG), Real-Time Clock (RTC), and Low-  
Frequency Clock (LSI/LSE).  
Enter: configure the core register control bit SLEEPDEEP=1, the power control register PDDS=1, execute  
WFI or WFE, optional SEVONPEND and SLEEPONEXIT.  
Exit: any external event (EXTI signal), external reset signal on NRST, IWDG reset, a rising edge on the WKUP  
pin, where the EXTI signal includes one of the 77 external I/O ports, RTC alarm clock.  
In standby mode, when normal power is supplied, the 32K-byte RAM is kept powered by configuring  
R32KSTY=1 in the PWR_CTLR register; When powered by VBAT, the 32K-byte RAM is kept non-volatile  
by configuring R32KVBAT=1 in the PWR_CTLR register. On this basis, RAM low-voltage mode can be  
enabled by configuring RAMLV=1 in the PWR_CTLR register to achieve the lowest power consumption.  
<em>Note: (1) In debug mode, if the microprocessor enters stop or standby mode, the debug connection will be lost.</em>
