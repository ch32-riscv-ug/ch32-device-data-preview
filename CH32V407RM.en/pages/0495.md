### 27.3.2 Pixel Format

Programmable pixel format is used for data stored in the frame buffer of the layer. Up to eight input pixel format  
can be configured for each layer through the R32_LTDC_LxPFCR register.  
The ARGB8888 format requires 8 bits of data per channel (Alpha, Red, Green and Blue). However, some channels  
in ARGB1555 and ARGB4444 formats are less than 8 bits. The pixel processing unit converts it into ARGB8888  
by copying the high bits and filling them into the low bits. When processing RGB888 and RGB565 formats, the  
pixel processing unit assumes Alpha=255, and if the number of bits of the channel is less than 8, the copy high bits  
are also padded to the low bits.  

### 27.3.3 Color Look-up Table (CLUT)

CLUT can be enabled for each layer at runtime through the CLUTEN bit in the R32_LTDC_LCR register. CLUT  
is only suitable for index colors when using L8, AL44 and AL88 input pixel format.  
First, CLUT must load R, G and B values to replace the original R, G and B values of the corresponding pixels  
(index colors). Each color (RGB value) has its own corresponding address in CLUT. The values of r, g and b and  
their respective addresses are programmed by R32_LTDC_LCLUTWR register.  
When using L8 and AL88 to input pixel format, CLUT must be loaded with 256 colors. The address of each color  
is configured in the CLUTADD bit of R32_LTDC_LCLUTWR register.  
When using AL44 to input pixel format, CLUT must only load 16 colors. The address of each color must be filled  
by repeating the 4-bit L channel into 8 bits, as follows:  
–L0 (Index Color 0), at address 0x00;  
–L1, at address 0x11;  
–L2, at address 0x22;  
–.....;  
–L15, at address 0xFF.  

### 27.3.4 Color Frame Buffer


#### 27.3.4.1 Color Frame Buffer Address

The color frame buffer of each layer has a start address, which is configured by R32_LTDC_LCFBAR register.  
When a layer is enabled, the data will be obtained from the color frame buffer.  

#### 27.3.4.2 Color Frame Buffer Length

Each layer is set with the total length (in bytes) and the number of lines of the color frame buffer, which can be  
configured by the R32_LTDC_LCFBLR and R32_LTDC_LCFBLNR registers respectively.  
The length and number of rows are set to prevent data beyond the end of the frame buffer from being prefetched  
into the FIFO corresponding to the layer.  
If it is set below the required bytes, a FIFO underflow interrupt will be generated (if previously enabled).
