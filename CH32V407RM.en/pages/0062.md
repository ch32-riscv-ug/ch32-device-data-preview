# Chapter 9 Central Processing Unit (CPU)

CH32V407 uses the QingKe V3V core. RISC-V3V supports the IMACV-X instruction set. It adopts a 2-3  
level pipeline internally and a sequential execution structure. The core supports RISC-V V1.0 vector  
instruction set and zvbb subset, and supports EEW bit width up to 64 bits.  
The internal management is modular and includes fast programmable interrupt controller (PFIC), memory  
protection, branch prediction mode, extended instruction support and other units. External multiple sets of  
buses are connected to external unit modules to realize the interaction between external functional modules  
and the core.  

## 9.1 Main Features

● Sequential single-issue architecture  
● 2~3 stage pipeline  
● Provide one non-maskable interrupt (NMI)  
● 2-level interrupt nesting  
● Programmable Fast Interrupt Controller (PFIC)  
● Custom extendable instructions  
● Hardware stack  
● Vector operations/parallel processing  

## 9.2 Function Description


### 9.2.1 Instruction Set

The QingKe V3V processor supports vector integer and fixed-point arithmetic instructions in the RISC-VV1.0  
instruction set, but does not support vector floating-point instructions. Vector operations use 32 sets of 64-bit  
wide vector registers. The maximum EEW of vector instructions is 64 bits. The configuration complies with  
the vector embedded extension Zve64x extension set, and supports vector instruction encoding check and  
instruction execution exception check.  

#### 9.2.1.1 RISC-V V1.0

Vector operations use 32 groups of 64-bit wide vector registers as operation registers, fully supporting the  
vector embedded extension Zve64x extension set.  
<em>Note: 1. The zve64x extended instruction set is all instructions defined in the RVV1.0 manual. For specific</em>  
<em>instruction functions, please refer to RISC-V &#x27;V&#x27; vector Extension1.0;</em>  
<em>2. All memory access instructions support eew=64 and iew=64 operations, but the scalar address bit</em>  
<em>width XLEN=32 bits and does not support 64-bit addressing, which complies with the manual Zve64x</em>  
<em>specification.</em>  

#### 9.2.1.2 RISC-V zvbb

zvbb is an extended bit-based operation subset of the vector instruction set. Full support for Zve64x extension  
set.
