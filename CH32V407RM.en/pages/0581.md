## 32.2 Flash Memory Programming and Safety


### 32.2.1 Two Program/Erase Methods

● Standard programming: This mode is the default programming mode (compatibility mode). In this mode, the  
CPU performs programming in a single 2-byte manner, and performs erase and whole-chip erase operations  
in a single 4K-byte manner.  
● Fast programming: This method uses page operation mode (recommended). After a specific sequence is  
unlocked, a single 256-byte programming, 32K-byte erasing, and entire chip erasing are performed.  
<em>Note: Functions related to FLASH erasure and programming may only be placed in the zero-wait zone of the FLASH.</em>
