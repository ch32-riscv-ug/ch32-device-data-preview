### 28.3.5 Slave Mode

Turning on the SLV_MODE bit means that it is in the state of waiting for commands from the host, with  
received command parameters placed in RESP1 and received command indexes placed in RESP2, while  
automatically answering to the host with an R1 type of answer, with the answer parameter being the value of  
CMDARG.  
Data sent and received in slave mode refer to master mode, but the slave can use the SLV_FORCE_ERR bit  
to force a data block CRC error, thus indicating an undesired data read or write.  
<em>Note: (1) The slave supports only the R1 type of answer, and the command indexes and parameter meanings</em>  
<em>used for master-slave communication are defined by the software;</em>  
- <em>(2) Slave mode is only available for CH32F20x_D8, CH32F20x_D8C, CH32V30x_D8, CH32V30x_D8C,</em>
<em>and CH32V31x_D8C products with the penultimate sixth digit of the lot number that is not zero.</em>
