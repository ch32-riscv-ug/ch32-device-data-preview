### 32.6.1 User Option Bytes Unlock

The user option bytes operation can be unlocked by writing the sequence to the FLASH_OBKEYR register.  
After unlocking, the OBWRE bit in the FLASH_CTLR register will be set to 1, indicating that user option  
bytes can be erased and programmed. By setting the OBWRE bit in the FLASH_CTLR register, it will be  
cleared to 0 by software to lock again.  
Unlocking sequence  
1) Write KEY1 = 0x45670123 to the FLASH_OBKEYR register;  
2) Write KEY2 = 0xCDEF89AB to the FLASH_OBKEYR register.
