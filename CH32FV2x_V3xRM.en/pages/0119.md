### 9.5.3 Dedicated CSR Registers

RISC-V defines some Control and Status Control Registers (CSR), which are used to configure, flag or  
record run status. CSR register is a register in the cores, with dedicated 12-bit address space. The CH32V20x,  
CH32V30x and CH32V31x not only have standard registers defined in RISC-V privileged architecture  
documentation, but also have some additional vendor-defined registers which need csr instruction to access.  
<em>Note: The CSR registers with attribute of MRW/MRO/MRW1 need to be accessed in machine mode.</em>  

#### 9.5.3.1 Interrupt System Control Register (INTSYSCR)
