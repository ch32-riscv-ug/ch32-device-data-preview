### 32.6.5 Write Protection Release

The write protection of flash memory is determined by the user option bytes. Read the FLASH_WPR  
register. Each bit represents 4K bytes of flash memory space. When the bit is ‘1’, it means the  
non-write-protected state, and ‘0’ means write-protected. The process of releasing write-protected is as  
follows:  
1) Erase the whole user option bytes area.  
2) Write the correct RDPR code 0xA5, and the read access is allowed;  
3) Perform a system reset and reload the selection byte (Including the new WRPR[3:0] byte) to release the  
write protection.
