The SD card is also a FLASH structure, and the FLASH needs to be erased before writing, but the SD card  
integrates erasing logic. If it is found that there is no erasure before executing the write command, it will  
automatically supplement the erasing operation. In many cases, especially before large batch writes, it can  
help to improve efficiency if the erase is actively performed.

<em>Note 1: The erase command here is the erase command of SD card defined by SD protocol specification, and</em>

<em>be a block address, that is, 512-byte alignment.</em>
