Note: This clock tree structure is applied for CH32F20x_D6, CH32F20x_D8, CH32V20x_D6 and  
CH32V30x_D8. When using the USB function, the CPU frequency must be 48MHz, 96MHz or 144MHz.  
when using the USB high speed function, the clock source of USBHSPLL can only be HSE. when the system  
wakes up from the stop or standby mode, the system will automatically switch to HSI as the main frequency.
