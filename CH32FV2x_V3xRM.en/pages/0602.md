# Chapter 32 Flash Memory and User Option Bytes

<strong><em>This chapter applies to the whole family of CH32F20x, CH32V20x, CH32V30x and CH32V31x.</em></strong>

The internal flash memory organization structure of the chip is as follows (Taking xVCT6 as an example):

<em>Note:</em>  
<em>1) The main memory area is used for the user&#x27;s application program storage, and the write protection is</em>  
<em>divided in unit of 4K bytes (32 pages). Except for the locked &quot;Vendor Configuration Word&quot; area before</em>  
<em>delivery which is inaccessible to users, other areas can be operated by users under certain conditions.</em>  
<em>2) When carrying out FLASH-related operations, it is strongly recommended that the system main frequency</em>  
<em>is not greater than 120M.</em>  
<em>If the actual application must require the use of system mains frequency greater than 120M, it should be</em>  
<em>noted that:</em>  
<em>In the non-zero-wait area FLASH and zero-wait area FLASH, user word read/write and vendor</em>  
<em>configuration word and Boot area read, the following operations need to be done, firstly, HCLK is divided</em>  
<em>into two (Related peripheral clocks are also divided at the same time, the impact needs to be evaluated), and</em>  
<em>then restored after the FLASH operation is completed to ensure that the FLASH access clock frequency does</em>  
<em>not exceed 60Mhz (FLASH_ CTLR register bit[25]-SCKMOD can configure FLASH access clock frequency</em>  
<em>as system clock or half of system clock, the default configuration of this bit is half of system clock).</em>  

## 32.2 Flash Memory Programming and Safety


### 32.2.1 Two Program/Erase Methods

● Standard programming: This method is the default programming method (Compatible method). In this  
mode, the CPU executes programming in a single 2-byte manner, and executes erasure and entire chip  
erasure operations in a single 4K byte
