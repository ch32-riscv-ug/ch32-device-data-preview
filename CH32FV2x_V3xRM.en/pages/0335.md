The I2S function is enabled by setting the I2SMOD bit in register I2SCFGR. At this point, the SPI module  
can be used as an I2S audio interface. I2S and SPI share 3 pins:  
- SD: Serial data (Mapped to MOSI pin), used to send and receive 2 time-multiplexed data channels;
- WS: word selection (Mapped to NSS pin), output as data control signal in master mode, and input in slave
mode;  
- CK: Serial clock (Mapped to the SCK pin), output as a clock signal in master mode, and input in slave
mode.

clock:
