RDes1  
It can be seen from the above figure that the receiving descriptor is also composed of 4 32-bit words, of  
which the first 32-bit word mainly returns the state when receiving, the second 32-bit word contains the  
received data length, and the third 32-bit word defines the address of the receive buffer or the low order of  
the return timestamp, the fourth 32-bit word is the address of the second buffer (RCH is not set), the address  
of the next buffer (RCH is set) or Returns the high order bit of the timestamp.  
The meanings of bits of the receive descriptor are as follows:

When LS (RDes0:8) is 1, this field indicates the length of the frame received by the DMA controller,<br>including the CRC. This bit is only valid when FT<br>(RDes0 [5]) is set.</td></tr><tr><td>11</td><td>OE</td><td style="text-align:left">Overflow error Set to indicate that the received frame is corrupted due to an overflow of the receive FIFO.</td></tr><tr><td>10</td><td>VLAN</td><td style="text-align:left">VLAN tag Set to indicate that a VLAN frame is received.</td></tr><tr><td>9</td><td>FS</td><td style="text-align:left">First descriptor This bit indicates that this descriptor contains the beginning of the frame.</td></tr><tr><td>8</td><td>LS</td><td style="text-align:left">Last descriptor It indicates that this descriptor contains the end of the frame.</td></tr><tr><td>7</td><td>IPHCE</td><td style="text-align:left">IP header checksum error This bit is set to indicate that there is an error in the IPv4 or IPv6 header.
