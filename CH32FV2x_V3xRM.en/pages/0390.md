#### 22.2.2.3 USB Endpoint Buffer Mode Control Register (R32_UEP_BUF_MOD)


<!-- p390-table-002 (table-22-2@1) -->
<table><tr><th>Bit</th><th>Name</th><th>Access</th><th>Description</th><th>Reset value</th></tr><tr><td>[31:16]</td><td style="text-align:left">RB_UEP_ISO_BUF<br>_MOD</td><td>RW</td><td style="text-align:left">Synchronous endpoint buffer mode control,<br>1 is valid.</td><td>0</td></tr><tr><td>[15:0]</td><td>RB_UEP_BUF_MOD</td><td>RW</td><td>Endpoint buffer mode control</td><td>0</td></tr></table>

<em>Note: When RB_UEP_ISO_BUF_MOD is 1, for the synchronous IN endpoint, after receiving the SOF packet,</em>  
<em>the hardware will perform the following operations: load the content of EPx_R_TOG into EPx_T_TOG; load</em>  
<em>the value of EPx_MAX_LEN into EPx_T_LEN; load the value of UEPn_RX_DMA into UEPn_TX_DMA.</em>  
<em>When RB_UEP_ISO_BUF_MOD is 1, for the synchronous OUT endpoint, after receiving the SOF packet,</em>  
<em>the hardware will perform the following operations: load the content of EPx_T_TOG into EPx_R_TOG; load</em>  
<em>the value of UEPn_TX_DMA into UEPn_RX_DMA.</em>
