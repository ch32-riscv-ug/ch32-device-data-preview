For address aligned and protection region range selection, it performs memory protection for the region  
between A_ADDR and B_ADDR (A_ADDR and B_ADDR are both required 4-byte aligned):  
1. If B_ADDR – A_ADDR == 22, it is based on NA4;  
2. If B_ADDR – A_ADDR == 2(G+2)and G≥1, and if A_ADDR= 2(G+2), it is aligned based on NAPOT;  
3. Otherwise it is based on TOR.
