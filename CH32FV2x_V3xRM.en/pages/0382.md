#### 22.2.1.4 USB Frame Number Register (R16_USB_FRAME_NO)


<!-- p382-table-003 (table-22-1@1) -->
<table><tr><th>Bit</th><th>Name</th><th>Access</th><th>Description</th><th>Reset value</th></tr><tr><td>[15:0]</td><td style="text-align:left">USB_FRAME_NO[15:0]</td><td>RO</td><td style="text-align:left">Frame number. In host mode, it indicates the frame number of the SOF packet to be sent. In device mode, it indicates the frame number of the currently received SOF packet. Among them, the lower 11 bits are the effective frame number, and the upper 3 bits are the micro frame number of the high-speed mode.</td><td>0</td></tr></table>

<em>Note: USB_FRAME_NO is a 16-bit register, in which the lower 11 bits represent the frame number of the</em>  
<em>SOF packet, and the upper 3 bits represent the current micro-frame, which can be used for interrupt,</em>  
<em>synchronization/real-time transmission under the operation of high-speed HUB.</em>
