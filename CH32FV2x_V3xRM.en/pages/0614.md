## 32.6 User Option Bytes

The User Option Bytes are solidified in FLASH and will be reloaded into the corresponding register after the  
system reset, and the user can erase and program at will. The user option word information block has a total  
of 8 bytes (4 bytes for write protection, 1 byte for read protection, 1 byte for configuration options, 2 bytes  
for user data storage), and each bit has the inverted code bit for checking during loading. The structure and  
meaning of the selected word information are described below.
