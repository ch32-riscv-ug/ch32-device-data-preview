● 2-group analog voltage comparator CMP: - 16-bit compact timer for auxiliary motor  
- General-purpose CMP, 3 input channels, applications
supports 3 CMP polling to detect positioning and - 2 watchdog timers (independent watchdog and  
output to peripherals or I/Os window watchdog)  
- Streamlined CMP, internally cascaded to OPA - SysTick: 32-bit counter
<strong>outputs ● 2 set of USART</strong>  
● 12-bit ADC - Support LIN  
- Analog input range: VSS~VDD● I2C interface
- 8 external signals + 3 internal signals ● SPI interface
- Support 3M sampling rate ● GPIO port
<strong>● 8-channel touch-key channel detection - 4 sets of GPIO ports, 31 I/O ports</strong>  
● Multiple timers - Mapping 1 external interrupt  
- 16-bit advanced-control timer, with dead zone ● Debug mode: 1-wire or 2-wire serial debug
control and emergency brake; can offer PWM interface  
complementary output for motor control ● Package: QFN, QSOP  
- 16-bit general-purpose timer, provide input
capture/output comparison/PWM/pulse  
counting/incremental encoder input
