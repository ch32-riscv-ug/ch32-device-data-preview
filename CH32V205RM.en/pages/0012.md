### 2.3.2 Sleep Mode (SLEEP)

In this mode, all I/O pins keep their state in Run mode and all peripheral clocks are normal, so try to turn off  
useless peripheral clocks before entering Sleep mode to reduce low-power consumption. This mode takes the  
shortest time to wake up.  
Enter: Configure the core register control bit SLEEPDEEP=0, the power control register PDDS=0, LPDS  
determines the state of the internal voltage regulator, execute WFI or WFE, and can choose SEVONPEND and  
SLEEPONEXIT.  
Exit: Arbitrary interrupt or wakeup event.  

### 2.3.3 Stop Mode (STOP)

Stop mode is a combination of peripheral clock control mechanisms based on the core&#x27;s sleep deep mode  
(SLEEPDEEP) and allows the voltage regulator to operate at a much lower-power consumption. This mode has  
the high frequency clock (HSE/HSI/PLL) domain turned off, the SRAM and register contents held, and the I/O  
pin state held. The system can continue to run after this mode wakes up, and the HSI is called the default system  
clock.  
If flash programming is in progress, the system will not enter sleep mode until the memory access is complete; if a  
PB access is in progress, the system will not enter sleep mode until the PB access is complete.  
Stop mode can work modules: Independent Watchdog (IWDG), Real-time clock (LSI/LSE), Low Frequency  
Clock (LSI/LSE).  
Enter: Set the core register control bit SLEEPDEEP to 1, the power control register PDDS to 0, and the optional  
LPDS bit; execute WFI or WFE; and enable the optional SEVONPEND and SLEEPONEXIT. Before entering the  
STOP voltage regulator low-power mode (PDDS=0, LPDS=1), preset FLASH_LP[1:0]=10b, i.e., FLASH  
low-power mode 1.  
Exit: Any external interrupt/event, external reset on the NRST pin, PVD output, IWDG reset, RTC alarm, USB  
wake-up signal, USB PD wake-up signal, CMP wake-up signal, etc.  
Different stop modes can be selected through various configurations. In stop mode (i.e., PDDS=0), the LPDS bit can be  
set as follows: LPDS=0, the voltage regulator operates in Stop Mode 1; LPDS=0, AUTO_LDO_EC=1, the power  
system automatically enters power-saving mode when the MCU enters stop mode, i.e., Stop Mode 2; or LPDS=0,  
LDO_EC=1, which also results in Stop Mode 2; When LPDS=1, the voltage regulator operates in Stop Mode 3. Based  
on Stop Mode 3, configuring the PWR_CTLR register to set RAMLV=1 enables the RAM low-voltage mode,  
minimizing power consumption to the lowest level, which is referred to as Stop Mode 4.  

### 2.3.4 Standby Mode (STANDBY)

In standby mode, the voltage regulator is turned off, and all circuits except for the wake-up circuit and the backup  
circuit are powered down to minimize power consumption. Upon exiting standby mode under specified wake-up  
conditions, the microcontroller is reset and performs a power-on reset. Modules that remain operational in standby  
mode include: Independent Watchdog (IWDG), Real-Time Clock (RTC), and Low-Frequency Clock (LSI/LSE).
