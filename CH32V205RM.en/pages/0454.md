# Chapter 28 Debug Support (DBG)


## 28.1 Main Features

This register allows the MCU to be configured in the debug state. It includes:  
● Independent Watchdog (IWDG) enabled counters  
● Window Watchdog (WWDG) enabled counters  
● Support timer counters  
● Support I2C and SMBus timeout control  
● Support bxCAN communication  

## 28.2 Register Description


### 28.2.1 Debug MCU Configuration Register (DBGMCU_CR)

Address: 0x7C0 (CSR)
