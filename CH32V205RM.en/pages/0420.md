When the programmed number of bytes to transmit or receive is reached, if TCIE=1, TCF is set to 1 and an  
interrupt is generated. When the data quantity is uncertain, the system will also set TCF to 1 when the external SPI  
limit is reached, based on the FLASH size defined in the R32_QSPIx_CR register.  
QSPI supports write flow control. This means that when the length filled in the DLR has not been fully  
transmitted and the FIFO is empty, the shift register transmission is paused. In this mode, for efficiency, the  
software should first write to the DR register to fill data into the FIFO, or set DMAEN to 1 to automatically  
request a certain amount of data from the DMA before writing the START bit to initiate transmission.  
<strong>Trigger Command Start</strong>  
Essentially, once the firmware provides the last information required by the command, the command will start.  
According to the configuration of QSPI, in indirect mode, there are 3 ways to trigger the command to start:  
1) Perform a write operation to the INSTRUCTION[7:0] field of the R32_QSPIx_CCR register. This is required  
when ADMODE=00b (address is mandatory) and when no data is provided by the firmware (when FMODE=01b  
or DMODE=00b);  
2) Write to the ADDRESS[31:0] field of the R32_QSPIx_AR register if an address is required (when  
ADMODE=00b) and no data is provided by the firmware (when FMODE=01b or DMODE=00b);  
3) Write to the DATA[31:0] field of the R32_QSPIx_DR register if an address is required (when ADMODE ≠  
00b) and data is provided by the firmware (when FMODE = 00b and DMODE ≠ 00b).  
Writing to the Alternate Byte Register (R32_QSPIx_ABR) never triggers a command start. If alternate bytes are  
required, they must be programmed in advance. Once a command starts, the BUSY bit in the R32_QSPIx_SR  
register is automatically set to 1.  
<strong>FIFO and Data Management</strong>  
In indirect mode, data is transferred through the 32-byte FIFO internal to the QSPI. The FLEVEL[5:0] bits of the  
R32_QSPIx_SR register indicate how many bytes are currently stored in the FIFO.  
In indirect write mode (FMODE=00b), when the firmware writes data to the R32_QSPIx_DR register, the data is  
appended to the FIFO. A word write adds 4 bytes to the FIFO, a half-word write adds 2 bytes, and a byte write  
adds only 1 byte. If the firmware writes data to the FIFO exceeding the value indicated by DL[31:0], any excess  
bytes are cleared from the FIFO upon completion of the write operation (when TCF is set to 1). Access to  
bytes/half-words in the R32_QSPIx_DR register must be strictly confined to the least significant byte/half-word  
of this 32-bit register.
