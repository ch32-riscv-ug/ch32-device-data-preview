### 27.5.4 Remove Write Protection

Whether the flash memory is write-protected or not is determined by the user option bytes. Read the  
FLASH_WPR register, each bit represents 8K bytes of flash space, when the bit is&#x27;1&#x27; for non-write-protected state,  
&#x27;0&#x27; for write-protected. The process of unprotecting a write is as follows:  
1) Erases the entire user option bytes area;  
2) Write the correct RDPR code 0xA5 to allow read access;  
3) The system is reset, the option bytes are reloaded (including the new WRPR [3:0] bytes), and the write  
protection is removed.
