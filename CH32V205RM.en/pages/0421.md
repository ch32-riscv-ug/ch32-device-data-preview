In indirect mode, QSPI will pause byte reads from Flash when the FIFO is full to prevent overflow. Reading from

### 26.3.4 QSPI Status Flag Polling Mode

In automatic polling mode, QSPI periodically starts commands to read a certain number of status bytes (up to 4).  
By masking the received bytes, some status bits can be isolated. When the selected bit has a preset value, an  
interrupt can be generated.  
Access to FLASH starts in the same way as in indirect reading mode: if an address (AMODE=00b) is not needed,  
access will start when R32_QSPIx_CCR is written. Conversely, if an address is required, the first access will start  
when R32_QSPIx_AR is written. At this time, BUSY becomes high level and remains unchanged even during  
periodic access.  
In automatic polling mode, the contents of the R32_QSPIx_PSMAR register&#x27;s MASK[31:0] bits are used to mask  
data from the FLASH. If MASK[n]=0, bit n in the result is masked and ignored. If MASK[n]=1 and the content of  
bit [n] matches the content of bit [n] in the R32_QSPIx_PSMAR register&#x27;s MATCH[n] field, bit n is considered a  
match.  
If the Polling Match Mode bit (PMM, bit 23 of R32_QSPIx_CR) is 0, the “AND” match mode is activated. This  
means the Status Match Flag (SMF) is set only when all unmasked bits match. If PMM=1, the “OR” match mode  
is activated, meaning SMF is set to 1 if a match occurs on any unmasked bit. If SMIE=1, an interrupt is triggered  
when SMF is set to 1. If the automatic polling mode is stopped (APMS=1), the operation halts and the BUSY bit  
is cleared upon detecting a match. Otherwise, the BUSY bit remains set, and periodic accesses continue until an  
abort occurs or QSPI is disabled (EN=0).  
The data register (R32_QSPIx_DR) contains the most recently received status byte (FIFO disabled). The contents  
of the data register are unaffected by the masking method used by the matching logic. The FTF status bit is set to  
1 after a new status read completes; once data is read, FTF is cleared.  

### 26.3.5 QSPI Memory Mapping Mode

When configured in memory-mapped mode, the external SPI device is treated as internal memory. If the QSPI  
peripheral is not properly configured and enabled, the QSPI Flash memory area cannot be accessed. Even with  
larger FLASH capacity, its address space is limited to a maximum of 256MB.  
Note: Memory-mapped addresses are for data access only and cannot be used for instruction access.  
Byte, half-word, and word access types are supported. The QSPI anticipates subsequent microcontroller accesses  
and preloads bytes from later addresses. Subsequent accesses to contiguous addresses are accelerated because the  
data has already been fetched.
