can have two filters, each of which contains a 16-bit identifier register and a 16-bit mask register; All four  
registers in identifier list mode are used as identifier registers.

Messages entering the FIFO mailbox are read and stored by the application, which typically distinguishes message  
data based on message identifiers. The CAN controller provides a filter number for messages filtered through  
different filters in the receive FIFO. This number is stored in the FMI[7:0] field of the CANx_RXMDTyR register,  
regardless of whether the filter group is enabled. Refer to Figure 25-4 for the numbering rules.  
When a message passes multiple filters, the stored filter number in the receive buffer is determined by the filter  
priority rules. The filter priority rules are as follows:  
● All 32-bit filters have higher priority than 16-bit filters.  
● For filters of the same width, those using an identifier list have higher priority than those using a mask bit  
pattern.  
● For filters with identical width and pattern, the one with the lower number has higher priority.  
As shown in Figure 25-5: When receiving a message, the identifier is first matched against the 32-bit identifier list  
pattern filter. If no match is found, it is then matched against the 32-bit mask pattern filter. If still no match occurs,  
it proceeds to match against the 16-bit identifier list pattern filter. If no match is found, it finally matches against  
the 16-bit mask pattern filter. If no match is found at any stage, the message is discarded. If a match occurs, the  
message is stored in the mailbox of the receive FIFO, and the identifier number is stored in the FMI field of the  
CAN1_RXMDTRx register.
