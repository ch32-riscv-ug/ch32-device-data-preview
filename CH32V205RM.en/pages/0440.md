## 27.2 Flash Memory Programming and Security


### 27.2.1 Programming/Erasing Methods

● Fast programming: This method uses page operation (recommended). After a specific sequence of unlocking,  
a single 256-byte programming, 256-byte erasing, 64-byte erasing, 2-byte erasing and whole erasing are  
performed.  

### 27.2.2 Security - Prevent Illegal Access (Read, Write, Erase)

● Page write protection  
● Read protection  
When the chip is in the read-protected state.  
1) Main memory pages 0-31 (8K bytes) are automatically write-protected state, not controlled by FLASH_WPR  
register; unread-protected state, all main memory pages are controlled by FLASH_WPR register.  
2) System boot code area, SDI mode, RAM area cannot erase or program the main memory, except the whole  
chip erase. The user option byte area can be erased or programmed. If you try to unprotect the read  
(programming user words), the chip will automatically erase the entire user area.  
<em>Note: The internal RC oscillator (HSI) must be turned on when programming / erasing flash memory.</em>
