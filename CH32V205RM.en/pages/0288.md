MASK_UC_SYS_CTRL:

<table><caption>Table 20-2 USB system control combination</caption><tr><th>RB_UC_HOST_MODE</th><th>MASK_UC_SYS_CTRL</th><th>USB system control description</th></tr><tr><td>0</td><td>00</td><td style="text-align:left">Disable the USB device function, turn off the internal pull-up resistor.</td></tr><tr><td>0</td><td>01</td><td style="text-align:left">Enable the USB device function, close the internal pull-up resistor, and need to add an external pull-up.</td></tr><tr><td>0</td><td>1x</td><td style="text-align:left">Enable USB device function, enable internal 1.5K pull-up resistor. This pull-up resistor takes precedence over the pull-down resistor and can also be used in GPIO mode.</td></tr><tr><td>1</td><td>00</td><td>USB host mode, normal working state.</td></tr><tr><td>1</td><td>01</td><td style="text-align:left">USB host mode, forcing DP/DM to output SE0 state.</td></tr><tr><td>1</td><td>10</td><td style="text-align:left">USB host mode, forces DP/DM to output J state.</td></tr><tr><td>1</td><td>11</td><td style="text-align:left">USB host mode, force DP/DM to output K state/wake up.</td></tr></table>
