# Overview

CH32V205 is an industrial-grade general-purpose microcontroller designed around the QingKe RISC-V core. The  
CH32V205 integrates a USB2.0 high-speed PHY transceiver (480Mbps) and a PD PHY, supporting PDUSB,  
including USB Host and USB Device functionality, USB PD, and Type-C fast charging capabilities. It provides a  
programmable protocol I/O controller (PIOC), Flexible Static Memory Controller (FSMC), QSPI interface, CAN  
interface, 8 USARTs, 2 I2Cs, 2 SPIs, multiple timers, 2 OPAs, 2 CMPs, a 4Msps high-speed 12-bit ADC, and  
16-channel Touchkey.  
This manual provides detailed usage information of CH32V205 and CH32V203 chips for user&#x27;s application  
development.
