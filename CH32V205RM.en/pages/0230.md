The default values after reset are all represented by binary numbers, and the bit values are described as follows:  
0: Always 0 after reset;  
1: Always 1 after reset;  
X: Reset does not affect data; initial data value is undefined;  
- -: Always clears to 0 after power-on reset; system reset or host forced reset does not affect data.
The read/write specifications for the host side are as follows:  
W: Bits that can be read or written;  
R: Read-only bits;  
U: Invisible bit, neither readable nor writable;  
S: Read-only switch bit. The host-side visible SFR_TIMER_CTRL differs from the eMCU side in that the  
SB_TMR0_ENABLE and SB_TMR0_OUT_EN bits are replaced by SB_GP_BIT_Y and SB_GP_BIT_X
