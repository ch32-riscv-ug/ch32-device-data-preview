<em>Note: Those with 100 pins support FSMC, and only support address and data line multiplexing mode.</em>  
NOR FLASH and PSRAM support unaligned access. For asynchronous mode, each operation requires an accurate  
address; for synchronous mode, only single address signal is issued, and then batches of data are sequentially  
processed through CLK. For NOR FLASH that supports unaligned batch access, the unaligned access mode of the  
memory can be set to the same mode as HB. If it cannot be set, the unaligned access mode is disabled, and the  
unaligned access request is divided into 2 consecutive access operations.
