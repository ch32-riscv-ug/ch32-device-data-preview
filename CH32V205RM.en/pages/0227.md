### 16.2.3 Stack

The eMCU features a stack memory with a depth of 6 levels and an 11-bit data width. It is used to store the  
program return address during subroutine calls and can also be employed with the PUSHAS instruction to save  
variables, status data, and other information from the running program onto the stack.  

### 16.2.4 Sleep and Awakening

When SB_MST_CLK_GATE is 0, the eMCU program will suspend execution. After executing the SLEEP or  
SLEEPX instruction, the eMCU enters sleep mode. The eMCU is designed as fully static, where program  
suspension and sleep mode have equivalent effects.  
After entering sleep, the eMCU supports two wake-up methods: - Wake-up via level change on a pin with level  
change detection enabled. - Wake-up via the SB_MST_CLK_GATE signal transitioning from 0 to 1.  

### 16.2.5 Event Wait Instruction

The WAITB instruction supports waiting for 8 types of events. When the event is invalid, WAITB continues to  
wait indefinitely, with the program counter (PC) remaining unchanged. Upon detecting the target event, the wait is  
terminated, and the next instruction is executed. Timer timeout reset can be optionally enabled during the wait.  
The instruction parameter WB_DATA_SW_MR_0 indicates waiting until SB_DATA_SW_MR becomes 0 to exit;  
if it is already 0, exit immediately.  
The instruction parameter WB_BIT_CYC_TAIL_1 indicates waiting until SB_BIT_CYC_TAIL becomes 1 to exit;  
if it is already 1, it exits immediately.  
The instruction parameter WB_PORT_I0_FALL indicates waiting until SB_PORT_IN0 detects a falling edge to  
exit; if a falling edge was previously detected and recorded, it also exits immediately, clearing the falling edge  
detection record upon exit.  
The instruction parameter WB_PORT_I0_RISE indicates waiting until SB_PORT_IN0 detects a rising edge to  
exit. If a rising edge has already been detected as recorded, it exits directly and clears the rising edge detection  
record upon exit.  
The instruction parameter WB_DATA_MW_SR_1 indicates waiting until SB_DATA_MW_SR is 1 to exit. If it is  
already 1, it exits directly.  
The instruction parameter WB_PORT_XOR1_1 indicates waiting until SB_PORT_XOR1 is 1 before exiting. If it  
is already 1, exit directly.  
The instruction parameter WB_PORT_XOR0_0 indicates waiting until SB_PORT_XOR0 is 0 before exiting. If it  
is already 0, exit directly.  
The instruction parameter WB_PORT_XOR0_1 indicates waiting until SB_PORT_XOR0 is 1 before exiting; if it  
is already 1, exit immediately.  

### 16.2.6 Bit Transfer Instruction

Bit transfer instructions support 2-bit operation registers: BP1F and BG1F correspond to register  
SFR_INDIR_ADDR, while BP2F and BG2F correspond to register SFR_DATA_EXCH.
