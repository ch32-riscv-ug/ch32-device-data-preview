# Chapter 10 GPIO and Alternate Function (GPIO/AFIO)

The GPIO port can be configured in a variety of input or output modes, with built-in pull-up or pull-down  
resistors that can be closed, and can be configured for push-pull or open-drain functions. The GPIO port can also  
be reused into other functions.  
PA11/PA12 can be multiplexed as USB I/O pins and feature 2 sets of mutually exclusive pull-up and pull-down  
resistors. When RB_UC_RST_SIE = 1, they function as standard GPIOs, and the control methods and  
characteristics of the pull-up and pull-down resistors are the same as those of other GPIOs. When  
RB_UC_RST_SIE = 0, they function as dedicated USB pins UDM/UDP. The USB pull-up resistor is  
approximately 1.5K; refer to Table 20-2 for control implementation. The USB pull-down resistor is approximately  
15K and is controlled by RB_UH_PD_DIS in R8_USB_CTRL; neither is controlled by the GPIO.  
PA0/PA1 can be multiplexed as USB PD I/O pins and feature 2 sets of independent pull-up and pull-down  
resistors. The control methods for the pull-up and pull-down resistors, which share the same characteristics as  
other GPIOs, are identical to those of other GPIOs. There is an additional set of pull-up and pull-down resistors  
Rd (not integrated in some package variants) for the Type-C pins, controlled by  
R16_PORT_CC1/R16_PORT_CC2. Additionally, the USBPD_IN_HVT bit in AFIO_CR can be used to select  
high-threshold input mode for PA0/PA1.  

## 10.1 Main Features

Each pin of the port can be configured to one of the following multiple modes  
● Floating input ● Open-drain output  
● Pull-up input ● Push-pull output  
● Pull-down input ● Inputs and outputs of alternate functions  
● Analog input  
Many pins have the alternate function, and many other peripherals map their output and input channels to these  
pins. The specific usage of these alternate pins needs to refer to each peripheral. Whether these pins are reused and  
remapped is explained in this chapter.
