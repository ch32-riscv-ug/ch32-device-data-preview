### 23.2.8 CMP Low-power Mode

Setting the LPx bit, CMPx enters the low-power mode, the current corresponds to a reduction of about 3.2μA, and  
it will prolong the comparison time of CMP and increase the output offset voltage. Please refer to the  
CH32V205DS0 for the corresponding parameter values.  

### 23.2.9 CMP Reset

After the OPA function is enabled, set RST_ENx=1 to turn on the CMPx reset function. When the CMPx output is  
high, the system is reset.  

### 23.2.10 CMP Brake

The brake signal source of timer can be selected by setting BKIN_SEL bit in CMP_CTLR register. When  
BKIN_SEL=0, the output of CMP1 is used as the brake source of timer. When BKIN_SEL=1, the output of  
CMP2 is used as the timer brake source.  

### 23.2.11 CMP Filter

The CMPx filtering function can be enabled by setting the FILT_ENx bits in the CMP_FILT register, and the  
CMPx filtering sampling interval can be configured using the FILTx[4:0] bits.
