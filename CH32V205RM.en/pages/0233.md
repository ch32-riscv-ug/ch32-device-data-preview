### 16.4.8 Port Input Output Register (SFR_PORT_IO)

The port contains 2 bidirectional input/output pins, each independently configurable as input or output via its  
respective direction bit SB_PORT_DIR. When set as output, data from SB_PORT_OUT is output to the pin. The  
default direction after reset is input. SB_PORT_IN is used to acquire the current pin input level (when  
SB_PORT_IN_EDGE=0) or the pin input level from the previous cycle (when SB_PORT_IN_EDGE=1), with the  
latter being approximately half a clock cycle ahead of the former.  
Both pins feature level change detection. When the input level differs from the data in the output data register  
SB_PORT_OUT, the corresponding SB_PORT_XOR bit becomes 1.  
The IO0 pin offers more available input instructions and methods, making it more suitable than IO1 for input or  
bidirectional data.  
The following table is a description of the port input and output register SFR_PORT_IO.
