<strong>Address Phase</strong>  
During the address phase, 1 to 4 bytes may be sent to the FLASH to indicate the operation address. The number of  
address bytes to be sent is configured in the ADSIZE[1:0] field of the R32_QSPIx_CCR register. In Indirect Mode  
and Auto Polling Mode, the address bytes to be sent are specified in the ADDRESS[31:0] field of the  
R32_QSPIx_AR register. In Memory-Mapped Mode, the address is provided directly by the system.  
The address phase can be configured to transmit 1 bit (via SIO0 in single-wire SPI mode), 2 bits (via SIO0/SIO1  
in dual-wire SPI mode), or 4 bits (via SIO0/SIO1/SIO2/SIO3 in quad-wire SPI mode) by setting the  
ADMODE[1:0] field in the R32_QSPIx_CCR register. If ADMODE = 00b, the address phase is skipped, and the  
command sequence proceeds directly to the next phase (if present).  
<strong>Alternate Byte Phase</strong>  
During the alternate byte phase, 1-4 bytes of data are sent to the FLASH, typically used to control operating  
modes. The number of alternate bytes to be sent is configured in the ABSIZE[1:0] field of the R32_QSPIx_CCR  
register. The specification of the bytes to be sent is completed in the R32_QSPIx_ABR register.  
Configured via the ABMODE[1:0] field in the R32_QSPIx_CCR register, the Alternate Byte Phase can transmit 1  
bit at a time (via SIO0 in single-wire SPI mode), 2 bits at a time (via SIO0/SIO1 in dual-wire SPI mode), or 4 bits  
at a time (via SIO0/SIO1/SIO2/SIO3 in quad-wire SPI mode). If ABMODE=00b, the alternate byte phase is  
skipped, and the command sequence proceeds directly to the next phase (if present).  
During the alternate byte phase, it is sometimes sufficient to transmit a single half-byte rather than a full byte. For  
example: When transmitting alternate bytes using only 2 cycles in dual-wire mode. In this case, the firmware can  
adopt four-wire mode (ABMODE=11b) and transmit a byte by setting bits [7] and [3] of ALTERNATE to 1 (SIO3  
remains high) and bits [6] and [2] to 0 (SIO2 line remains low). The upper 2 bits of the half-byte are stored in bits  
[4:3] of ALTERNATE, while the lower 2 bits reside in bits [1] and [0]. For instance, if half-byte 2 (0010) is  
transmitted via SIO0/SIO1, ALTERNATE should be set to 0x8A (1000_1010).  
<strong>Null Instruction Cycle Phase</strong>  
During the null instruction cycle phase, when operating at higher clock frequencies, no data transmission or  
reception occurs within a specified 1-31 cycle window to ensure sufficient time for the FLASH to prepare data.  
The number of cycles in this phase is defined by the DCYC[4:0] field in the R32_QSPIx_CCR[22:18] register.  
In SDR mode, the duration is defined by a fixed number of full clock cycles. If DCYC is 0, the empty instruction  
cycle phase is skipped, and the command sequence proceeds directly to the data phase (if present).  
The operating mode during the empty instruction cycle phase is fixed to single-wire mode.
