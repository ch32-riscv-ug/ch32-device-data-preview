#### 9.5.4.1 Machine Trap-vector Base Address Register (MTVEC)

CSR address: 0x305

For the V3 series microcontrollers (MCUs), the startup file is configured by default to set MODE0 to 1. The entry  
points for exceptions or interrupts are offset by 4 times the interrupt number. Note that the V3B microcontroller  
can use either a jump instruction or the absolute address of the interrupt service routine; the default startup file is  
configured to use the absolute address.  

#### 9.5.4.2 User Mode Global Interrupt Enable Register (GINTENR)

This register is used to control the enabling and disabling of global interrupts. In machine mode, global interrupts  
are enabled and disabled via the MIE and MPIE bits in the mstatus register; this register cannot be accessed in  
user mode. The global interrupt enable register (gintenr) is a mapping of the MIE and MPIE bits in mstatus; in  
user mode, gintenr can be manipulated to set or clear the MIE and MPIE bits.  
CSR address: 0x800
