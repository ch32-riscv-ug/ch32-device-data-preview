### 26.3.9 Instruction Sent Only Once

Certain FLASH devices (e.g., Winbound) support a mode where commands must be sent using only the first  
command sequence, with subsequent commands executed directly based on the address. Users enable this feature  
by setting the SIOO bit in the R32_QSPIx_CCR register.  
The SIOO bit applies to all functional modes: Indirect Mode, Status Polling Mode, and Memory-Mapped Mode.  
When SIOO is set to 1, only the first command is sent as an instruction, and a write operation is performed on the  
R32_QSPIx_CCR register. Subsequent command sequences skip the instruction phase until the R32_QSPIx_CCR  
register is written again. However, the SIOO bit is ineffective when IMODE=00b (no instruction).  

### 26.3.10 QSPI Error Management

The possible error situations are:  
● In indirect mode or status flag polling mode, if an incorrect address is set in the R32_QSPIx_AR register,  
TEF will be set to 1 based on the FLASH size defined by FSIZE[4:0] in the R32_QSPIx_DCR register. If  
enabled, an interrupt will also be generated.  
● In indirect mode, if the sum of the address and data length exceeds the FLASH size, TEF will be set to 1  
when the access is triggered.  
● In memory-mapped mode, if the master device attempts an out-of-range access or QSPI is disabled: a bus  
error will be generated in response to the master device’s request.  
● If the master device attempts to access the memory-mapped space while memory-mapped mode is disabled:  
a bus error will be generated in response to the master device’s request.  

### 26.3.11 Busy Bit and Abort Function of QSPI

When QSPI begins operating on the FLASH, the BUSY bit in the R32_QSPIx_SR register is automatically set to  
1. In indirect mode, the BUSY bit is cleared when QSPI completes the requested command sequence and the  
FIFO is empty; In automatic polling mode, the BUSY bit goes low only after the last periodic access completes,  
either due to a match when APMS=1 or due to an abort operation. In memory-mapped mode, after the first access,  
the BUSY bit goes low only upon a timeout event or an abort.  
Any operation can be aborted by setting the ABORT bit to 1 in the R32_QSPIx_CR register. Upon completion of  
the abort, the BUSY and ABORT bits automatically reset, and the FIFO is cleared.  
<em>Note: If the writing operation to the status register is stopped, some FLASH may have abnormal behavior.</em>
