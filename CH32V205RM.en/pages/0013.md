Enter: Set the kernel register control bit SLEEPDEEP to 1 and the power control register PDDS to 1; execute WFI  
or WFE; optionally enable SEVONPEND and SLEEPONEXIT; and, before entering STANDBY mode, set  
FLASH_LP[1:0] to 10b, i.e., FLASH low-power mode 1.  
Exit:  
1) Any of the external events EXTI0 through EXTI17 (excluding interrupts); after being woken up by one of these,  
the microcontroller performs a power-on reset.  
2) The rising edge of the WKUP pin, the rising edge of an RTC alarm event, an external reset on the NRST pin, an  
IWDG reset, or an RTC alarm; after being woken up by one of these, the microcontroller performs a power-on  
reset.  
In Standby mode, when normal power is supplied, setting R4KSTY=1 in the PWR_CTLR register prevents the  
4K-byte RAM from losing power, and setting R28KSTY=1 prevents the 28K-byte RAM from losing power;  
When powered by VBAT, set R4KSTY=1 in the PWR_CTLR register to prevent the 4K-byte RAM from losing  
power, and set R28KSTY=1 to prevent the 28K-byte RAM from losing power. On this basis, setting RAMLV=1  
in the PWR_CTLR register enables the RAM low-voltage mode, minimizing power consumption.  
<em>Note: In debug mode, if the microprocessor enters stop or standby mode, the debug connection will be lost.</em>  
<em>R4KSTY=1 controls the address range of the 4K-byte RAM: 0x20000000—0x20000000+4K;</em>  
<em>R28KSTY=1 controls the address range of the 28K-byte RAM: 0x20000000+4K—0x20000000+4K+28K.</em>  

### 2.3.5 RTC Auto-wakeup (AWU)

The RTC supports automatic wake-up without the need for external interrupts. By programming the time base, the  
system can be periodically woken from Sleep or Standby mode.  
You can choose either a high-precision external 32.768KHz crystal oscillator (LSE) or an internal LSI oscillator as the  
RTC clock source; however, the LSI oscillator offers lower precision and higher power consumption compared to the  
LSE.  
The RTC alarm event can wake the MCU from Sleep mode and Standby mode. To enable this functionality, external  
interrupt line 17 must be configured, and the RTC must be set to generate alarm events.  

### 2.3.6 FLASH Low-power Mode

Before entering FLASH low-power mode, you must first set bit 1 of the FLASH_LP_REG field in the power control  
register (PWR_CTLR) to enable FLASH low-power mode, and then configure the FLASH_LP[1:0] bits in the power  
control register (PWR_CTLR). At this point, the MCU’s FLASH low-power mode configuration is complete.
