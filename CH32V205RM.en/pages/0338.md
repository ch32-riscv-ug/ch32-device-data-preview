### 23.2.3 OPA1 Interrupt

The OPA interrupt can only wake up SLEEP mode, OPA1 interrupt configuration:  
1) Configure the OPA interrupt in the core&#x27;s PFIC to ensure that it can respond correctly;  
2) Configure POLL_EN1=1 to enable the OPA1 polling function.  
3) Enable OPA1 to enable the OPA1 interrupt.  
Interrupt Configuration:  
- (1) OPA interrupt
Set IE_OUT1=1 to turn on OPA1 interrupt enable and enter the interrupt when OPA1 outputs high level.  
- (2) OPA polling interrupt
Set IE_CNT1=1 to turn on the OPA1 polling interval end interrupt enable and enter the interrupt when the P  
terminal of OPA1 is polled once.  
- (3) OPAN MI
Set NMI_EN1=1 to turn on the OPA1 NMI interrupt enable, and enter the NMI interrupt when the OPA1 output is  
high.  

### 23.2.4 OPA1 Reset

After enabling the OPA function, set RST_EN1=1 to turn on the OPA1 reset function, and the system is reset  
when the OPA1 output is high.  

### 23.2.5 OPA Brake

The brake signal source can be selected by setting the BKIN_CFG[1:0] bits in the OPA_CFGR1 register. When  
BKIN_CFG = 00b, the timer brake comes from the I/O; when BKIN_CFG = 01b, the timer brake comes from the  
output of CMP1/CMP2; When BKIN_CFG = 10b, the timer’s brake signal comes from the OPA1 poll result;  
when BKIN_CFG = 11b, the timer’s brake signal comes from the OPA2 output.  

### 23.2.6 CMP

In the CMP_CTLR register: Configure the ENx bits to enable the corresponding CMPx; configure MODEx[1:0]  
to select the output channel for CMPx as a standard I/O port or an internal timer channel; Configure PSELx[1:0]  
to select the positive input pin for CMPx; configure NSELx[1:0] to select the negative input pin for CMPx;  
configure the HYENx bit to enable the CMPx hysteresis function.
