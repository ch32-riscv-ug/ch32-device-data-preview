Setting the DOUBLE_MODE bit in the DMA_CFGRx register to 1 enables dual-buffer mode, automatically  
enters loop mode, and automatically switches memory addresses (alternating between DMA_MADDRx and  
DMA_M1ADDRx) after completing one cycle.  
At the end of each cycle, the DMA controller switches from one memory target to another. This allows the DMA  
transfer to fill or access a second memory region while the software is processing the first one. The dual-buffer  
channel operates in both directions, as shown in the table below.  

<!-- p117-table-001 (table-11-4@1) -->
<table><caption>Table 11-4 Source and destination address registers in dual buffer mode</caption><tr><th>DMA_CFGRx.DIR</th><th>Direction</th><th>Source address</th><th>Target address</th></tr><tr><td>0</td><td>Read from peripheral</td><td>DMA_PADDRx</td><td style="text-align:left">DMA_MADDRx/<br>DMA_M1ADDRx</td></tr><tr><td>1</td><td>Read from memory</td><td>DMA_MADDRx/DMA_M1ADDRx</td><td>DMA_PADDRx</td></tr></table>

<em>Note: Configuring memory-to-memory mode is prohibited when dual-buffer mode is enabled.</em>
