# Chapter 30 Extended Configuration


## 30.1 Extended Configuration

The system provides 2 EXTEN extension configuration unit (EXTEN_CTR register). The unit uses a HB clock  
and performs a reset action only when the system is reset.  
It mainly includes the following extended control bit functions:  
1) Adjusting the core voltage: The LDOTRIM and ULLDOTRIM fields are set to their default values; these  
values can be modified to balance performance and power consumption.  
2) PLL clock selection: The HSIPRE field, in conjunction with the existing clock configuration registers, allows  
you to select whether the HSI clock is divided or undivided as the input clock for the PLL.  
3) Lock-up function monitoring: If the LKUPEN field is enabled, the Lock-up situation monitoring of the  
system will be turned on. In case of Lock-up, the system will reset the LKUPRST field by software and set  
the LKUPRST field to 1. After reading, you can write 1 to clear this flag.  
The EXTEN_CTLR1 register contains the mapping selection functions for the DMA&#x27;s 8 channels.
