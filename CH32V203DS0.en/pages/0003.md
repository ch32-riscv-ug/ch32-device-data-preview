# Chapter 1 Series Product Description

CH32V series are industrial-grade general-purpose enhanced MCUs based on 32-bit RISC-V instruction set and  
architecture. Its products are divided by function resources into categories such as general-purpose, connectivity,  
and wireless communication. They extend each other in terms of package types, peripheral resources and  
quantities, pin numbers, and device characteristics, but they are compatible with each other in software, functions,  
and hardware pin configurations. The product iterations and rapid applications provide freedom and convenience  
for users in product development.  
For the features of this series of products, please refer to the datasheet.  
For the peripheral function description, usage and register configuration, please refer to &quot;CH32FV2_V3RM&quot;.  
The datasheets and reference manuals can be downloaded on the official website of WCH:  
https://www.wch-ic.com/  
Information about the RISC-V instruction set architecture can be downloaded from: https://riscv.org/  
This manual is for CH32V203 series datasheet. Please refer to &quot;CH32V307DS0&quot; for V303/305/307/317  
series and &quot;CH32V208DS0&quot; for V208 series.
