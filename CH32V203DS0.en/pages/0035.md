<em>Note 4: For CH32V203C6T6, CH32V203C8T6 and CH32V203C8U6 chips, pin 5 and pin 6 are configured as</em>  
<em>OSC_IN and OSC_OUT function pins by default after chip reset, and the software can reset these two pins to</em>  
<em>PD0 and PD1 functions. For CH32V203F6P6, CH32V203G6U6 and CH32V203K8T6 chips, pin 2 and pin 3</em>  
<em>are configured as OSC_IN and OSC_OUT function pins by default after chip reset, and the software can reset</em>  
<em>these 2 pins to PD0 and PD1 functions. While CH32V203RBT6 chip only has OSC_IN and OSC_OUT function</em>  
<em>pins, which cannot be reused as PD0 and PD1 functions. For more details, please refer to the reuse function</em>  
<em>I/O chapter and debugging setting chapter in the CH32FV2x_V3xRM manual;</em>  
<em>Note 5: For chips with neither BOOT0 nor BOOT1/PB2 pins lead out, the internal BOOT0 pin has been</em>  
<em>shorted to GND and the BOOT1/PB2 pins are floating. Under low power consumption, it is recommended to</em>  
<em>configure PB2 in pull-down input mode to prevent additional current.</em>  
<em>For chips where the BOOT1/PB2 pin is lead out but the BOOT0 pin is not, the BOOT0 pin is internally shorted</em>  
<em>to GND.</em>  
<em>For chips with the BOOT0 pin but not the BOOT1/PB2 pin, the internal BOOT1/PB2 pin has been shorted to</em>  
<em>GND. Under low-power consumption, it is recommended to configure the PB2 pull-down input mode to prevent</em>  
<em>additional current.</em>  
<em>Note 6: For chips with BOOT0 and PB8 or PB9 pins packaged together, it is recommended to connect an</em>  
<em>external 4.7K pull-down resistor to ensure that BOOT0 is low during power-on in order to enter the program</em>  
<em>flash memory boot mode. After normal operation, the PB8 or PB9 pin can be used for output as needed.</em>  
<em>Note 7: For devices in 20-pin/28-pin package, several pins are shorted (at least 2 I/O function pins are</em>  
<em>physically shorted as one pin). In this case, the driver should not configure the output function at the same time,</em>  
<em>otherwise the pins may be damaged. Note pin states when there is a power consumption requirement;</em>  
<em>Note 8: The value underlined by the remapping function indicates the configuration value of the corresponding</em>  
<em>bit in the AFIO register. For example, UART4_RX_3 indicates that the corresponding bit of AFIO register is</em>  
<em>configured as 11b;</em>  
<em>Note 9: TIM2_CH1 and TIM2_ETR share a common pin, but cannot be used at the same time.</em>
