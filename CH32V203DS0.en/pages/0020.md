### 2.5.23 2-wire SDI Serial Debug Interface

The core comes with a serial 2-wire serial debug interface (SDI), including SWDIO and SWCLK pins. The  
default debug interface pin function is turned on after system power on or reset, and SDI can be turned off as  
needed after the main program is running.
