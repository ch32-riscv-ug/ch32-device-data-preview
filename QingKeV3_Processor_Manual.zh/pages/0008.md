# 第 3 章 PFIC 与中断控制

青稞 V3 微处理器内部设计了一个可编程快速中断控制器（Programmable Fast Interrupt  
Controller,PFIC）可管理异常在内的最多256个中断。  
其中V3A、V3B、V3C、V3V前16个固定为微处理器内部中断，其余为外部中断，即最大支持扩展  
240个外部中断。其主要特征如下：  
● 240个外部中断，每个中断请求都有独立的触发和屏蔽控制位，有专用的状态位  
● 可编程多级中断嵌套，最大嵌套深度2级  
● 特有免表（Vector Table Free,VTF）中断响应机制，4路可编程直达中断向量地址  
其中V3F前32个固定为微处理器内部中断，其余为外部中断，即最大支持扩展224个外部中断。  
其主要特征如下：  
● 224个外部中断，每个中断请求都有独立的触发和屏蔽控制位，有专用的状态位  
● 可编程多级中断嵌套，最大嵌套深度2级  
● 特有快速中断进出机制，硬件自动压栈和恢复，最大硬件压栈深度2级，无需指令开销  
● 特有免表（Vector Table Free,VTF）中断响应机制，4路可编程直达中断向量地址  
注：不同型号的微处理器，中断控制器支持的最大嵌套深度和硬件压栈深度不同，具体可参考表1-1；
