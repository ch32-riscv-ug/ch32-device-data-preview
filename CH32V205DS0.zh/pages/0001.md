# 概述

CH32V205是基于青稞RISC-V内核设计的工业级通用微控制器。CH32V205内置USB 2.0高速PHY  
收发器（480Mbps）和PD PHY，支持PDUSB，包括USB Host主机和USB Device设备功能、USB PD及  
Type-C快充功能，提供了可编程协议I/O控制器PIOC、静态存储器控制器FSMC、QSPI接口、CAN接  
口、8组USART串口、2组I2C、2组SPI、多组定时器、2组OPA运放、2组CMP电压比较器、4Msps  
高速12位ADC、16路Touchkey等丰富外设资源。  

# 产品特性

● 内核Core： - 多路输出通道，可选ADC引脚  
- 青稞RISC-V3B内核，RV32ICBM-X指令集 ● 高速12位模数转换ADC：
- 快速可编程中断控制器+硬件中断堆栈 - 模拟输入范围：VSSA～VDDA
- 2级硬件中断堆栈 - 16路外部信号通道+3路内部信号通道
- 冲突处理机制 - 片上温度传感器
- 系统主频支持最高192MHz ● 16路TouchKey通道检测
● 存储器： ● 实时时钟RTC：32位独立定时器  
- 32KB易失数据存储区SRAM ● 多组定时器：
- 256KB程序存储区CodeFlash - 1个16位高级定时器，提供死区控制和紧急
- 3328B系统引导程序存储区BootLoader 刹车，提供用于电机控制的PWM互补输出
- 256B系统非易失配置信息存储区 - 2个16位通用定时器
- 256B用户自定义信息存储区 - 1个32位通用定时器
● 电源管理和低功耗： - 2个看门狗定时器：独立和窗口型  
- 系统供电VDD 电压范围：1.8～3.6V - 系统时基定时器：32位计数器
- 独立供电VIO 电压范围：1.45～3.6V ● 8组USART串口：支持LIN和ISO7816
- 低功耗模式：睡眠、停止、待机 ● 2组I2C接口：支持SMBus/PMBus
- VBAT 电源独立为RTC和后备寄存器供电 ● 2组SPI接口
● 系统时钟和复位： ● QuadSPI接口  
- 内置出厂调校的8MHz的RC振荡器 ● FSMC静态存储器接口
- 内置约40KHz的RC振荡器 ● CAN接口（2.0B主动）
- 内置PLL，可选CPU时钟达192MHz ● USB 2.0全速控制器及PHY：
- 外部支持3～25MHz高速振荡器 - 支持USB主机或USB设备，支持单线USB
- 外部支持32.768KHz低速振荡器 ● USB 2.0高速控制器及PHY：
- 上电/下电复位、可编程电压监测器 - 支持480Mbps高速USB主机或USB设备
● 2组16路通用DMA控制器： - 支持USART串口或I2C引脚映射  
- 16个通道，支持环形缓冲区管理 ● USB PD和Type-C控制器及PHY：
● 可编程协议I/O控制器PIOC： - 支持DRP、Sink和Source应用，支持PDUSB  
- 可编程，支持多种单线接口、两线接口 - 支持PD3.2和EPR，支持100W或240W快充
● 2组模拟电压比较器CMP： ● 快速GPIO端口：  
- 各2路输入通道，可选内部参考电压 - 80个I/O口，支持16个外部中断
- 输出到I/O或者内部直接触发TIM ● 安全特性：芯片唯一ID
● 2组运放OPA/PGA/电压比较器： ● 调试模式：单线（默认）/双线调试接口  
- 多路输入通道，可选多档增益 ● 封装形式：LQFP
