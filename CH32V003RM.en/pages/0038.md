<em>Note:</em>  
<em>1. The default value of PFIC_ISR1 register is 0xC, that is, NMI and exception are always enabled by default.</em>  
<em>2. NMI and EXC support interrupt pending clear and setting operation, but not interrupt enable clear and</em>  
<em>setting operation.</em>  
<em>Note: When using the PFIC_IENRx register to mask any interrupt or the CSR register to mask global interrupts,</em>  
<em>add an additional “fence.i” instruction to synchronize the kernel control state with the interrupt enable state.</em>
