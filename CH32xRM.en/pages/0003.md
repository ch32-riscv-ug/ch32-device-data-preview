# Chapter 1 Memory and Bus Architecture


## 1.1 Bus Architecture

The CH32F103 is a microcontroller based on the Cortex-M3 core. The core, arbitration unit, DMA module, and  
SRAM memory, etc. in the framework interact through multiple sets of buses. The system architecture is as  
shown in Figure 1-1.  
The CH32V103 is a general microcontroller based on the QingKe RISC-V3A core. The core, arbitration unit,  
DMA module and SRAM memory, etc. of the architecture interact through multiple sets of buses. The 2-level  
assembly line processing is adopted for the core, and is equipped with static branch prediction and command  
prefetch mechanisms to achieve the best performance ratio of the system with low-power, low-cost, and  
high-speed operation. The system architecture is as shown in Figure 1-2.
