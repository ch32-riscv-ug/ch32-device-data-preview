### 24.4.7 Main Memory Fast Erase

Quick erasure is also performed according to the pages (128 bytes).  
1) Check the FLASH_CTLR register LOCK bit. If it is 1, you need to perform the &quot;Release Flash Memory  
Lock&quot; operation.  
2) Check the BSY bit in the FLASH_STATR register to ensure that there is no other programming operation in  
progress.  
3) Check the FLASH_CTLR register FLOCK bit. If it is 1, you need to perform the &quot;Fast Programming Mode  
Unlock&quot; operation.  
4) Set the FTER bit in the FLASH_CTLR register to enable the fast erasure mode function.  
5) Write the page heading address of the fast erasure page to the FLASH_ADDR register.  
6) Set the STAT bit in the FLASH_CTLR register to ‘1’ to start the fast page erasure action.  
7) When the BYS bit changes to &#x27;0&#x27; or the EOP bit in the FLASH_STATR register to be &#x27;1&#x27;, it indicates the end  
of erasure. Clear the EOP bit to 0.  
8) Check the FLASH_STATR register to see if there is an error, or read the erasure page address data for  
verification.  
9) To continue fast page erasure, you can repeat steps 5-8 to end erasing and clear the FTER bit to 0.
