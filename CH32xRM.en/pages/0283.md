#### 21.2.2.5 Endpoint 7(15) Mode Control Register (R8_UEP7_MOD)


<!-- p283-table-001 (table-21-6@1) -->
<table><tr><th><strong>Bit</strong></th><th><strong>Name</strong></th><th><strong>Access</strong></th><th><strong>Description</strong></th><th style="text-align:left"><strong>Reset value</strong></th></tr><tr><td>[7:5]</td><td>Reserved</td><td>RO</td><td>Reserved.</td><td>0</td></tr><tr><td>3</td><td>RB_UEP7_RX_EN</td><td>RW</td><td style="text-align:left">1: Enable endpoint 7 (15) reception (OUT);<br>0: Disable endpoint 7(15) reception.</td><td>0</td></tr><tr><td>2</td><td>RB_UEP7_TX_EN</td><td>RW</td><td style="text-align:left">1: Enable endpoint 7 (15) transmission (IN);<br>0: Disable endpoint 7(15) transmission.</td><td>0</td></tr><tr><td>1</td><td>Reserved</td><td>RO</td><td>Reserved.</td><td>0</td></tr><tr><td>0</td><td>RB_UEP7_BUF_MOD</td><td>RW</td><td style="text-align:left">Endpoint 7(15) data buffer mode control bit.</td><td>0</td></tr></table>

<em>Note: For CH32V103x, endpoint 7 configuration option is mapped to endpoint 15. CH32F103x series products</em>  
<em>do not have this register.</em>  
The data buffer mode of USB endpoint 1 ~ endpoint 15 is configured in combination for RB_UEPn_RX_EN,  
RB_UEPn_TX_EN and RB_UEPn_BUF_MOD, respectively. Refer to Table 21-6 for details. Among them, in  
the double 64-byte buffer mode, the first 64-byte buffer will be selected based on RB_UEP_*_TOG=0 and the  
last 64-byte buffer will be selected based on RB_UEP_*_TOG=1 during USB data transmission, and  
RB_UEP_AUTO_TOG=1 is set to realize automatic switch. Note: During synchronous transmission, when  
(RB_UEPn_RX_EN, RB_UEPn_TX_EN, RB_UEPn_BUF_MOD) are only (1, 0, 0) or (0, 1, 0), endpoint 3  
supports a maximum of 1023 bytes.
