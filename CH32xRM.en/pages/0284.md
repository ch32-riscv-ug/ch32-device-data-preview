#### 21.2.2.7 Endpoint n Transmit Length Register (R8_UEPn_T_LEN) (n=0-7)


<!-- p284-table-003 (table-21-6@2) -->
<table><tr><th><strong>Bit</strong></th><th><strong>Name</strong></th><th><strong>Access</strong></th><th><strong>Description</strong></th><th style="text-align:left"><strong>Reset value</strong></th></tr><tr><td>[7:0]</td><td>R8_UEPn_T_LEN[7:0]</td><td>RW</td><td style="text-align:left">Set the number of data bytes that USB endpoint n is ready to send (applied to F103) n=0-7.</td><td>X</td></tr></table>

<em>Note 1: F103 product endpoint sending length configuration supports 0-4 endpoints, and V103 product</em>  
<em>endpoint sending length configuration supports 0-7 endpoints and can be mapped to configure the sending of</em>

<em>Note 2: Since the host endpoint sending register multiplexes the sending register of the endpoint 3 of the device,</em>  
<em>in V103, the host sending supports a maximum of 1023 bytes (for synchronous endpoint), so it is valid when the</em>  
<em>endpoint 3 sending register is expanded to 16 bits.</em>
