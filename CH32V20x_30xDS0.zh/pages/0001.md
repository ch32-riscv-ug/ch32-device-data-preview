# 概述

CH32V 系列是基于青稞 RISC-V 内核设计的工业级通用微控制器，包括 CH32V305 连接型 MCU、  
CH32V307/CH32V317 互联型 MCU、CH32V208 无线型 MCU 等。CH32V30x 和 CH32V31x 系列基于青稞 V4F  
微处理器设计，支持单精度浮点指令和快速中断响应，支持144MHz主频零等待运行，提供8组串口、  
4组电机PWM高级定时器、SDIO、DVP数字图像接口、4组模拟运放、双ADC单元、双DAC单元，内置  
USB2.0高速PHY收发器（480Mbps）、千兆以太网MAC控制器及10兆物理层收发器、10/100兆物理层  
收发器（仅适用于CH32V317）等。  

# 产品特性

● 内核Core： ● 2组12位模数转换ADC：  
- 青稞32位RISC-V4F内核，多种指令集组合 - 模拟输入范围：VSSA～VDDA
- 快速可编程中断控制器+硬件中断堆栈 - 16路外部信号+2路内部信号通道
- 分支预测、冲突处理机制 - 片上温度传感器
- 单周期乘法、硬件除法、硬件浮点 - 双ADC转换模式
- 系统主频144MHz，零等待 ● 16路TouchKey通道检测
● 存储器： ● 多组定时器：  
- 可配最大128KB易失数据存储区SRAM - 4个16位高级定时器，支持死区控制和紧急
- 可配480KB程序存储区CodeFlash 刹车，提供用于电机控制的PWM互补输出
（零等待应用区+非零等待数据区） - 4个16位通用定时器，提供输入捕获/输出比  
- 28KB系统引导程序存储区BootLoader 较/PWM/脉冲计数及增量编码器输入
- 128B系统非易失配置信息存储区 - 2个基本定时器
- 128B用户自定义信息存储区 - 2个看门狗定时器（独立和窗口型）
● 电源管理和低功耗： - 系统时基定时器：64位计数器  
- 系统供电VDD额定：3.3V ● 多种通讯接口：
- GPIO单元独立供电VIO额定：3.3V - 8个USART接口（包含5个UART）
- 低功耗模式：睡眠、停止、待机 - 2个I2C接口（支持SMBus/PMBus）
- VBAT电源独立为RTC和后备寄存器供电 - 3个SPI接口（SPI2、SPI3用于I2S2、I2S3）
● 系统时钟、复位： - USB2.0 全速主机/设备接口，内置PHY  
- 内置出厂调校的8MHz的RC振荡器 - USB2.0 全速OTG接口
- 内置约40kHz的RC振荡器 - USB2.0 高速主机/设备接口，内置PHY
- 内置PLL，可选CPU时钟达144MHz - 2组CAN接口（2.0B主动）
- 外部支持3～25MHz高速振荡器 - SDIO主机接口（MMC、SD/SDIO卡及CE-ATA）
- 外部支持32.768kHz低速振荡器 - FSMC存储器接口
- 上电和掉电复位、可编程电压监测器 - 数字图像接口DVP
● 实时时钟RTC：32位独立定时器 - 千兆以太网MAC控制器，10兆PHY收发器  
● 2组18路通用DMA控制器： - 10/100兆PHY收发器（仅CH32V317）  
- 18个通道，支持环形缓冲区管理 ● 快速GPIO端口：
- 支持TIMx/ADC/DAC/USART/I2C/SPI/I2S/SDIO - 80个I/O口，映射16个外部中断
● 4组运放、比较器：连接ADC和TIMx ● 安全特性：CRC计算单元，96位芯片唯一ID  
● 2组12位数模转换DAC ● 调试模式：串行2线调试接口  
● 封装形式：LQFP、QFN和TSSOP
