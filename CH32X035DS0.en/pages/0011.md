### 1.4.22 2-wire SDI Serial Debug Interface

The core comes with a 2-wire serial debug interface (SDI) including the SWDIO and SWCLK pins. The default  
debug interface pin function is turned on after system power-up or reset, and the SDI can be turned off as required  
after the main program is running.
