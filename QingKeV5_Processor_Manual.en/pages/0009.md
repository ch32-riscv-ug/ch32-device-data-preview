# Chapter 3 PFIC and Interrupt Control

QingKe V5 microprocessor is designed with a Programmable Fast Interrupt Controller (PFIC) that can manage  
up to 256 interrupts including exceptions.  
The first 32 of V5F are fixed as internal interrupts of the microprocessor, and the rest are external interrupts,  
i.e. the maximum number of external interrupts can be extended to 224. Its main features are as follows.  
● 224 external interrupts, each interrupt request has independent trigger and mask control bits, with  
dedicated status bits  
● Programmable multi-level interrupt nesting, maximum nesting depth 8 levels  
● Unique fast interrupt access mechanism, Hardware Prologue/Epilogue (HPE) and recovery, maximum  
hardware stack pressing depth of 3 levels, no instruction overhead.  
● Vector Table Free (VTF) interrupt response mechanism, 4-channel programmable direct access to  
interrupt vector addresses
