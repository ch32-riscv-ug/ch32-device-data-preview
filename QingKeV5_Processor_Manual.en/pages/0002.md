## 1.1 Instruction Set

QingKe V5 series microprocessors follow the standard RISC-V Instruction Set Architecture (ISA). Detailed  
documentation of the standard can be found in the RISC-V International website. The RISC-V instruction set  
has a simple architecture and supports a modular design, allowing for flexible combinations based on different  
needs, and the V5 series supports the following instruction set extensions.  
● RV32: 32-bit architecture, general-purpose register bit width of 32 bits  
● I: Support integer operation, with 32 integer registers  
● M: Support integer multiplication and division instructions  
● A: Support atomic instructions  
● C: Support 16-bit compression instruction  
● B: Support bit manipulation instructions  
● F: Support single-precision floating-point instructions  
● XW: 16-bit compression instructions for self-extending byte and halfword operations  
<em>Note:</em>  
<em>1: In order to further improve the code density, extend the XW subset, add the following compression</em>  
<em>instructions c.lbu/c.lhu/c.sb/c.sh/c.lbusp/c.lhusp/c.sbsp/c.shsp, use of which needs to be based on the MRS</em>  
<em>compiler or the toolchain it provides;</em>
