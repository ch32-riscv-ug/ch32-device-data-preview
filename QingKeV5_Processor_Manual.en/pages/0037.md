<strong>Instruction cache register (progbufx)</strong>  
This register is used to store arbitrary instructions and deploy corresponding operations, including eight. Note  
that one “ebreak” instruction is hidden after progbuf.

<strong>Pause status register (haltsum0)</strong>  
This register is used to indicate whether the microprocessor is suspended or not. Each bit indicates the  
suspended status of a microprocessor, and when there is only one core, only the lowest bit of this register is  
used to indicate it.
