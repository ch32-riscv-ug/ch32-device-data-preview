# QingKeV5 Microprocessor Manual

V1.0  

# Overview

QingKe V5 series microprocessors are self-developed 32-bit general-purpose MCU microprocessors based on  
standard RISC-V instruction set architecture. The series includes V5F. V5F supports RV32IMABCF  
instruction set and custom instruction set extensions XW. Supports single-cycle multiplication and hardware  
division, Hardware Prologue/Epilogue (HPE), Vector Table Free (VTF), streamlined 1-/2-wire debugging  
interface, and support for &quot;WFE&quot; instruction.
