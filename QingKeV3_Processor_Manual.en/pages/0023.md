Its folks are defined as.  

<!-- p23-table-003 (table-3-3@1) -->
<table><tr><th><strong>Bit</strong></th><th><strong>Name</strong></th><th><strong>Access</strong></th><th><strong>Description</strong></th><th><strong>Reset value</strong></th></tr><tr><td>[31:2]</td><td>BASEADDR</td><td>MRW</td><td style="text-align:left">Interrupt vector table base address, where bits [9:2] are fixed to 0.</td><td>0</td></tr><tr><td>1</td><td>MODE1</td><td>MRO</td><td style="text-align:left">Interrupt vector table recognition mode:<br>0: Identify by jump instruction, with limited scope, and support non-jump instruction;<br>1: Identify by absolute address, support full range, but must jump.<br>Note: This bit is only valid for V3B/C/F/V.</td><td>0</td></tr><tr><td>0</td><td>MODE0</td><td>MRW</td><td style="text-align:left">Interrupt or exception entry address mode selection.<br>0: Use of the uniform entry address.<br>1: Address offset based on interrupt number *4.</td><td>0</td></tr></table>

For MCUs with V3 series microprocessors, MODE0 is configured to be 1 by default in the startup file, and  
the entries for exceptions or interrupts are offset according to the interrupt number *4. Note that the V3A  
microprocessor stores a jump instruction at the vector table, while the V3B/C/F/V microprocessor can be either  
a jump instruction or use the absolute address of the interrupt function, which is configured as an absolute  
address in the default startup file.
