# 概述

CH32H417是基于青稞RISC-V5F和RISC-V3F双内核设计的互联型通用微控制器。CH32H417集成了  
USB 3.2 Gen1控制器和收发器、百兆以太网MAC及PHY、SerDes高速隔离收发器、Type-C/PD控制器  
及PHY，提供SD/EMMC控制器SDMMC、500MBytes通用高速接口UHSIF、DVP数字图像接口、单线协议  
主接口SWPMI、可编程协议I/O控制器PIOC、灵活存储控制器FMC、DFSDM、LTDC、GPHA、DMA控制器、  
多组定时器、8组串口、I3C、4组I2C、2组QSPI、4组SPI，2组I2S、3组CAN等外设资源，内置了  
5M采样率双12位ADC单元、20M采样率10位高速HSADC单元、16路Touchkey、双DAC单元、3组运  
放OPA、电压比较器CMP等模拟资源，支持10M/100M以太网通讯，支持USB 2.0和USB 3.0，支持USB  
Host主机和USB Device设备功能、Type-C和PDUSB快充功能，支持SerDes高速隔离及远距离传输，  
支持双内核分工提升网络协议处理效率和通讯响应速度。  

# 产品特性

● 内核Core： ● 1组10位高速模数转换HSADC：  
- 双内核结构：青稞RISC-V5F和RISC-V3F - 模拟输入范围：VSS～VDDIO
- 快速可编程中断控制器+硬件中断堆栈 - 7路外部信号通道
- V5F最高频率400MHz，V3F最高频率160MHz - 采样速率高达20Msps
● 存储器： ● 2组12位数模转换DAC  
- 896KB易失数据存储区SRAM ● 32位宽度125MHz通用高速接口UHSIF
（包含128KB ITCM和256KB DTCM） ● 150MHz数字图像接口DVP  
- 960KB程序存储区CodeFlash ● 200MHz SD/EMMC控制器：支持单双沿
- 56KB系统引导程序存储区BootLoader ● SDIO主机/从机接口：支持SD/SDIO/MMC口
- 256B用户自定义信息存储区 ● 单线协议主接口SWPMI
● 电源管理和低功耗： ● 可编程协议I/O控制器PIOC：  
- 系统供电VDD33 额定：3.3V - 可编程，支持多种单线接口、两线接口
- 常规GPIO供电VDDIO，额定3.3V，支持1.8V - 支持单线RGB芯片多级串联
- 高速GPIO供电VIO18，可选1.2/1.8/2.5/3.3V ● 以太网控制器MAC及10M/100M PHY：
- VBAT 电源独立为RTC、LSE供电 - MAC和100M PHY全集成，外围只需要电容
- 低功耗模式：睡眠、停止 - 支持Auto-MDIX线路自动转换和极性自适应
● 系统时钟和复位： - 提供RGMII接口，可连接外置1000M PHY  
- 内置出厂调校的25MHz的RC振荡器 - 内置预分配的全球唯一MAC地址
- 内置约40kHz的RC振荡器 ● 5Gbps超高速USB 3.0控制器及PHY：
- 高速振荡器支持外部25MHz晶体 - 支持超高速的Host和Device模式
- 低速振荡器支持外部32kHz晶体 - 支持驱动USB 3.0 HUB
- 上电/下电复位、可编程电压监测器 - 高速一体化设计，实测每秒450Mbytes
● 2组共16路通用DMA控制器： ● 480Mbps高速USB 2.0控制器及PHY：  
- 共16个通道，支持环形缓冲区管理 - 支持高速/全速的Host和Device模式
● 2组12位模数转换ADC： - 支持1024字节数据包  
- 模拟输入范围：VSS～VDDIO- 支持USART串口或I2C引脚映射
- 16路外部信号通道+2路内部信号通道 ● 全速USB 2.0控制器及PHY：
- 采样速率高达5Msps，支持双ADC转换模式 - 支持全速/低速的Host和Device模式
● 16路TouchKey通道检测 - 支持OTG功能
