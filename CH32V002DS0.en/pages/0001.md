# CH32V002 Datasheet

V1.7  

# Overview

CH32V002 is an industrial-grade general-purpose microcontroller designed based on QingKe RISC-V core, which  
supports 48MHz system main frequency, with wide voltage, low-power consumption, 1-wire SDI and other  
features. Its pins and functions are compatible with CH32V003. CH32V002 has a built-in 12-bit ADC, with a  
sampling rate of up to 3Msps; it provides rich peripheral resources, such as 7-channel DMA controller,  
multi-group timer, USART, I2C, SPI and so on.
