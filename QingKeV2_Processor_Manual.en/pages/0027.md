## 6.2 Debug Interface

Different from the standard RISC-V defined JTAG interface, QingKe V2 series microprocessors use  
1/2-wire debugging interface, of which the V2A only supports a 1-wire interface, following the WCH  
debugging interface protocol. The debug interface is responsible for the communication between the debug  
host and the debug module, and realizes the read/write operation of the debug host to the debug module  
registers. WCH designed WCH_Link and open source its schematic and program binary files, which can be  
used for debugging all microprocessors of RISC-V architecture.  
Refer to WCH Debug Protocol Manual for specific debug interface protocols.
